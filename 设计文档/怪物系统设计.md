# 《分道扬镳》怪物系统设计（大纲）

> 版本：v0.1（大纲版，细节待填充）
> 定位：自然型、智慧型、精英怪的统一规则源；仇恨、升级、复活、掉落等规则在此定义，避免散落在各文档中
> 关联文档：《环境亲和度与双路线玩法》《岛中岛开场设计》《Boss属性与行为设计》《圣物系统设计》《技能系统设计》《塔防与塔系统设计》《装备与宝石系统设计》《游戏机制总览》《AI数值测试与验收文档》

## 一、怪物总览与分类

| 分类 | 驱动 | 受亲和度影响 | 示例 | 主要产出 |
| --- | --- | --- | --- | --- |
| 自然型 | 本能驱动 | 是，按亲和度阈值行动 | 牛怪、熊怪 | 狂暴精华、自然材料、生肉 / 血食 |
| 智慧型 | 有目标和战术，追击 / 守卫 / 配合 | 否 | 幽灵（即恶魔仆从）、恶魔之子、Boss | 圣物材料、精英装备、幽灵精魄、技能书 |
| 精英怪 | 中期枢纽，智慧型强化模板 | 否 | 恶魔之子 | 圣物卷轴、精品装备、技能书、塔材料 |
| 小Boss | 有明确仇恨目标 / 场景驱动，独立威胁 | 否 | 恶魔分身、深渊幽灵将军 | 击杀奖励待定 |

- 统一口径：幽灵 = 恶魔仆从（DemonMinion），即智慧型普通怪，恶魔系，击杀不扣亲和度；文档统一称幽灵。
- 精英怪统一称为恶魔之子。
- Boss 由《Boss属性与行为设计》单独定义；本设计覆盖普通怪、精英怪与小Boss。
- 需要明确：分类判定标准（亲和敏感性 / 行为驱动 / 掉落阵营）。

## 二、自然型怪物设计（待填充）

### 2.1 类型与示例
- 牛怪：自然型基础怪，全图数量最多、分布最散；主要产出自然材料与生肉。
- 熊怪：自然型守卫怪，主要聚集在宝箱附近，攻击力更高；开箱路线的天然威胁。
- 分布定位：牛怪全图散点分布、数量最多；熊怪集中于宝箱 / 资源点附近，数量少但威胁高。
- 击杀自然型怪基础 -5 亲和（牛怪 / 熊怪一致，待校准）。

### 2.2 亲和度行为阈值
- 亲和度 0-100，初始 80；按亲和度分档切换行为（无视 / 警戒 / 敌对 / 追杀）。
- 具体档位与行为表待补（参考《环境亲和度与双路线玩法》3.2）。

### 2.3 行为规则
- 巡逻 / 逃跑 / 反击 / 受击仇恨。
- 投喂响应：鲜肉、怪物腐肉、被病毒感染的肉。
- 被病毒感染的肉：自然怪吃下后增加对指定玩家的仇恨。

### 2.4 掉落
- 狂暴精华、自然材料、生肉 / 血食；狂暴层掉落更好。

### 2.5 击杀代价
- 击杀自然型怪 -5 基础亲和；同区域连续击杀热度可加深扣减。

### 2.6 技能（牛怪 / 熊怪）

| 技能 | 所属 | 效果 | 触发条件 | 触发概率 |
| --- | --- | --- | --- | --- |
| 蛮牛冲击 | 牛怪 | 10m 快速冲击撞向敌人，命中造成 2 秒眩晕 | 攻击范围内存在亲和度低于 50 的敌人 | 基础 10%；随敌人亲和度降低线性升高，最高 25% |
| 狂暴 | 熊怪 | 5 秒内攻击与移速提升 30% | 攻击范围内存在亲和度低于 50 的敌人 | 基础 10%；随敌人亲和度降低线性升高，最高 25% |

- 概率公式（待校准）：触发概率 = 10% + 15% × (50 - 敌人亲和度) / 50；亲和度 50 时为 10%，亲和度 0 时封顶 25%。
- 自然怪使用技能后的 30 秒内，自然怪掉落物品概率翻倍。

## 三、智慧型怪物设计（待填充）

### 3.1 类型与示例
- 幽灵（即恶魔仆从 / DemonMinion）：唯一智慧型普通怪，恶魔系，击杀不扣亲和度。

### 3.2 行为规则
- 追击、守卫、配合；是否组队 / 拉怪联动待定。
- 不随亲和度变化，始终保持敌对。

### 3.3 仇恨与目标选择
- 小怪层采用简化仇恨：最近 / 伤害最高 / 被投喂标记。
- Boss 层采用完整总分体系，见《Boss属性与行为设计》。

### 3.4 掉落
- 圣物卷轴、幽灵精魄、技能书、塔 / 宝石材料；与普通怪区分掉落权重。

## 四、精英怪：恶魔之子（待填充）

### 4.1 身份与出生

- 精英怪统一称为恶魔之子。
- 全图设 3-5 个固定出生点，每次随机从一个出生点出生。
- 由全图共享击杀计数触发出生；具体阈值待定。
- 击杀恶魔之子同样计入共享击杀计数。

### 4.2 行为与开箱

- 会攻击玩家，也会主动开启宝箱获取物品并提升自身属性。
- 开箱规则与玩家一致，读条时间为玩家的 2 倍；受击回退等规则同玩家。
- 是否守卫资源点 / 是否召唤待定。

### 4.3 UI 信息

- UI 显示恶魔之子已获得的装备清单，玩家可随时查看，用于判断是否值得猎杀。

### 4.4 掉落

- 击杀获得：精英基础掉落 + 恶魔之子开箱获得装备的一部分（比例 / 战利品袋形式待定）。
- 掉落 2 精品 + 1 圣物卷轴；击杀第 3 个恶魔之子必出圣物（是否保留待统一）。
- 技能书必掉；塔材料与宝石按配额产出。

### 4.5 与 Boss 苏醒的关系

- 不使用"击杀精英缩短 Boss 苏醒 2 分钟"规则。
- 击杀恶魔之子按权重规则计入共享击杀进度（见第五章）：恶魔之子权重 = 10。
- 智慧怪（幽灵）权重 = 2，即 1 个恶魔之子 = 5 个幽灵。

### 4.6 守卫结构

- 出生点附近存在自然型哨兵：低亲和玩家进入仍会被针对。
- 附近智慧型守卫：亲和度无法豁免。

## 五、Boss 苏醒与恶魔分身（权重规则）

### 5.1 Boss 苏醒权重（替代数量规则）

- 击杀权重：自然怪 = 1，智慧怪（幽灵）= 2，精英怪（恶魔之子）= 10。
- 单位时间（建议 60 秒滑动窗口，待实测）内共享击杀权重超过阈值 → Boss 提前苏醒；未超过 → Boss 按正常时间苏醒。
- 阶段阈值示例：第一阶段阈值 100（示例值，各阶段待定）。
- 玩家互杀是否计入权重：待定（倾向高权重）。

### 5.2 恶魔分身（小 Boss）触发

- 个人击杀权重在同一窗口内超过总阈值的 65%（示例：阶段阈值 100，个人 > 65）→ 触发恶魔分身追杀该玩家。
- 玩家可实时看到个人击杀值（UI 显示）。
- 恶魔分身是独立怪物：不受圣物减伤影响，不进入 Boss 仇恨总分体系；仇恨以触发玩家为主。
- 分身强度随超出量增长（待定）；击杀 / 消失 / 超时规则待定。
- 击杀分身是否计入共享权重与掉落：待定。

### 5.3 UI 可见性

- 实时显示：共享权重进度、Boss 苏醒阈值、个人击杀值、分身预警线（65%）。

## 七、与其它系统联动

- 亲和度：击杀扣减、阈值行为、B 区共生。
- 双路线：狩猎流（A 区智慧怪 / 精英）与开箱流（B 区自然怪）的掉落平衡。
- 海平面：低地怪物被压缩 / 淹没后的行为。
- 掉落：圣物材料、技能书、宝石、塔材料、怪物专属道具的统一掉落表。
- Boss 召唤物：Boss 召唤类技能（当前示例为魔潮召唤）产生的幽灵小怪是否为智慧怪（幽灵），击杀是否计入共享击杀计数与精英触发阈值。
- 恶魔分身：独立小 Boss，不受圣物减伤，不参与 Boss 仇恨总分；详细见第五章。
- 阿蛮：怪物是否会攻击 / 守护阿蛮（若流程涉及）。

## 九、测试与验收（待填充）

- 自然型亲和阈值切换正确。
- 牛怪蛮牛冲击 / 熊怪狂暴在敌人亲和 <50 时按概率触发，概率随亲和降低线性升高。
- 自然怪使用技能后 30 秒内掉落翻倍生效，计时与适用范围正确。
- 恶魔之子保底掉落规则（第 3 个是否必出圣物）待统一后验收。
- 恶魔之子击杀权重（= 10，智慧怪 = 2）正确计入共享击杀进度。
- 恶魔之子出生点随机、开箱读条为玩家 2 倍且可被打断；UI 装备清单可随时查看。
- 怪物数量配额 / 重生 / 海平面淹没不产生卡死或刷怪漏洞。

## 十、开放问题

1. 牛怪 / 熊怪的具体掉落与亲和扣减如何与全局规则统一。
2. 熊怪在宝箱附近的分布数量与守护强度如何平衡开箱流路线。
3. 恶魔之子出生阈值（每累计击杀多少智慧怪触发）、单局刷新上限与守卫强度待定。
4. Boss 召唤类技能（当前示例为魔潮召唤）产生的幽灵小怪是否计入共享击杀计数与精英触发阈值。
5. 怪物仇恨是否统一采用简化规则，还是分层实现。
6. 阿蛮是否会被怪物攻击 / 需要守卫流程。
7. 自然怪使用技能后 30 秒掉落翻倍的作用范围：全图自然怪共享，还是仅触发者 / 当前区域？
8. 玩家获得恶魔之子开箱装备的比例与"战利品袋"形式待定。
9. 恶魔之子的开箱数量 / 属性提升上限，以及第 3 个恶魔之子保底圣物是否保留待定。
10. 权重窗口时长（60 秒建议）与各阶段共享阈值待实测。
11. 个人 65% 分身线的具体数值与"超出量越大分身越强"的曲线待定。
12. 恶魔分身击杀 / 超时 / 权重回落的消失规则，以及击杀是否计入共享权重与掉落。
13. 玩家互杀是否计入 Boss 苏醒权重（若计入，权重值待定）。
14. 精英（恶魔之子）出生触发是否改用权重进度而非击杀计数。

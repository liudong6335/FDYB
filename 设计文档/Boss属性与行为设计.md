# 《分道扬镳》Boss 属性与行为设计

> 版本：v0.2（明确：判定快照不重算 / 可读性靠经验模式，不靠数值计算）
> 定位：Boss 本体（属性 / 技能 / 行为逻辑）设计；三方博弈与结盟规则见《Boss战设计_三国演义式三方博弈》
> 原则：Boss 是"想赢、怕死、记仇、谨慎"的第三方，所有属性与行为都服务这一人格

## 一、Boss 定位

- Boss 不是木桩，也不是普通怪：它承担共同威胁、博弈杠杆、终局载体三个功能。
- 属性回答"玩家要花多久才能打死它"；行为回答"它现在想赢、怕死，还是在试探"。

## 二、属性基线（初版）

| 属性 | 初版值 | 说明 |
| --- | --- | --- |
| 生命 | 10000 | 正常状态基线；状态统一为虚弱、正常、暴走，倍率待定 |
| 防御 | 100 | 固定减伤：1 点防御抵消 1 点伤害，角色通用 |
| 攻击 | 300/次 | 攻击间隔 2 秒，等效 DPS 150/秒；圣物文档的减伤示例沿用此基准 |
| 移速 | 3 m/s | 低于玩家基础 4 m/s，可被风筝，但受海平面压缩 |
| 仇恨范围 | 20m | 正常 20m，残血目标翻倍至 40m；目标按仇恨总分排序，详见仇恨结算 |
| 强化层 | 每 30 秒 +1 层 | 每层攻击 / 技能频率 +5-10%，层数 UI 可见 |
| 残血回血 | <20% 缓回，<10% 加速 | 制造斩杀线前的抉择窗口 |
| 控制抗性 | 减速生效，眩晕缩短 / 免疫 | 避免控制链锁死 Boss |

### 与圣物的交互

- 圣物只对 Boss 造成的伤害生效：日之石约 50% 减伤，月之石约 40% 减伤；玩家之间的攻击不受圣物影响。
- 以 Boss DPS 150/秒 为基准：无圣物承受 150/秒，日之石 75/秒，月之石 90/秒（圣物文档示例）。
- 具体获取、合成、替换规则见《圣物系统设计》。
- **圣物仇恨加成**：Boss 苏醒后，持有圣物的玩家获得圣物仇恨（日之石 5000、月之石 4000），自苏醒起 2 分钟内线性消散至 0；不单独使用"锁定"概念，目标一律按仇恨总分排序。
  - 双方都无圣物 → 无圣物仇恨，Boss 根据位置快照前往最后已知位置搜寻玩家。
  - 一方有圣物 → 该持有者获得对应圣物仇恨，成为主要目标。
  - 双方都有圣物 → 日之石持有者仇恨更高（5000 > 4000），成为首要目标。
- 圣物每 5 秒向 Boss 发送一次位置信标，Boss 据此持续追踪圣物持有者。
- 承伤顺序：圣物按 Boss 总攻击力计算比例抵消（日 50% / 月 40%），剩余伤害再减去角色防御固定值；即最终伤害 = Boss 攻击力 × (1 - 圣物减伤比例) - 防御（下限 0）。

### 状态：虚弱、正常、暴走

Boss 状态统一使用三种互斥表述：

| 状态 | 触发 | 效果 | 退出 |
| --- | --- | --- | --- |
| 虚弱 | 提前苏醒或对手淘汰后苏醒 | 按提前量降低起始强度；强度和仇恨倍率下调 | 强度恢复到 100% 后进入正常 |
| 正常 | 正常苏醒或虚弱恢复完成 | 使用标准属性、技能频率和仇恨倍率 | 到达暴走时间后进入暴走 |
| 暴走 | 苏醒后达到设定时间 | 使用最高属性、技能频率和仇恨倍率 | 死亡 |

规则：

- 虚弱状态下，起始强度暂定为 50-60%，每分钟恢复约 10%。
- 玩家在 Boss 苏醒前死亡但成功回魂时，不属于对手淘汰，不触发虚弱。
- 如果虚弱状态在到达暴走时仍未恢复完成，直接进入暴走。
- 行为逻辑可以通过行为控制器调整，但状态控制器只提供属性、技能频率和仇恨倍率。
- UI、日志和后续文档统一使用“虚弱 / 正常 / 暴走”，不再使用第一、第二、第三形态作为状态名称。
## 三、技能设计（三个）

技能设计原则：每个技能制造一个决策，而不是纯伤害；技能按行为状态触发，与结盟 / 翻脸 / 风筝联动。

| 技能 | 效果 | 行为目的 |
| --- | --- | --- |
| 鲜血收割 | 点名范围内生命最低玩家，高额单体伤害并标记 5 秒；标记以仇恨加成计入总分（数值待定） | 落实"残血不结盟、直接击杀"；逼弱者不能靠低血量骗结盟 |
| 魔潮召唤 | 召唤 2-3 只幽灵小怪攻击玩家，Boss 本体保持移动 | 打断风筝节奏、消耗资源，制造"清怪 vs 打 Boss"抉择；结盟 / 翻脸后制造混战 |
| 锁链囚笼 | 对 10m 内两名玩家的连线区域释放锁链，命中减速 / 定身并拉近 | 阻止无限风筝，强迫双方站位靠近，配合海平面收束 |

技能触发规则：

- 残血目标在攻击范围内 → 优先鲜血收割。
- 被风筝（长时间无有效目标）→ 锁链囚笼。
- 被双人围攻且局势判断"打不过" → 尝试结盟；未结盟时用魔潮召唤制造混战。
- 结盟执行期间：只使用召唤与范围技能，锁链不作用于盟友。

## 四、行为逻辑（核心）

Boss 是"状态机 + 每 10 秒局势判断"的决策者：

```
漫游 → 追击 → 局势判断（10 秒快照）→ 进攻 / 结盟 / 转向 → 结盟执行 → 翻脸 / 追杀 → 死亡 → 心争夺
```

- **不做极端状态重算**：10 秒局势判断快照固定使用到下一周期，残血、血量突变等极端变化不打断局势判断快照。Boss 不聪明、凭上次判断行事，这是设计意图，行为更可读（仇恨层的血量打断规则见仇恨结算）。

### 仇恨结算（总分排序 + 5 秒快照）

- 所有候选目标按仇恨总分从高到低排序，取最高者；不使用仇恨类型优先级（标记、圣物不单独置顶），同分时按"血量更低 → 战力更低 → 更近"依次裁决。
- 仇恨值 = 滚动 5 秒窗口内对 Boss 造成的真实伤害 + 残血修正 + 圣物仇恨 + 结盟追杀仇恨；各加分项独立累加（如有）。
- 伤害统一采用真实伤害：扣除防御、减伤后实际对 Boss 造成的伤害；玩家本体、玩家召唤物与塔计入，玩家间伤害不计入。
- 残血修正：目标血量低于 30% 起算，修正 = 2000 × (30% - 当前血量%) / 20%，血量越低加成越高，HP ≤ 10% 封顶 2000；血量变化实时更新分值。
- 快照规则：正常每 5 秒结算一次目标，窗口内不因伤害变化换目标；唯一例外是目标血量从 10% 以上跌破 10%（残血修正达到上限 2000）时立即打断快照并换目标，其他血量变化不打断。
- 残血追击范围：目标血量低于 30% 时从 20m 翻倍至 40m；目标超出 Boss 40m 时终止残血追击。血量恢复到 30% 以上时，追击范围立即回到 20m，之后按正常仇恨体系结算（20m 范围 + 总分排序）。
- 当前目标死亡或超出仇恨范围时允许立即重选，其余情况等到下个结算周期。
- 圣物仇恨：日之石 5000、月之石 4000，自 Boss 苏醒起 2 分钟内线性消散至 0。
- 塔不进入玩家仇恨竞争：塔仇恨 = 滚动 5 秒窗口内对 Boss 造成的真实伤害 × 80%，仅在没有可追击玩家目标时生效；塔血量用于"拆塔模式"完成判定，已开始拆的塔血量越低越不中途放弃，拆完再回到玩家仇恨。
- 仇恨结算决定"追谁"（战术），10 秒局势判断决定"怎么打 / 是否结盟"（战略），两者独立；局势判断快照不因血量变化重算。

行为优先级（每周期；目标选择只按仇恨总分，不使用类型优先）：

1. 结盟执行中（Boss + 玩家）→ 盟友仇恨豁免，剩余玩家按仇恨总分排序选择结盟目标；只用召唤 / 范围技能。
2. 仇恨总分最高的目标在攻击范围内 → 优先释放对应技能（残血修正由总分体现，不单独置顶）。
3. 被风筝超过阈值 → 锁链囚笼，拉近距离；仍无可追击玩家目标时转为拆塔。
4. 被双人围攻且判断打不过二人联手 → 考虑结盟（主动发起约 20% 概率）；结盟对象需未攻击过 Boss，未结盟则召唤混战。
5. 结盟结束 → 按结盟追杀仇恨规则追击原盟友。
6. 血量 <20% → 回血姿态，逼玩家在斩杀窗口内做翻脸 / 结盟 / 全力输出决策。

### 与结盟的仇恨联动

- 与 Boss 结盟：申请人必须没有攻击过 Boss（对 Boss 的仇恨为 0），Boss 只与没有攻击过它的玩家结盟；被攻击不会自动产生仇恨，申请不受距离限制。
- 与玩家结盟：玩家之间没有仇恨概念，申请不受仇恨限制，可自由申请；每名玩家每局只有一次申请机会。
- 圣物仇恨在苏醒后 2 分钟内线性消散至 0，归零后不再产生仇恨，持有者可正常与 Boss 结盟。
- 结盟期间，缔约方之间互不攻击；盟友不可成为仇恨目标，即使被强者打到 10% 以下也不会触发残血上限打断，直到结盟结束。
- 结盟结束后，原盟友的仇恨：先进 3 秒缓冲（仇恨为 0），之后进入追杀仇恨；若目标仍 ≤10%，残血修正与结盟惩罚仇恨（+5000，30 秒内线性归零）是两个独立加分项，叠加计算；攻击 Boss 造成的伤害仇恨照常另算。

人格一致性总结：Boss 想赢（能双杀就杀、残血必杀）、怕死（打不过才结盟、主动结盟低概率）、记仇（追杀结盟过的弱者）、谨慎（不与残血者结盟、不与攻击过自己的玩家结盟）。

行为可读性：玩家不需要精确预测 Boss。紧张局势下即使显示精确数值，绝大多数玩家也来不及计算，只能靠经验判断；因此意图呈现以可观察的模式为主（低吼 / 变色 / 地面特效 / 强化层光环）。只有极少数顶尖玩家会利用精确数值，设计不以此为前提。

## 五、开放问题

1. 虚弱、正常、暴走三种状态的属性倍率、技能频率倍率、仇恨倍率和切换时间待实测。
2. 防御公式已定：1 点防御抵消 1 点伤害（固定减伤，角色通用）；暴走状态下防御是否同步变化待定。
3. 三个技能的数值、冷却与范围。
4. 强化层幅度（5-10% / 30 秒）与"合作 DPS 在 40% 前追不上"的目标。
5. 移速、仇恨范围与海平面压缩速度的配合。
6. 控制抗性的具体规则（眩晕免疫 / 缩短比例）。
7. 承伤顺序已定：圣物按 Boss 总攻击力比例抵消，防御按固定值抵消；圣物文档示例（150 / 75 / 90）未计入防御，数值落地时统一口径。
8. 残血修正满值 2000 与圣物仇恨 5000/4000 的数值平衡需实测校准。

## 六、测试对接

- 属性与技能数值进《AI数值测试与验收文档》的 Boss 判定与稳定性验收项。
- 行为逻辑用 AI 稳定性用例验证：状态机无非法迁移、技能按触发规则释放、局势判断快照可复现。
- 仇恨验收项：总分排序正确（真实伤害 + 残血修正 + 圣物仇恨 + 结盟追杀仇恨，各加分项独立累加）；5 秒窗口内不换目标、仅跌破 10% 打断；残血追击在 40m 外终止、血量恢复 30% 以上后追击范围回到 20m 并按正常体系结算；圣物仇恨 2 分钟线性消散至 0；结盟期间盟友仇恨豁免且互不攻击、与 Boss 结盟要求未攻击过 Boss、玩家间结盟无仇恨门槛且每局一次申请机会、结盟结束先进 3 秒缓冲且残血与结盟惩罚仇恨叠加。

# 《分道扬镳》版本规划（新手版 / 进阶版）

> 版本：v2.0
> 定位：只提供两个玩家版本：新手版（单机教学）与进阶版（联网好友房）；原"完整版"不再独立成版，作为进阶版上线后的更新路线分批交付
> 关联文档：《结盟机制设计》《Boss属性与行为设计》《Boss战设计_三国演义式三方博弈》《游戏机制总览》《塔防与塔系统设计》《圣物系统设计》《技能系统设计》《环境亲和度与双路线玩法》《AI数值测试与验收文档》

## 一、版本总览

| 版本 | 对战方式 | 时长 | 定位 |
| --- | --- | --- | --- |
| 新手版 | 离线，纯 AI 对手 | 10 分钟 | 教学 + 单人练习 |
| 进阶版 | 联网 1v1（好友房） | 首发约 15 分钟，随更新扩展至 22-25 分钟 | 唯一正式对战版本，持续更新 |

- 只提供两个玩家版本，不做排位、段位与快速匹配，只做好友房。
- 两个版本共用同一套战斗框架与代码，用系统开关区分。
- 玩家死亡与回魂契约在所有版本使用完全相同的规则与数值，不因版本调整。

## 二、新手版（10 分钟单机）

定位：教学 + 单人练习，让玩家在无联机压力下学会核心博弈。

- 玩家 + AI 对手 + AI Boss，全程本地，不可联网。
- 核心链：打 Boss、玩家间限时结盟、与 Boss 结盟（60% 基础版）、翻脸、抢心交付。
- 与 Boss 结盟 60%：申请 / 确认 / 时限 / 翻脸 / 盟友豁免流程完整；10 秒局势判断与仇恨惩罚曲线简化。
- 仇恨统一使用总分排序：真实伤害窗口、残血修正、圣物仇恨、追杀仇恨和塔仇恨；目标快照周期为 5 秒。
- 只留 1 种攻击塔 + 打怪 / 开箱掉攻击与 HP 点数。
- AI 对手可注入人格（保守 / 背叛 / 风筝），分别练习"怎么结盟、怎么防翻脸、怎么抢心"。
- 教学任务：完成结盟 1 次、翻脸 1 次、抢心 1 次即可解锁进阶版。
- 不做段位，只记录教学完成度。

## 三、进阶版（唯一正式版本）

定位：唯一正式对战版本；首发上线后通过更新持续扩展，不再单独提供第三个版本。

### 3.1 首发范围（约 15 分钟核心局）

- 联网 1v1，只做好友房。
- 玩家间结盟 + 翻脸 + 与 Boss 结盟（100%）。
- 与 Boss 结盟 100%：完整 10 秒局势判断快照、无结盟仇恨门槛、3 秒单向申请等待期、20% 主动概率、3 秒缓冲 + 5000 惩罚仇恨、与总分排序联动。
- 简化圣物：地图拾取的一次性减伤道具，淘汰掉落。
- 1-2 个主动技能、海平面缩圈、攻击塔 + 生命塔 2 种。
- 仇恨升级为总分：伤害 + 残血修正 + 圣物仇恨。
- 不做段位与积分，只保留好友房胜负记录。

### 3.2 更新路线（原"完整版"内容分批并入进阶版）

| 更新 | 内容 | 目标时长 |
| --- | --- | --- |
| U1 | 圣物完整链（合成 / 销毁 / 掉落 / 替换）、四类塔、宝石与六装备位完整成长 | 约 20 分钟 |
| U2 | 完整技能卡 / 双槽、海平面完整规则、虚弱/正常/暴走状态 + 强化层、环境亲和度双路线、完整仇恨总分（塔仇恨 / 结盟惩罚 / 40m 追击） | 22-25 分钟 |
| U3 | 细节与周边：岛中岛开场、观战、回放、复盘、语音 / 快捷消息、好友邀请与结算表现 | 不影响单局时长 |

- 所有更新直接进入进阶版，玩家不需要切换第三个版本。

## 四、两版规则差异表

| 系统 | 新手版 | 进阶版（首发） | 进阶版（更新后） |
| --- | --- | --- | --- |
| 对战方式 | 离线 vs AI | 联网 1v1（好友房） | 联网 1v1（好友房） |
| 时长 | 10 分钟 | 约 15 分钟 | 22-25 分钟 |
| Boss 仇恨 | 总分排序 + 5 秒目标快照 | 总分排序 + 5 秒目标快照 | 总分排序 + 5 秒目标快照 |
| 结盟 | 玩家间 + 与 Boss 结盟（60% 基础流程） | 玩家间 + 与 Boss 结盟（100%） | 保持 100%，完整联动 |
| 圣物 | 无 | 简化拾取道具 | 完整合成链 / 掉落 / 替换 |
| 塔 | 攻击塔 1 种 | 攻击 + 生命 2 种 | 4 类 |
| 成长 | 点数升级 | 点数 + 简易装备 | 宝石 / 六装备位完整成长 |
| 技能 | 无 | 1-2 个 | 完整技能卡 / 双槽 |
| 海平面 | 无（固定时长） | 缩圈倒计时 | 完整海平面 + 低地淹没 |
| 回魂契约 | 相同规则与数值 | 相同规则与数值 | 相同规则与数值 |
| 亲和 / 双路线 | 无 | 无 | 完整 |
| Boss 状态 | 随时间变强 | 随时间变强 | 虚弱/正常/暴走 + 强化层 |
| 战绩记录 | 仅教学完成度 | 好友房胜负记录 | 好友房胜负记录 |

## 五、解锁与好友房流程

- 新手玩家默认进入新手版；完成教学任务（结盟 1 次、翻脸 1 次、抢心 1 次）后解锁进阶版。
- 好友房由房主选择档位：新手版或进阶版；新玩家只能被邀请进新手版房间，完成新手教学后才能进进阶版房间。
- 不做段位与匹配，只做好友房；新手版不计胜负，进阶版保留好友房胜负记录。

## 六、开发阶段规划

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| 一 | 新手版：核心框架（移动 / 攻击 / Boss 基础 AI / 胜负流程）+ 离线教学闭环 + 玩家间结盟 + 与 Boss 结盟（60%）+ 抢心 + 教学任务 | 新手教学三目标可完成并解锁进阶版 |
| 二 | 进阶版首发：联网基础（房间 / 邀请 / 同步 / 断线重连）+ 首发核心规则（与 Boss 结盟 100%、简化圣物、基础技能、攻击 + 生命塔、仇恨总分、海平面缩圈） | 15 分钟联网 1v1 可正常打完 |
| 三 | 进阶版更新：U1 / U2 系统扩展 + U3 细节与周边（原"完整版"内容分批交付） | 22-25 分钟完整局 + 周边系统齐全 |
| 四 | 长线运营：平衡调优、新内容与活动迭代 | 可持续运营 |

发行节点：阶段一结束可上 Demo；阶段二结束进阶版首发，可正式发行；阶段三起为更新与升级内容。

## 七、技术要点

- 两版共用同一套战斗代码，用"系统开关配置"区分，避免维护多套逻辑。
- 联网层只在进阶版启用；新手版不接网络，规避联机 bug 对新手的干扰。
- 解锁条件放客户端即可；前期不做段位，只做好友房。
- AI 对手人格做成可注入配置，同时服务于新手版教学与好友房缺人时的机器人补位。

## 八、开放问题

1. 新手版 AI 对手是否需要可选难度（简单 / 中等 / 困难）。
2. 好友房缺人时是否用机器人补位。
3. 新手版完成教学后是否允许直接玩首发进阶版（跳过后续学习局）。
4. 进阶版 U1 / U2 / U3 更新包的具体上线顺序与节奏。
5. 两版共用系统开关的具体配置表与数值差异维护方式。
6. 新手版 Boss 结盟 60% 的简化边界：哪些流程必须完整、哪些可先简化。

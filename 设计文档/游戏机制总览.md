## 一、游戏概述

### 1.1 核心理念

《分道扬镳》是一款 1v1 策略竞技游戏（PvPvE），核心体验是"动态关系博弈"：两名玩家从被迫合作逐渐走向必然对立，在共享的恶魔（Boss）压力下进行资源争夺、心理博弈和策略抉择。

- 决策重于操作，攻击对手会加速共同威胁，形成经典囚徒困境。
- Boss 行为可预测，玩家需要动态判断"合作还是对抗"，并持续预判对手决策。
- 极端情况下，弱势一方可以阶段性帮助 Boss 压制另一方。

### 1.2 基本信息

| 项目 | 内容 |
| --- | --- |
| 玩法类型 | 1v1 策略竞技（PvPvE） |
| 单局时长 | 22-25 分钟（设计目标） |
| 美术风格 | 3D 卡通风格，2.5D 视角 |
| 开发引擎 | Unity 6.0 LTS |
| 运营平台 | PC（Steam） |

### 1.3 故事背景

故事发生在封禁之地。百年之前恶魔哈里斯被巫族大祭司囚禁于此，力量已日渐虚弱。两名外出历练的游侠先后误入此地，为了生存被迫并肩作战，又因资源匮乏而相互竞争。

一天，二人击败一只恶魔仆从后，巫族大祭司的孙女阿蛮从天而降。她冒险进入封禁之地，只为取得恶魔之心拯救生命垂危的大祭司，并承诺成功后带二人通过祭坛传送离开。

祭坛因年久破损，能量只够两人离开。三人约定阿蛮留下修复传送阵，二人去击杀恶魔，谁先取得恶魔之心并交给阿蛮，谁就能先离开。祭坛激活 8 分钟后恶魔会苏醒；在苏醒前，二人需找到镇压恶魔的两件圣物（日之石与月之石），并用巫族装备制作秘法合成能杀死恶魔的装备。

### 1.4 胜负条件

| 条件 | 结果 |
| --- | --- |
| 击杀恶魔（Boss）取得恶魔之心，并交给阿蛮 | 交付方获胜 |
| 玩家自身死亡 | 死亡者失败 |
| 对手成功将恶魔之心交付给阿蛮 | 交付方获胜，另一方失败 |
| NPC 阿蛮在岛中岛守点或关键事件中死亡 | 双方失败 |
| 双方都死亡 | 双方失败 |

> ⚠️ 当前代码只落地了阶段状态机（Victory / GameOver）与阿蛮死亡触发 GameOver；Boss、恶魔之心、交付判定均未实现。

## 二、核心循环与阶段流程

### 2.1 阶段总览（初版设计）

| 阶段 | 时间 | 内容 |
| --- | --- | --- |
| 第一阶段：祭坛守点 | 0-3 分钟 | 传送到岛中岛，守护阿蛮激活祭坛，抵御幽灵/水怪与小 Boss |
| 第二阶段：自由探索与争夺 | 岛中岛任务结束后 | 寻找宝箱、获取物品与金币，强化属性，应对对手和恶魔威胁 |
| 第三阶段：恶魔之心争夺 | 任务结束 +10 分钟后 | 恶魔苏醒后击杀 Boss 夺取恶魔之心，结盟或背叛，交付阿蛮获胜 |

> ⚠️ 阶段时间线以《岛中岛开场设计》为准：岛中岛任务结束后 3 分钟第一次涨潮；任务结束后 +10 分钟 Boss 苏醒倒计时结束；单局约 25 分钟。当前实现尚未落地。

### 2.2 当前阶段状态机（✅ 已实现）

`EscortPhaseController` 维护 `GamePhase`：

```
Menu → Opening → Exploration → BossBattle → Victory / GameOver
```

- `Opening`：岛中岛祭坛守点，守点期间不可互攻，完成后进入探索。
- `Exploration`：岛中岛任务结束后进入；当前仅切换状态，探索玩法仍由场景中的宝箱/商店/怪物承担。
- `BossBattle / Victory`：仅存在于枚举与 HUD 文案，尚无实际 Boss 战与胜负结算逻辑。
- `GameOver`：阿蛮死亡时触发。

### 2.3 当前完整玩法循环（✅ 已实现部分）

```
对话阿蛮 → 传送到岛中岛
  → 阿蛮激活祭坛，幽灵/水怪波次 + 深渊幽灵将军
  → 守点完成 → 祭坛升起、石桥出现
  → 奖励结算（高级宝石 + Boss 技能书）
  → 阿蛮留在祭坛成为回血点
  → 任务结束 +3 分钟第一次涨潮，探索开始
  → 任务结束 +10 分钟 Boss 苏醒倒计时结束
```

## 四、岛中岛任务（开场）

- 取消护送：对话后三人传送到岛中岛，阿蛮激活祭坛，完成前无路可出。
- 幽灵（恶魔系智慧型，必须清，不扣亲和）与水怪（自然型，可选，-5 亲和/只）；湖心岛有 3 木箱 + 1 铜箱。
- 第三波出现深渊幽灵将军：仇恨切换、召唤、横扫；不掉亲和，不影响 Boss 苏醒。
- 祭坛完成奖励：双方各 1 颗高级宝石，输出高者优先选（口径：Boss + 幽灵总伤害）。
- Boss 掉落：2 本不同技能书 + 1 颗普通宝石；20% 门槛，最后一击者拿宝石并优先选书。
- 任务结束前处于结盟状态（不可互攻）；任务结束后双方进入自由状态（PvP 开启），可互相攻击。
- 结盟：限时合作工具，见《Boss战设计_三国演义式三方博弈》，结盟期间不可互攻且可翻脸。
- 阿蛮留在祭坛成为回血点；Boss 被击杀后赶来收取恶魔之心，交付作为终局过场动画。详细规则见《Boss战设计_三国演义式三方博弈》。

### 4.1 PvP 伤害与结盟规则

**自由状态（岛中岛任务结束后生效）**

- 岛中岛任务结束前处于结盟状态，双方不可互攻。
- 任务结束后进入自由状态：玩家之间可以自由攻击，可攻击对方玩家与其营地、防御塔。
- PvP 伤害走统一伤害通道：攻击、技能、装备/宝石加成正常生效，命中与结算规则同打怪一致。
- 玩家死亡 = 出局（无复活）；死亡掉落按物品 dropOnDeath 配置，营地不提供第二条命。

**结盟（限时、可翻脸，取代止戈）**

- 结盟是 Boss 战内的限时合作工具，规则见《Boss战设计_三国演义式三方博弈》；全局不再有不可逆的止戈。
- 玩家 + 玩家结盟：一方发起、对方 2-3 秒内确认，期间双方不可互相攻击；任一玩家攻击对方即结盟破裂，攻击方获得"Boss 仇恨锁定"，被攻击方获得短暂"Boss 不打你"。
- 结盟期间双方未放置的塔锁定不可放置、不计入战力；结盟结束后解锁。
- 结盟时限到即强制解除并进入 PvP/心争夺；怪物、Boss 与环境压力不受结盟影响。

## 六、掉落、背包与商城

### 6.1 全局掉落预算（✅ 已实现）

- `LootBudgetManager` 控制全图产出总量：装备类按 `maxCount` 限量，药水/金币等 `unlimited` 不限量。
- 所有宝箱/怪物掉落统一走 `PickOne(dropEntries)`：过滤预算 → 按权重抽取 → 扣减 → 返回 `GameItem`。
- 每局开始（岛中岛任务启动）调用 `Reset()`。

### 6.2 掉落物生命周期（✅ 已实现）

| 来源 | 行为 |
| --- | --- |
| 宝箱 | 开箱动画后，掉落物从箱口飞向玩家（抛物线，约 0.6s） |
| 怪物 | 先落地弹跳，尸体消失（约 1s）后飞向击杀者 |
| 玩家死亡掉落 | 停在地面，玩家靠近 4 米自动拾取，其他玩家也可拾取 |
| 背包已满 | 掉落物落回地面，腾出空间后可再次拾取 |

- 怪物掉落归属：击杀者优先，无击杀者回退最近玩家。
- 死亡掉落规则：按物品配置 `dropOnDeath + deathDropChance`，不走全局预算。

### 6.3 背包与装备（✅ 已实现）

| 规则 | 内容 |
| --- | --- |
| 背包容量 | 20 格，每格一件，金币不占格 |
| 装备部位 | 5 个：护腕 / 铠甲 / 护肩 / 裤子 / 武器宝石 |
| 自动穿戴 | 首次获得该部位装备自动穿戴；同类更强装备可手动/自动替换 |
| 自动合成 | 同部位、同类型、同稀有度的两件装备自动合成下一稀有度（普通 → 精品 → 稀有 → 史诗） |
| 属性加成 | 生命词条加固定 HP；DPS 词条按 `statValue / 100` 的百分比倍率叠加 |
| 出售价 | 按稀有度：普通 25 / 精品 50 / 稀有 100 / 史诗 200 / 神话 500 |

> ⚠️ 初版设计是"两个同名普通装备自动合成精品"，当前实现扩展为同基装备逐级合成；初版将 DPS 视为固定数值，当前实现为百分比倍率。

## 七、已规划但未实现的设计

### 7.1 环境亲和度与双路线玩法（📐《环境亲和度与双路线玩法》）

- 亲和度 0-100，初始 80；击杀自然型怪扣亲和，投喂（鲜肉/怪物腐肉/被病毒感染的肉）影响双方。
- 形成"狩猎流"（低亲和，A 区，靠击杀成长）与"开箱流"（高亲和，B 区，靠宝箱成长）双路线。
- 自然型/智慧型怪物划分、区域划分、自然回血、三种投喂道具（鲜肉/怪物腐肉/被病毒感染的肉）、路线专属掉落。
- 影响第三阶段：Boss 战自然回血、狂暴怪群、恶魔之心持有者被怪物针对。

### 7.2 投喂道具（仅保留互坑小玩法）

- 陷阱模块已移除，只保留三种投喂道具：鲜肉（喂怪 +15 亲和）、怪物腐肉（喂对手，自然怪仇恨上升、亲和 -10，背包限时 1 分钟）、被病毒感染的肉（喂自然怪，自然怪增加对对手仇恨、亲和 -15）。
- 怪物腐肉在结盟期间不可对对手使用；被病毒感染的肉通过怪物生效，不受结盟限制。


### 7.3 Steam 房间与邀请机制（📐《Steam 房间与邀请机制设计》）

- 好友挑战 + 6 位房间码两种进入方式，Steam Lobby 承担房间。
- 房主权威端 + P2P/中继传输，输入/快照同步。
- 房间状态机：Waiting → Ready → Loading → Playing → Finished → Closed。

| 精英怪 3 个，掉落 2 精品 + 1 圣物卷轴；击杀精英缩短苏醒 2 分钟 | ❌ |

### 7.5 海岛地图与海平面上升（📐《海岛与海平面上升机制设计》）

- 正式地图为海岛，海平面 0m → 16m；岛中岛任务结束后 3 分钟开始上涨，可活动区域逐步收缩。
- 低地先淹、高地后淹，峰顶祭坛为最终决战圈；断桥被淹后自动改走高路。
- 淹没前 30 秒预警；浅水减速、深水 30 HP/s；未完成区域保留 60 秒缓冲。
- 低地宝箱/商店/掉落物按节点沉没或迁移，怪物向高地聚集。
### 7.6 领地与塔系统（弱化版，📐《领地与塔系统设计》）

- 领地只作为补给点与防御点，不构成独立基地或独立胜负线。
- 营地提供回血、休整与少量补给；被摧毁只损失保命手段，玩家不会因此失败。
- 每名玩家最多 1-2 座防御塔，任务结束 +5 分钟解锁；塔保护营地与资源点，PvP 自由状态可攻击对手，结盟期间不生效。
- 无战争迷雾、无营地等级、无替死化身；玩家死亡即出局，不能复活。
- 选位与海平面联动：低地营地发育快但易被淹没，高地营地安全但发育慢。
### 7.7 技能系统（📐《技能系统设计》）

- 每名玩家 2 个技能槽：天赋槽自动携带且不可更换，学习槽通过技能书获得/覆盖。
- 天赋技能预设在角色 Prefab 内；施法前摇/吟唱受击回退、不归零。
- 技能书来自宝箱/怪物/商店，背包可堆叠；点击使用后学习、升级或覆盖：同技能书升级学习槽技能，不同技能书覆盖。
- 两个槽可以是相同技能，独立冷却分别施放。
- 技能统一打包为 SkillCard（技能卡），覆盖天赋技能与扩展技能。
- 技能可升级至 Lv3（×1.3 / ×1.6），商店与精英/暗黑宝箱提供固定产出保底。
### 7.8 装备与宝石系统（📐《装备与宝石系统设计》）

- 六装备位：肩甲/胸甲/护腕/鞋子 + 武器 + 圣物；装备开局固定，游戏内不再掉落具体装备。
- 四件防具使用同类型宝石（生命/力量/防御），四件同类型获得 +10% 额外加成。
- 宝石成为主要成长资源：生命/力量/防御宝石、武器宝石，以及合成获得的圣物（日之石/月之石）。
### 7.9 岛中岛开场（📐《岛中岛开场设计》）

- 取消护送：对话后传送到岛中岛，守护阿蛮激活祭坛，完成前无路可出。
- 怪物分幽灵（必须清，不扣亲和）与水怪（可选，少量扣亲和）；湖心岛有宝箱。
- 第三波出现深渊幽灵将军：不掉亲和、不影响 Boss 苏醒，掉落 2 本技能书 + 1 颗普通宝石（20% 门槛）。
- 祭坛完成后祭坛升起、石桥出现，阿蛮成为回血点；双方各获 1 颗高级宝石，输出高者优先选。
- 任务结束前处于结盟状态（不可互攻）；任务结束后双方进入自由状态（PvP 开启），可互相攻击。
- 结盟：限时合作工具，见《Boss战设计_三国演义式三方博弈》，结盟期间不可互攻且可翻脸。
- 单局约 25 分钟，阶段门控：0-5 分钟选址建营地/基础技能，+5 分钟防御塔解锁，+10 分钟 Boss 苏醒，+15 分钟峰顶决战圈。
- 每件装备可镶嵌 1 颗宝石；宝石按部位/属性/等级（普通/高级/传说）区分，替换时旧宝石回到背包。
- 同类型同等级宝石不堆叠，凑够数量自动合成并自动镶嵌；圣物槽每名玩家 1 个，日之石/月之石二选一。

## 十三、现有机制整体评价（优势 / 劣势）

### 13.1 优势：值得保留的设计

| # | 优势 | 说明 |
| --- | --- | --- |
| 1 | 合作-竞争双目标结构 | 岛中岛守点是共享目标，宝箱/商店/出售池是竞争资源，天然形成囚徒困境，博弈空间充足 |
| 2 | 开局资源与共同目标绑定 | 岛中岛守点决定开局宝石/技能书分配，玩家必须参与共同防御 |
| 3 | 决策重于操作 | 点击移动、自动导航、读条规则都简单直接，上手门槛低，符合策略竞技定位 |
| 4 | 怪物压力曲线 | 怪物分类与升级规则由独立怪物系统设计，形成清怪与发育的权衡 |
| 5 | 全局掉落预算 | 装备产出总量可控、归属清晰（击杀者优先），单局数值不膨胀 |
| 6 | 数据层契约先行 | 背包/出售/合成 API 原子性 + 事件驱动，UI 与数据解耦，工程上稳健 |
| 7 | 玩家 AI 与角色卡 | 可用于自动测试、人机模式和平衡验证，是低成本迭代资产 |
| 8 | 设计文档体系完整 | 亲和度双路线、投喂道具、Steam 房间都有设计稿，后续方向明确 |

### 13.2 劣势与风险：需要解决

| # | 劣势 / 风险 | 具体影响 |
| --- | --- | --- |
| 1 | 核心闭环缺失 | Boss、恶魔之心、胜负结算未实现，一局游戏无法完成，是所有问题的根 |
| 2 | 玩家间对抗缺位 | PvP 自由状态与结盟规则已补充（见 4.1）但未实现；抢箱/打断/投喂/引怪手段仍缺，对手在当前玩法里存在感弱，"动态关系博弈"尚未在代码落地 |
| 3 | 阶段压力单调 | 岛中岛守点 + 探索资源点仍可能重复；海平面收缩与结盟/背叛窗口已补足压力设计，尚未实现 |
| 4 | 经济未闭环 | 金币产出与消耗没有平衡设计，商店硬编码，出售池/限购/刷新规则未接 UI |
| 5 | 装备深度不足 | 只有 HP、DPS 两类词条，无套装、无主动效果、无特色机制，养成反馈单一 |
| 6 | 怪物类型单一 | 目前只有恶魔仆从一种（靠等级区分），没有精英/Boss/自然型-智慧型差异，战术深度有限 |
| 7 | 信息反馈不完整 | 无小地图情报、伤害数字、对手意图提示，玩家难以读取对方路线，博弈反馈弱 |
| 8 | 惩罚偏被动 | 距离惩罚已取消；剩余惩罚需以选择驱动（如水怪亲和扣减、低地淹没） |
| 9 | 开箱博弈浅 | 先到先得 + 读条 + 受击回退，缺少对手主动干扰（打断道具、投喂、争夺） |
| 10 | 数值未调优 | 怪物伤害、装备倍率、掉落权重、合成数值均未经测试，DPS 词条改成百分比倍率后手感需要验证 |
| 11 | 工程债 | 旧 Input API 未迁移、商店/UI 硬编码、多处占位面板、无主菜单与场景管理 |
| 12 | 配置不数据化 | 大量数值散落在代码字段和 Inspector，缺统一配置表和运行时调参工具，平衡迭代慢 |
| 13 | 叙事与玩法脱节 | 8 分钟苏醒、圣物、祭坛、恶魔之心等故事设定尚未进入玩法，世界观没有形成玩法压力 |

### 13.3 结论与调整方向

1. **先把"一局游戏"做完整**：补 Boss 与恶魔之心、胜负结算，并把"恶魔苏醒倒计时 + 海平面收缩 + 结盟/背叛窗口"作为全局压力线，让守点/探索/争夺都有时间锚点。
2. **再补"对手感"**：落地玩家间对抗（PvP 规则、抢箱/打断、引怪、出售池博弈），这是当前机制设计上最缺的一层。
3. **后做机制扩展**：亲和度双路线、投喂道具按设计稿分批接入，但不应作为第一阶段依赖。
4. **同步清工程债**：统一数值配置、补齐 HUD 信息、迁移 Input System、建立正式主场景，避免机制越加越难改。

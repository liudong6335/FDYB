# 塔防与塔系统设计

> 版本：v0.4（2026-08-25 更新：移除回收机制）
> 关联文档：《游戏机制总览》《海岛与海平面上升机制设计》《环境亲和度与双路线玩法》《道具系统设计》《背包数据契约》《宝箱开箱系统设计》
> 定位：为玩家提供可主动构建的地图控制层，通过材料收集、塔合成、选点放置与升级，形成"阵地争夺"与"合作/对抗"双面博弈

## 一、设计目标

1. 给玩家一条可主动构筑的成长线：打怪/开宝箱收集材料 → 合成塔 → 选点放置 → 升级强化。
2. 四类塔分别覆盖战斗、续航、强化、亲和四条路线，与现有岛中岛任务、探索、Boss 阶段互补。
3. 用 40m 排他性 + 每局塔制造资源配额（通常最多 4 座/玩家，正常流程保底 2 座）+ 单次升级，把"放哪、何时放、是否升级"变成持续决策，塔主要作为后期 Boss 战战略资源。
4. 主动塔是玩家主导的地图控制手段，与海平面、技能、宝石共同构成成长与博弈。
5. 与海平面联动：低地塔会被淹没，鼓励提前转移，避免一座塔永久控图。

## 二、材料与合成

### 2.1 材料来源

- 建造图纸来自怪物与宝箱；对应宝石复用装备宝石系统（宝箱/怪物/商店产出）；石头通过挖石获得。
- 石头是地图数值资源，不占背包：挖取地图石块获得；塔合成不再消耗木头。
- 塔材料走独立掉落权重，不占用现有装备/金币掉落预算；每局材料总量按配额控制，通常支持每名玩家制造 4 座塔，正常流程保底 2 座；对应宝石与装备共用产出，造塔数量还会受宝石库存约束。
- 材料类型：

| 材料 | 存放方式 | 用途 |
| --- | --- | --- |
| 石头 | 数值资源，不占背包 | 通用塔基资源 |
| 建造图纸 | 背包格，每格一件 | 合成任意塔的通用图纸 |
| 对应宝石 | 背包格，复用装备宝石系统 | 生命/力量/防御宝石作为塔属性核心 |

> 石头按数值计数，与金币同一套 UI；建造图纸与宝石占用背包格、不可堆叠，制造材料多了会挤压装备空间；宝石同时是装备成长资源，造塔与镶装备构成资源抉择。

### 2.2 合成规则

- 配方：建造图纸 ×1 + 石头 ×1 + 对应宝石 ×1 → 对应类型塔；攻击塔合成消耗石头 ×2，获取难度更高。
- 对应宝石与装备共用同一套宝石系统：攻击塔用力量宝石、生命塔用生命宝石、Buff 塔用防御宝石，亲和度塔的对应宝石待定；宝石被消耗后不返还。
- 合成在塔面板进行，读条 2 秒；受击回退 1 秒。
- 合成产物为"塔（待放置）"；未放置的塔占用背包格，持有数量受制造资源总量与背包容量约束。
- 合成不消耗金币；是否允许商店出售塔材料由数值阶段再定。
- 塔合成与升级在岛中岛任务结束 +5 分钟后开放；此前仅收集石头、图纸与对应宝石。

## 三、放置规则

### 3.1 总量限制与排他

- 不设"每名玩家最多 N 座塔"的硬性数量上限；塔总量由每局可获得的制造资源决定。
- 每局塔制造资源配额：通常全图产出的塔材料最多支持每名玩家制造 4 座塔；上限由掉落配额与来源数量控制，而不是玩家身上的计数。
- 保底规则：按正常流程（清理普通怪、开启宝箱、挖石），每名玩家至少能获得 2 座塔的制造资源；超过 2 座的部分需要争夺精英怪、暗黑宝箱或资源点补足。
- 分配限制：图纸、石头与对应宝石分散在多个来源且各有配额，任何单一来源都不能凑满 4 座塔，防止单一刷点量产。
- 塔有排他性：任意塔中心 40m 内不允许出现其他塔；放置预览用红色圈提示冲突。
- 塔可为同一类型，也可混合类型；同类型塔各自独立运作，效果不合并计算，但多塔覆盖可以形成口袋战术。

### 3.2 地形限制

- 只能放置在 NavMesh 可行走且未被海水淹没的地面。
- 不能放置在任务物品刷出点与玩家出生保护圈内；Boss 决战圈内允许放置。
- 海平面预警时，低地塔显示"即将被淹没"提示；塔被淹后沉没，直接损失。

### 3.3 放置流程

```
选择待放置的塔 → 打开放置预览（范围圈 + 排他圈 + 地面有效性）
  → 确认位置 → 1 秒放置读条（被打断不消耗）
  → 塔落地激活
```

### 3.4 升级体系
- 所有塔相关读条统一采用受击回退：合成、放置、升级被打断时进度回退，不归零。

- 塔只能升级一次：初级（基础属性）→ 强化（×2）。
- 升级需要站在塔附近操作，读条期间受击回退；升级消耗：
  - 初级 → 强化：250 金币 + 石头 ×4 + 对应宝石 ×1，8 秒读条。

- 升级只提升效果数值，范围与 40m 排他半径不变。
- 塔被摧毁或被海淹时直接损失，不返还任何材料。
- 已建造的塔可以分别升级，先升哪座、什么时候升是玩家中后期的核心资源决策；前期不建议随意放置或升级。
- 升级在塔合成开放后（任务结束 +5 分钟）可用；前期资源稀缺，塔主要留作后期 Boss 战战略资源。

## 四、塔类型与效果

### 4.1 共同规则

- 作用范围 40m（初版），效果随距离线性递减：效果倍率 = 1 - 距离/40，中心 100%，40m 处为 0。
- 范围圈固定显示 40m；衰减曲线后续可在 TowerDefinition 中配置。
- 塔被摧毁后，范围圈与效果立即消失。

### 4.2 攻击塔

| 项目 | 初版数值 |
| --- | --- |
| 目标 | 范围内小怪、对手玩家与 Boss |
| 伤害 | 30/次 |
| 攻击频率 | 1 次/秒 |
| 攻击距离 | 40m（随距离衰减） |
| 生命 | 800 |
| 特殊 | 止戈（全局休战）时不攻击对手玩家，仍攻击小怪；不攻击对手塔 |

- 目标选择：优先攻击最近敌人；受到攻击时优先反击攻击者。
- Boss 战阶段攻击塔会持续攻击 Boss；止戈开启时仍会攻击 Boss。
- 攻击塔的伤害/频率等数值只随塔等级（初级/强化）变化，不受阶段、止戈或其他因素调整。
- 攻击塔是玩家后期击杀 Boss 的主要辅助输出，不攻击对手塔。
- 攻击塔获取难度高于其他塔：力量宝石获取更稀缺，合成消耗石头翻倍。

### 4.3 生命塔

| 项目 | 初版数值 |
| --- | --- |
| 效果 | 范围内玩家每秒回复生命 |
| 中心回血 | 25 HP/s |
| 作用范围 | 40m（随距离衰减） |
| 生命 | 600 |

- 生命塔可以配置是否同时治疗阿蛮，初版默认治疗范围内所有友方单位。

### 4.4 Buff 塔

| 项目 | 初版数值 |
| --- | --- |
| 效果 | 范围内玩家攻击强化 + 受伤减免 |
| 中心数值 | 攻击 +20%，受到伤害 -15% |
| 作用范围 | 40m（随距离衰减） |
| 生命 | 600 |

- 当前数值体系没有独立防御属性，"受伤 -15%"作为防御加强的表现形式。

### 4.5 亲和度塔

| 项目 | 初版数值 |
| --- | --- |
| 效果 | 范围内玩家亲和度提升 |
| 中心数值 | +2 亲和/秒（上限 100） |
| 作用范围 | 40m（随距离衰减） |
| 生命 | 500 |

- 亲和度塔依赖《环境亲和度与双路线玩法》落地；亲和度系统未实现前，此塔先做占位或推迟开发。

## 五、止戈与破坏

### 5.1 止戈功能

- 复用现有"止戈"按钮：岛中岛任务结束前默认止戈且按钮不激活；任务结束后按钮激活，每名玩家只有 1 次发起机会。
- 开启止戈后，双方攻击塔不再攻击对手玩家，但继续攻击小怪与 Boss；与"结盟后不可互攻"规则保持一致。
- 止戈是全局休战状态：发起后双方不可互攻，双方攻击塔不再攻击对手玩家，但继续攻击小怪与 Boss。

### 5.2 破坏

- 塔有独立 HP，怪物、对手玩家、Boss（可配置）均可攻击塔。
- 塔 HP 归零后播放倒塌表现，清除范围圈与效果，直接损失。

## 六、与现有系统联动

### 6.1 背包与物品

- 建造图纸与对应宝石占用背包格且不可堆叠，石头走数值资源；宝石与装备共用库存，制造材料占用背包时，塔面板需要提示剩余容量。

### 6.2 掉落与商店

- 建造图纸进入怪物/宝箱掉落表，不占装备/金币预算；对应宝石复用装备宝石系统掉落；石头通过挖石获取。
- 对应宝石由装备宝石系统产出（宝箱/怪物/商店），图纸由精英怪/宝箱产出，保证中后期能稳定合成。
- 升级消耗金币、石头与对应宝石，是金币与宝石经济的重要回收口，缓解后期资源溢出。

### 6.3 海平面

- 塔只能放在未被淹没的地面；低地塔被淹没后直接沉没，强化塔投入同样损失。
- 淹没预警期间 HUD 显示受影响塔；塔被淹后直接沉没，直接损失。

### 6.4 环境亲和度

- 亲和度塔提升玩家亲和，自然型怪对高亲和玩家更友好。
- 攻击塔打自然型怪会持续扣亲和，攻击塔与自然区共生时会形成路线矛盾，强化"选路线"决策。

### 6.5 Boss 阶段

- 攻击塔会攻击 Boss，是玩家后期击杀 Boss 的主要辅助输出；塔可以放在 Boss 决战圈内。
- Boss 可以摧毁塔；Boss 阶段只有玩家主动放置的塔。

## 七、技术方案（Unity 实现草案）

### 7.1 组件划分

| 组件 | 职责 |
| --- | --- |
| TowerDefinition | ScriptableObject：类型、范围、衰减曲线、效果数值、HP、配方、投射物 |
| TowerUpgradeConfig | 初级/强化数值倍率、单次升级消耗、升级读条时长 |
| Tower | 塔实体：Owner、状态机、目标选择、效果 Tick、HP |
| TowerPlacementController | 放置预览、排他检测、地形检测、资源配额校验、放置读条 |
| TowerCraftController | 材料消耗、配方校验、合成读条、塔栏管理 |



### 7.2 数据配置

- TowerDefinition：towerType、range=40、falloffCurve、effectValue、maxHp、recipe、projectilePrefab。
- 材料表：itemId、类型、来源（怪物/宝箱）、掉落权重。

- TowerUpgradeConfig：等级倍率、升级消耗、读条时长。
- 资源点配置：树木/石块刷新点、采集耗时、重生时间。

### 7.3 事件接口

```csharp
public static event Action<Tower> OnTowerPlaced;
public static event Action<Tower> OnTowerDestroyed;
public static event Action<Tower> OnTowerRecycled;



public static event Action<bool> OnCeaseFireChanged;
```

### 7.4 开发节点拆分

| 阶段 | 内容 | 验证标准 |
| --- | --- | --- |
| 一 | 材料/配方数据 + 石头数值资源 | 挖石可计数，图纸/对应宝石可入背包，配方表正确 |
| 二 | 合成流程 | 消耗材料、2 秒读条、产出待放置的塔 |
| 三 | 放置流程 | 资源配额校验、40m 排他、地形/水域检测、预览正确 |
| 四 | 四类塔行为 + 单次升级 | 攻击/回血/Buff/亲和按距离衰减生效，初级→强化生效 |

| 五 | 破坏/止戈 | 塔可被摧毁，不返还材料；止戈后不打对手 |
| 六 | HUD + 整合测试 | 塔面板、范围圈、预警提示、整局流程无冲突 |

## 九、验收与测试目标

1. 建造图纸从怪物/宝箱正确掉落并进入背包；石头通过挖石按数值计数；对应宝石复用装备宝石系统。
2. 配方消耗正确（图纸 + 石头 + 对应宝石），合成成功生成待放置的塔。
3. 放置规则完整：资源配额限制（通常 4 座上限、保底 2 座）、40m 排他、水域/地形限制、Boss 决战圈可放。
4. 升级体系正确：初级 → 强化单次生效（×2），升级消耗与读条正确，投入不返还。
5. 塔可为同类型或混合类型；四类塔效果按距离衰减正确，止戈（全局休战）后攻击塔不攻击对手。
6. 攻击塔可攻击 Boss 且不攻击对手塔；数值只受升级影响；攻击塔获取难度高于其他塔。
7. 塔可被怪物/对手/Boss 攻击摧毁，不返还任何材料。

8. 海平面淹没低地塔后塔直接沉没，升级投入一并损失。
9. 塔系统与背包、掉落、亲和度、Boss 阶段联动无冲突。

## 十、开放问题

1. 挖石点的数量、采集耗时与重生节奏如何定？

2. 图纸/宝石占用背包后，是否需要为制造材料预留容量或扩容机制？
3. 多塔口袋战术若过强，是否需要后续数值压制（如同类塔效果递减）？
4. 强化塔被摧毁后是否给少量金币补偿，还是完全损失？

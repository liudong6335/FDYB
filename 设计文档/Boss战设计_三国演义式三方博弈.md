# 《分道扬镳》Boss 战设计文档

> 版本：v1.8（明确：判定快照不重算 / 玩家靠经验判断而非数值计算）
> 定位：1v1 海岛策略竞技的终局阶段
> 核心体验：**被迫合作，到必然对立；每一次结盟与翻脸，都在赌对方的判断**
> 文档边界：本文只保留玩法、策略和三方博弈；Boss 实现见《Boss 功能开发清单》，恶魔之心与胜负见《Endgame 终局系统》，环境与塔见各自专项文档

## 一、设计总纲

### 1.1 一句话核心

> **Boss 战不是两个人打一个木桩，而是三方（强者 / 弱者 / Boss）在 shrinking 地图上的三国演义。结盟是阶段性把三方博弈降维成双方博弈的工具，不作为即双输。**

### 1.2 三大设计支柱

| 支柱 | 含义 |
|------|------|
| **Boss 是唯一胜负目标** | 一切（塔、装备、杀怪、结盟）最终服务于"打 Boss"；无独立于 Boss 的胜负条件 |
| **Boss 随时间变强** | 时间不是朋友，是所有人的敌人；不作为即被 Boss 淘汰 |
| **结盟降维** | 用限时结盟把混乱的三方混战阶段性简化为清晰的两方对决 |

### 1.3 终局节奏（Boss 苏醒 → 结束，约 10 分钟）

```
Boss 苏醒 ──→ 被迫合作（满血→50%）──→ 裂痕（50%→25%）──→ 抉择（25%→10%）──→ 决战（10%→0%）──→ 心争夺（拾取 / 抢夺 / 交付）
                                              │                              │
                                         结盟窗口                        翻脸 / 倒计时
```

## 二、Boss 行为规则（第三方博弈方）

### 2.1 基础规则

1. **有目的移动**：Boss 每 5 秒获取一次存活玩家位置；有目标时追击，没有有效目标时前往最后已知位置，最后位置失效后前往安全区或战术驻守点，不进行无目的随机漫游。
2. **仇恨机制**：统一按仇恨总分排序选择目标，包含真实伤害、残血修正、圣物仇恨、追杀仇恨和塔仇恨；目标使用 5 秒快照。
3. **随时间变强**：每 30 秒提升一次属性（攻击 / 血量 / 技能频率），幅度约 5–10%。
4. **残血回血**：Weak / Normal 血量进入 20% 区间开始缓慢回血，10% 以下加速；Rage 禁用；
   迫使玩家做选择。
5. **求生判断**：Weak / Normal 使用独立的 5 秒求生快照。Weak 在生命低于 `35% × 0.9-1.1`
   且 20m 内非盟友总生命大于 Boss 当前生命 150% 时优先逃跑；Normal 仅在生命低于 10%
   且敌我生命比大于 200% 时逃跑，否则优先残血追击/击杀。首次跌破求生进入阈值时立即刷新快照，
   不等 5 秒周期。
6. **求生退出**：Weak 恢复到 40%、Normal 恢复到 30% 时结束求生；Rage 不逃跑、不结盟，
   只攻击和追击。第一槽 `Disabled` 时不进入求生；`Cooldown` 时可有限等待；最长求生时间到后
   强制结束并转入普通战斗或结盟。逃跑目标每秒重新评估一次，按威胁中心、NavMesh 落点、安全区
   和地形风险评分，只选择目标点并让 NavMeshAgent 处理路线；累计 2.5 秒无有效路径进度时强制退出。
7. **技能释放**：Boss 行为层只按状态请求技能槽，不依赖固定技能名。Demo 当前配置为
   `slot1=地震波`、`slot2=分身`、`slot3=嗜血狂暴`；Survive 或连续 3 秒未命中敌对玩家时请求
   `slot1`，普通战斗固定 `slot3` 优先于 `slot2`，第三槽随机池后置。“保命技能”只是体验描述，
   不是槽位类型。
8. **残血追击**：目标生命低于 30% 时，仇恨修正按 30%→10% 线性增加至 2000，
   有效追击距离从 20m 扩展到 40m；超过 40m 或恢复到 30% 以上后超出 20m 时立即退出追击。

> **变强、回血与求生共同构成全局倒计时**：合作越久越难打，拖延必然双输。

### 2.2 Boss 的"判断力"（结盟判定）

Boss 不是被动木桩，它有自己的生存判断：**每 10 秒进行一次局势判断；只有场上仍有 2 名玩家，且判断打不过二人联手时，才会考虑与其中一人结盟。**

**结盟绝对门禁**：Boss + 玩家结盟要求场上恰好有 2 名玩家存活。只剩 1 名或 0 名玩家时，
Boss 不结盟、不接受申请、不主动提议；若此前已有 Boss + 玩家结盟，则立即结束且不产生追杀仇恨。

| 情况 | Boss 反应 |
|------|----------|
| 只剩下 1 名存活玩家 | 绝对不结盟，直接进入 Boss 与该玩家的战斗 |
| Boss 判断自身战力明显占优 | 不结盟，直接进攻 |
| Boss 自评打不过二人联手，弱者状态尚可 | 进入结盟判定；主动发起结盟的概率上限约 20% |
| Boss 自评打不过二人联手，但弱者已残血 | 不结盟（Boss 不与残血者结盟），选择先击杀弱者 |
| 强者（战力高方）按结盟 | 与弱者规则一致：按 10 秒快照 + 当前对 Boss 仇恨归零条件判定 |
| 双方战力差 < 阈值（约 5%） | 视为势均力敌，适合走"玩家间结盟"路径 |

Boss 进入 `Rage（暴走）` 后直接禁用结盟路径：不逃跑、不结盟、不接受申请、不主动提议，只执行攻击、追击并请求配置为进攻用途的技能槽。

**判定周期（10 秒，局势判断）**：Boss 每 10 秒按当前状态做一次局势判断并保存快照；判断条件包括战力压制、残血排除和结盟资格。玩家申请结盟时不实时重算，以**上一次判断快照**作为依据（结果存在 0-10 秒延迟窗口）。快照固定使用到下一周期，不因残血 / 血量突变等极端变化重算——Boss 凭上次判断行事，这是设计意图。**玩家永久淘汰或 Boss 死亡时，事件结算后立即强制刷新一次快照。结盟状态本身是实时版本化子状态：结盟开始、结束或翻脸时立即更新并递增 `allianceVersion`，目标过滤不等待下一周期，但不重掷其他战略字段。**

**主动结盟概率限制**：Boss 判断打不过二人联手后，主动发起结盟的概率上限约 20%（初版建议，待实测）。Boss 作为想赢的第三方，很少主动帮人；结盟本身就是与虎谋皮。

**玩家申请不共用主动概率**：Boss 同意玩家结盟申请只依据 10 秒局势判断快照结果与残血排除；条件满足即同意，不经过 20% 主动发起概率。

**战力压制使用 70% 战力阈值**：两名玩家经 Boss 战力感知浮动后的 CombatPower（战斗力）都低于 Boss CombatPower（战斗力）的 70% 时，`BossPowerAdvantage（Boss 战力压制）= true`，Boss 不结盟。玩家可以把这种表现理解为 Boss 有“双杀”把握，但“双杀”不是系统功能。

**玩家无法精确读取 Boss 的感知战力**：Boss 读取玩家战力时使用固定的 `±5%` 随机浮动；玩家只能看到实际战力，因此无法完全反推出 Boss 当前使用的感知值。

**弱者 = Boss 可利用的刀；强者 = Boss 不需要的帮手。**

**设计意图：结盟是最后手段，不是稳定策略**：到 Boss 阶段，弱者若想赢基本只有赌结盟这一条路；因此真正重要的是前期把自身发展好，而不是依赖结盟翻盘。Boss 随时会反咬，弱者把赢的希望寄托在结盟上，本身就是高风险赌博。

### 2.3 战力计算体系：塔的计入规则

Boss 判定结盟、以及玩家自身评估"我能不能 solo"时，依据的实际战力为：**当前生命值总量 × 1 + 当前 DPS × 4 + 当前防御值 × 2 + 已放置且未销毁塔的当前攻击总和 × 1**。Boss 读取时再乘以随机 `0.95-1.05`，且随机值在当前 10 秒策略周期内固定。已放置且有效的塔计入；背包中未放置的塔不计入，结盟期间锁定不可放置，结盟结束后可继续放塔；结盟不会没收囤塔。

> **囤塔定义**：前期收集并合成塔，但不在战场上放下。囤塔不计入战力，结盟期间锁定不可放置，结盟结束后解锁；这是弱势玩家为 Boss 战翻盘的手段之一。

| 规则 | 含义 |
|------|------|
| **战力组成** | 攻击、生命、防御、已放置塔综合统计为一个数值 |
| **已放下的塔** | 计入战力 |
| **背包 / 未放置的塔** | **不计入战力**；结盟期间锁定不可放置，结盟结束后可继续放塔 |
| **被摧毁的塔** | 从战力中实时扣除 |

**设计意图：**

1. **战力是"当前能打的火力"，不是"你攒了多少"** —— 已放塔是当前战力的一部分，未放塔是预留资本。
2. **结盟不没收囤塔** —— 前期囤下的塔不被作废，弱者可以把塔留到结盟结束后用于风筝与翻盘。
3. **战力接近不代表一边倒** —— 战力是属性的综合评价；接近时胜负仍由属性结构、操作与时机决定。
4. **伪弱者边界** —— 囤塔压战力骗结盟只在双方装备接近时有意义；塔在战力中权重不高，囤塔对战力差影响有限，强者仍靠装备与技能拉开差距。

> 对玩家的信息呈现：战力对比界面显示综合战力数值（攻击 / 生命 / 防御 / 塔），并标注"背包中未放置塔不计入战力；结盟期间锁定，结盟结束后可放置"。

## 三、结盟系统（核心机制）

### 3.1 结盟路径

| 类型 | 发起方 | 确认方 | 生效条件 |
|------|--------|--------|----------|
| **弱者 + Boss** | 弱者申请 或 Boss 主动 | 对方确认/拒绝 | 申请：10 秒局势判断快照通过且当前对 Boss 仇恨归零即同意；主动：额外受 20% 概率限制（结盟不没收囤塔） |
| **强者 + Boss** | 强者申请或 Boss 主动 | 对方确认/拒绝 | 与弱者 + Boss 相同：10 秒快照通过 + 当前对 Boss 仇恨归零即同意 |
| **玩家 + 玩家** | 一方发起 | 另一方确认（各一次机会） | 双方都确认 |

**共同点：都有时间限制；时限到即强制解除并进入 PvP；结盟期间背包中未放置的塔锁定不可放置、不计入战力，结盟结束后可继续放塔。Boss 主动提议失败后，本次判定周期内不重复向同一玩家发起，下一周期重新计算。任一缔约玩家死亡时结盟立即结束；Boss 死亡时所有结盟立即结束，均不进入缓冲、不产生追杀仇恨。**

### 3.2 弱者 + Boss 结盟

#### 触发判定

**判定周期（每 10 秒）**：Boss 每 10 秒按当前状态计算一次结盟条件并保存快照，判定流程如下：

1. **绝对门禁**：存活玩家数必须恰好为 2；否则直接禁止结盟。
2. **战力压制**：两名玩家感知战力都低于 Boss 战力的 70% → 不结盟；否则进入下一步。
3. **弱者状态（残血排除）**：Boss 不与残血者结盟；目标残血 → 优先击杀，目标状态尚可 → 进入结盟判定。
4. **结盟资格**：检查当前对 Boss 仇恨是否归零、申请冷却和其他门槛。
5. **主动结盟概率限制（仅限 Boss 主动）**：未触发战力压制时，主动发起结盟的概率上限约 20%。玩家申请不经过该概率。

**结果采用上一次计算快照**：玩家申请结盟时，Boss 不实时重算，直接采用最近一次判定结果；Boss 也可在计算后主动向玩家发起结盟提议，玩家可接受或拒绝。

> 正式实现统一由 `BossAllianceController（Boss 结盟控制器）` 先计算 `BossAllianceAllowed`：
> 存活玩家数必须恰好为 2 且为非 Rage。只有该门禁为真时才计算战力压制。两名玩家感知战力
> 都低于 Boss 战力的 70% 时，`BossPowerAdvantage=true`，本周期禁止结盟。

#### 结盟生效期间（建议 15–20 秒）

- Boss 仇恨按总分排序：结盟期间盟友仇恨豁免，剩余玩家中总分最高者为结盟目标（通常为强者）
- 弱者只打强者，不强者即视为"盟友"
- 强者被 Boss + 弱者夹击
- 结盟期间 Boss 持续变强 / 回血 → 弱者必须速战速决
- **强者的反制**：强者需在中期预判弱者结盟意图，并通过技能配置强化保命（如第二技能选隐身、冰冻），用于躲过结盟爆发窗口或打断弱者输出

#### 结盟结束

- **Boss 优先追杀结盟过的弱者**（防止退回三方混战）
- 弱者需面对：强者可能还活着 + Boss 转头
- 弱者临死前可"引 Boss"至强者脸上，做最后一搏

#### 拒绝的惩罚

- Boss 短暂优先攻击该弱者（约 10 秒）暴露意图，强者获得反击窗口
- 弱者申请与 Boss 结盟有 30 秒冷却：申请失败（判定不通过 / 被拒 / 超时）后，下次申请需等冷却结束
- **弱者拒绝 Boss 主动结盟**：本次判定周期内 Boss 不再向该弱者重复提议，并可转向强者发起结盟提议，强者可接受或拒绝

#### 囤塔与"终局放塔"

**结盟不没收囤塔：前期囤下的塔不计入战力，结盟期间锁定不可放置；结盟结束后解锁，可继续放塔用于风筝与翻盘。**

**但弱者可以把"放塔"留到结盟结束之后：**

- 结盟期间（20 秒内）：弱者全力打强者；未放塔锁定不可放置，只能等结盟结束后再放塔风筝
- 结盟结束、Boss 转头追杀弱者时：弱者获得"临场放塔"窗口 —— 在 Boss 行进路径上放**攻击塔**输出、在风筝折返点放**生命塔**回血，把 Boss 引着绕圈

> **弱者赢的终局形态 = 被 Boss 追杀 + 用事先预留的塔风筝 Boss。**
> 预留的塔 = 弱者 solo 阶段的生存资本；预留得越多，风筝越久，翻盘概率越高。

**这构成了一个关键的前期决策**：弱者前期要不要**少放塔、攒着**？——攒着则结盟前战力低（Boss 更易判定通过），但结盟后 solo 资本少；全摆出来则战力高（判定风险）、但当场可打的火力多。**"预留多少塔"是弱者贯穿中后期的隐藏决策。**

### 3.3 玩家 + 玩家结盟

#### 触发条件

- 任意一方可自由发起申请（玩家之间无仇恨概念，申请不受仇恨限制）
- 每名玩家每局只有一次申请机会
- 一方发起 → 另一方 2–3 秒内确认（否则超时拒绝）

#### 结盟生效期间（建议 30–45 秒）

- 双方不能互相攻击
- 共同目标：击杀 Boss
- **Boss 残血时可翻脸**（高风险，见下）
- 任一玩家攻击对方 → 结盟立即破裂，攻击方获得结盟惩罚仇恨加成（3 秒缓冲后 +5000，30 秒内线性归零，计入总分），被攻击方短暂仇恨为 0（3 秒缓冲）

#### 结盟结束

- 倒计时 3 秒提示后 PvP 解锁
- 或直接由翻脸提前破裂
- Boss 已死 → 直接进入恶魔之心争夺

### 3.4 结盟时限设计原则

| 结盟类型 | 建议时长 | 设计意图 |
|----------|---------|----------|
| 弱者 + Boss | 15–20 秒 | 弱者必须全力爆发，强者需极限操作 |
| 玩家 + 玩家 | 30–45 秒 | 需足够时间合作击杀 Boss |

- 适用于 Boss + 玩家结盟：盟友对 Boss 造成真实伤害时，当前结盟时间缩短，Demo 暂定 -1 秒。
- 适用于 Boss + 玩家结盟：非盟友玩家对 Boss 造成真实伤害时，当前结盟时间延长，Demo 暂定 +1 秒。
- 调整按 `(allianceId, attackerOwnerId, gameSecondBucket)` 去重；同一玩家同秒内的多段伤害、DoT、分身、召唤物和塔命中只算一次。
- `attackerOwnerId` 使用最终归属者；后续同秒事件记录为 `rate_limited`，不累计调整。
- 时长先应用调整再钳位到 `[0, 基础时长]`；缩短到 0 时立即结束，后续事件不能再延长。
- 正常到期 T0 立即结束关系并刷新目标、求生、策略结盟区块和 AI 视角；T+3 惩罚仇恨生效时立即刷新目标仇恨排序。

## 四、双方各自的赢的路径

### 4.1 强者（战力高方）

> **发育 → 引 Boss → 合作消耗 → 在 Boss 残血前翻脸 → solo 收尾**

| 阶段 | 强者处境 | 理性选择 |
|------|---------|---------|
| Boss 满血 | 需弱者帮忙 | 忍，不翻脸 |
| Boss 50% | 弱者开始试探 | 继续忍，控制自身血量 |
| Boss 25% | 弱者持续施压 | 准备翻脸 |
| Boss 15% | 弱者没停手 | **必须翻脸** |
| Boss 10% | 自身血量 < 30% | 赌博式翻脸或认栽 |

**翻脸时机 = 核心决策**：太早 → solo 打不完；太晚 → 被弱者反杀。

### 4.2 弱者（战力低方）

> **推 Boss 进度 → 胁迫合作 → 持续压强者血量 → 残血时反杀或合作到底**

| 阶段 | 弱者处境 | 理性选择 |
|------|---------|---------|
| Boss 满血 | 不合作 = solo 必死 | 打 Boss（被迫合作） |
| Boss 50% | 强者血量在降 | 试探（打强者一下） |
| Boss 25% | 强者血量 < 我 | 持续压强者 |
| Boss 15% | 强者血量 < 40% | **全力打强者** |
| Boss 10% | 强者未翻脸 | 赌一把翻脸 |
| 结盟结束 / 强者死 | Boss 转头追杀 | **放预留塔，风筝 Boss** |

**弱者赢的方式不是正面击败，是借 Boss 为武器 + 残血收割 + 终局风筝：**

1. 中期少放塔、攒**预留塔**（囤塔不计战力、结盟不没收囤塔；结盟期间不能放置，结盟结束后解锁，留到 solo 阶段风筝最稳）
2. 结盟结束被 Boss 追杀 → 边跑边在 Boss 路径上放攻击塔 / 在折返点放生命塔
3. 用塔把 Boss 引着绕圈 → 持续输出 + 回血 → 拖到 Boss 可被击杀

> **注意设计一致性**：结盟不没收囤塔，囤下的塔始终保留；无论弱者走哪条结盟路径，"囤塔用于终局风筝"都在 solo 阶段可用。

### 4.3 势均力敌时

双方皆非"明确强/弱"，走**玩家间结盟**路径：

- 假装合作 → 等 Boss 残血 → 谁先动手谁暴露
- 用塔改变 DPS 对比 → 从势均力敌变为"我强" → 转强者路径
- 用走位 / 假动作骗对手先暴露 → 后发制人

> **赢的路径不是一个固定路线，是一个时机判断："我现在翻脸能赢吗？"**

## 五、三方混战（都不结盟时）

### 5.1 默认路径：被动合作

三方都不结盟 → 双方都在打 Boss（被动合作）→ Boss 变强 → 收敛：

| 分支 | 结果 |
|------|------|
| 双方 DPS 够 | Boss 被打死 → 恶魔之心争夺 → 交付方获胜 |
| DPS 不够 | Boss 越来越强 → 一方先残 → 翻脸或逃跑 |
| 有人提前翻脸 | 三方混战 → 有人先死 → 终局 |
| 双方都未能击杀并交付 | 两名玩家分别结算失败 |

### 5.2 未击杀 Boss 的玩家失败

> **实力差不多 + 都不结盟 = 双方都可能无法完成交付。**

系统不结算 `BossVictory（Boss 胜利）`，只分别结算每名 Player（玩家）的胜负。Boss（首领）在系统层只负责战斗行为、击杀玩家和产生终局事件。

## 六、决策场景写法（设计方法）

### 6.1 每个决策点需闭环

每个决策的后果必须在 **1–3 分钟内可见**，并能引出下一个决策。

### 6.2 决策卡模板

```
【时机】游戏第 X 分钟 / Boss 血量区间 / 某事件触发
【情境】玩家可见信息（Boss形态 / 双方血量 / 强化层数 / 对手行为）
【选择】A / B / C
【即时后果（1–3分钟内）】每个选择导致什么
【对后续的影响】后果如何改变下一个决策的输入
```

### 6.3 示例：弱者考虑与 Boss 结盟（Boss 30%）

> **情境**：Boss 第 2 层强化，回血中；你 55% 血，强者 40% 血；攻击塔已建 1 座。
>
> **选择**：
> - A：按结盟 → 赌 Boss 判定通过 → 20 秒内需击杀强者
> - B：继续打 Boss → 赌强者也不翻脸 → Boss 死 → 你赢
> - C：打强者 → 翻脸 → 赌自己能先杀强者
>
> **后果**：
> - A 成功 → 强者死 → 你 vs Boss（结盟时血量）→ 赢或死
> - A 失败（拒绝/超时）→ 暴露意图 → 强者反杀窗口
> - B → Boss 持续回血 → 可能双输
> - C → 被 Boss 集火 → 需强者也翻脸才成立

## 七、海平面与空间压缩

- Boss 苏醒前后海平面开始上升，持续压缩活动空间
- 把双方与 Boss 自然逼入同一区域，避免无限风筝
- Boss 按位置快照和最后已知位置向战场移动，并被海平面逐步压缩至峰顶决战圈，不会长期远离战场
- 被淹没区域：持续掉血 / 减速（具体规则待定）
- 高地是后期可靠阵地，低地塔需提前转移

> 海平面是**倒计时与压缩器**，不是独立机制；确保"不去 Boss 区域"不是可持久选项。

## 八、终局交接（不在本文展开）

> 恶魔之心掉落、拾取、易手、交付和胜负判定已移至《Endgame 终局系统》。

Boss 只发布 `BossDiedEvent` 并请求死亡掉落；恶魔之心由 `ILootDropService` 生成为 Item。
Endgame 负责心争夺阶段、双方死亡后的结束判断和最终结果。

## 十、开放问题与待办

| 优先级 | 问题 | 方向 |
|--------|------|------|
| P0 | Boss 变强幅度与间隔（5–10% / 30 秒） | 实测，以"合作 DPS 在 40% 前追不上"为目标 |
| P0 | 弱者+Boss 结盟时长（15/20 秒） | 强者解谜窗口 vs 弱者爆发窗口平衡 |
| P0 | 第一技能槽的范围目标过滤与恢复平衡 | 求生期间必须能推动 Weak / Normal 达到 40% / 30% 退出阈值，同时不能形成无限求生 |
| P0 | 求生最大时长与强制退出冷却 | 根据第一槽技能冷却调参，保证不会无限逃跑，也不会刚进入就被迫退出 |
| P1 | 逃跑目标权重、2m 位移阈值和 0.15 评分滞回 | 验证不会绕进第二个敌人、卡障碍或频繁折返 |
| P1 | 70% 战力压制阈值是否适配实际战力分布 | 只调整阈值，不增加独立判断脚本 |
| P0 | 弱者残血时 Boss 转击杀的边界 | 明确"几下能杀"的判定阈值，并给玩家可感知的反馈（Boss 转头） |
| P1 | Boss 结盟申请 30 秒冷却 | 实测失败惩罚与翻盘窗口平衡 |
| P1 | 强者 + Boss 结盟路径的条件与时长 | 已统一：与弱者 + Boss 相同，需实测确认平衡 |
| P1 | 10 秒判定快照的延迟窗口 | 快照结果与实况偏差在 0-10 秒，需保证玩家可读 |
| P1 | 玩家申请通过率的可读性 | 已定：不共用主动结盟 20% 概率；申请只看 10 秒快照 + 残血 + 仇恨资格。Boss 感知战力使用固定 ±5% 浮动 |
| P0 | 强者 solo 残血 Boss 成功率 | 翻脸时机应有 50–70% 成功区间 |
| P0 | 弱者+Boss 结盟后 Boss 剩余血量（40–60% 最佳） | 确保弱者 solo 有挑战但可行 |
| P0 | 玩家间结盟时长（30–45 秒） | 够打死 Boss 但不过于宽裕 |
| P1 | 强者反制手段（中期预判 + 保命技能配置：隐身 / 冰冻 / 位移） | 确保被结盟方不无解 |
| P1 | 海平面上升节奏 | 与 Boss 苏醒时机协调 |
| P2 | 单局时长与前期节奏 | 避免"全程对峙"僵局 |
| P1 | 囤塔数量与弱者 solo 风筝可行性 | 囤几座塔能让风筝"有挑战但可行"，需配合 Boss 移动速度与塔射程实测 |
| P1 | 结盟前战力是否被"Boss 实时读取" | 玩家临结盟前紧急放塔能否影响判定（建议：判定瞬间冻结战力快照，防钻空子） |
| P0 | 恶魔之心拾取读条（10 秒）与打断/抢夺节奏 | 实测拾取与抢夺的紧张感，避免心争夺变成尾刀或运气 |

## 十一、一句话总结

> **这不是两个人打一个 Boss，是三方在倒计时里轮流谈判、结盟、背叛。强者靠时机翻脸，弱者靠 Boss 翻盘、靠预留塔风筝，Boss 靠耐心收割——不作为的人，把胜利留给 Boss。塔要么在战场上发光，要么被囤到最后一刻；弱者把塔留到最后一刻，才换来 solo 时的一线生机。**

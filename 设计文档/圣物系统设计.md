# 圣物系统设计文档

## 一、设计定位

圣物是《分道扬镳》中**对抗 Boss 的核心生存资源**，定位为"与 Boss 单挑/结盟博弈的入场券"。

- **核心作用**：大幅抵消 Boss 伤害，使玩家具备 solo 或翻脸的资本
- **设计原则**："有没有圣物"比"圣物好坏"更影响策略；圣物状态的不对称，是 Boss 战前心理博弈的主要燃料
- **一句话**：没圣物 = 面对 Boss 基本裸奔，非合作路径几乎不可行；有圣物 = 获得 solo / 翻脸的选择权

---

## 二、核心规则一览

| 编号 | 规则 |
|------|------|
| 1 | 每名玩家**最多装备 1 个**圣物 |
| 2 | 圣物有两种：**日之石**（约 50% 减伤）、**月之石**（约 40% 减伤） |
| 3 | 圣物**仅抵消 Boss 伤害**，**不抵消玩家之间的攻击** |
| 4 | 圣物为**中期获取，通过合成获得**，非随机掉落 |
| 5 | 地图上共有**三套**合成材料 |
| 6 | 材料机制 = **零和 + 独立混合**（见第三章） |
| 7 | 已获得的材料可被**销毁**，销毁**无代价、瞬时** |
| 8 | 玩家**死亡时圣物必定掉落** |
| 9 | 掉落圣物**其他玩家可拾取** |
| 10 | **拾取 ≠ 更换**：拾取随时允许；主动替换装备**战斗中禁止** |
| 11 | **已装备物品（圣物）只可替换，不可卸载**，装备槽不可为空 |
| 12 | 圣物属**一次性装备**：合成后即绑定，不可拆解、不可退还材料 |

## 三、合成系统

### 3.1 合成公式

每个圣物由 **3 类材料**合成：

```
圣物 = 任意高级宝石 × 1  +  圣石 × 1  +  圣物卷轴 × 1
```

| 材料 | 说明 | 获取 |
|------|------|------|
| **任意高级宝石** | 宝石系统中已合成好的高级宝石（作为催化剂/核心） | 宝石合成线 |
| **圣石** | 圣物专属矿石，天然生成于地图中 | 探索/开采（地图资源点） |
| **圣物卷轴** | 分两种，决定合成出**日之石**还是**月之石** | 探索/精英怪掉落，见 3.3 |

> **说明**：高级宝石是"通用材料"，两种圣物共用同一份高级宝石池；真正区分圣物种类的是**卷轴**。

### 3.2 地图材料总量（三套）

地图上**共有三套**完整的合成材料（即最多可合成 3 个圣物）：

- 每套包含：若干圣石 + 若干卷轴（日/月）+ 对应高级宝石的原料
- 三套材料的**分布位置、守护强度、路线要求各不相同**

由于每名玩家最多持有 1 个圣物，**3 套材料 ≥ 2 名玩家的需求**，因此：
- 正常情况下双方**都能**获得圣物（一个 50%、一个 40%，或同为某一类）
- 但**销毁机制**（见 3.4）可能让总数 < 2

### 3.3 卷轴种类与对应圣物

| 卷轴 | 合成产物 | 减伤 |
|------|----------|------|
| **日影石卷轴** | 日之石 | ≈ 50% |
| **月影石卷轴** | 月之石 | ≈ 40% |

- 高级宝石 + 圣石 + **日影石卷轴** → 日之石
- 高级宝石 + 圣石 + **月影石卷轴** → 月之石
- 卷轴是**唯一决定圣物种类的材料**，因此卷轴的争夺 = 圣物种类的争夺

### 3.4 材料机制：零和 + 独立混合

- **独立部分**：三套材料各自位于不同区域/路线，玩家可独立收集其中一套，互不干扰
- **零和部分**：卷轴、圣石等**必要材料总量有限**；核心材料（如某类卷轴）全图数量受限

> 若 A 已合成圣物，又遇到多余材料，可选择**销毁**，阻止对手凑齐整套。

#### 销毁规则

- **触发**：玩家获得/持有某材料时，可主动销毁
- **代价**：**无**（瞬时、无读条、无惩罚）
- **效果**：该材料从游戏中移除；若它是某套的**必要材料**，则该套圣物**永久报废**
- **设计意图**：让持有优势者拥有"我不要，也不让你有"的破坏性策略，制造信息博弈

#### 销毁的信息博弈

- 销毁**默认静默**（地图上该材料消失，对手不知是被捡还是被毁）
- 对手可能**白跑一趟**去寻找已被销毁的必要材料 → 中期心理压力来源
- 可选：是否增加全局提示（待定，见开放问题）

### 3.5 合成时机与限制

- 合成在**合成界面**完成，需要玩家主动操作
- 合成**无读条**（保持简洁，不加额外复杂度）
- 合成**可在非战斗/战斗中均可进行**（合成本身非"更换装备"，属即时拾取类行为）——*具体战斗限制以 3.7 战斗规则为准*

## 四、圣物效果

### 4.1 减伤规则

- 圣物**仅作用于 Boss 造成的伤害**
- 玩家之间的攻击**不受圣物影响**（确保结盟/PvP 公平性）

| 圣物 | 对 Boss 伤害减免 |
|------|------------------|
| 日之石 | ≈ 50% |
| 月之石 | ≈ 40% |

**示例**（Boss DPS = 150/秒）：
- 无圣物 → 承受 150/秒（裸奔，极危险）
- 日之石 → 承受 75/秒
- 月之石 → 承受 90/秒

### 4.2 减伤差异的战略意义

10% 的差异在长时间 solo 中被放大（如 40 秒 solo，相差约 600 伤害），因此：
- **日之石持有者**底气更足，更倾向 solo / 激进翻脸
- **月之石持有者**相对更需要合作，或需搭配更多生命塔
- 双方圣物**不对称** → Boss 战前策略空间分化，是本系统的核心乐趣

## 五、掉落与拾取

### 5.1 死亡掉落

- 玩家**死亡时圣物必定掉落**（100%，无例外，玩家/Boss 击杀均触发）
- 掉落的圣物在地上可被**另一名玩家拾取**

### 5.2 拾取规则

| 拾取时背包状态 | 行为 | 战斗中是否允许 |
|----------------|------|----------------|
| **背包无圣物（装备槽空）** | 拾取 → **自动装备** | ✅ 允许 |
| **背包已有圣物** | 拾取 → **进入背包**，装备槽不变 | ✅ 允许 |

- 拾取**无读条、无代价**，瞬时完成
- 全图可配提示/播报（待定）

### 5.3 拾取 ≠ 更换（关键区分）

| 行为 | 战斗中 | 脱离战斗 |
|------|--------|----------|
| 拾取（背包空 → 自动装备） | ✅ 允许 | ✅ 允许 |
| 拾取（背包有 → 入背包） | ✅ 允许 | ✅ 允许 |
| **主动替换**（背包有 → 装备槽） | ❌ **禁止** | ✅ 允许 |

- **拾取**是即时响应（抓住机会），战斗中随时可做
- **主动替换**是战术决策，需要思考，**必须脱离战斗**

**示例**：A 死亡掉落圣物，B 正在战斗且背包为空 → B 可直接拾取并自动装备；若 B 已有圣物，拾取后进背包，但**战斗中不能换成装备槽的圣物**，须脱离战斗后才可替换。

## 六、装备与替换（通用装备规则）

> 本章节适用于**圣物**。（注：宝石遵循独立的宝石系统，不在此列。）

### 6.1 核心规则

- 每名玩家**最多装备 1 个**圣物（装备槽 × 1）
- **已装备的圣物只可替换，不可卸载**
- **装备槽不可为空**：一旦装备了圣物，就无法将其"取下留空"，只能通过替换换成另一个

### 6.2 替换流程

```
背包中已有圣物 B，装备槽中为圣物 A
  → 主动替换 → A 与 B 互换位置（A 回背包，B 装备上）
```

- 替换**瞬时、无冷却、无代价**
- 替换**仅在脱离战斗时可执行**

### 6.3 "不可卸载"的设计意图

- 玩家**无法主动裸奔**：一旦拥有圣物，就没有途径把它卸下
- 强化"圣物是入场券"的定位：踏上这条路就不能回头，**只能换、不能退**
- 避免玩家通过"临时卸下圣物诱导 Boss/对手"等钻空子行为

---

## 七、"战斗中"的判定（全局通用规则）

- **进入战斗**：玩家攻击他人 / 被他人攻击 → 立即进入战斗状态
- **脱离战斗**：持续 **3 秒**无任何攻击行为 → 脱离
- **适用范围**：该规则**从前期到后期完全一致**（抢材料、遭遇战、Boss 战均适用）

### 战斗中的装备约束

| 行为 | 战斗中 | 脱离战斗 |
|------|--------|----------|
| 拾取圣物（背包空 → 自动装备） | ✅ | ✅ |
| 拾取圣物（背包有 → 入背包） | ✅ | ✅ |
| 主动替换装备槽中的圣物 | ❌ | ✅ |
| 卸载/清空装备槽 | ❌（任何时候都禁止） | ❌（任何时候都禁止） |

## 八、与 Boss 战三条路径的关系

基于 Boss 血量 10000、Boss DPS 150、防御减伤 50% 的数值框架：

| 路径 | 圣物的角色 | 结论 |
|------|-----------|------|
| **合作（玩家间结盟）** | 双方均有圣物 → 存活更久，可在结盟窗口内输出 | 最优解，但考验信任 |
| **弱者 solo** | 圣物 = 唯一入场券；无圣物则被 Boss 快速击杀 | 有圣物 + 预留塔才有可行窗口 |
| **强者翻脸 solo** | 圣物决定能否扛过 Boss 追杀至击杀 | 高风险高回报，血量+圣物决定生死线 |

**核心结论**：圣物是"非合作路径"的必要（但不充分）条件——**没圣物 ≈ 必须合作**。

## 九、策略空间总结

| 局面 | 策略含义 |
|------|----------|
| A 有圣物，B 无 | A 可威胁 solo/翻脸；B 被迫合作 |
| A、B 圣物不同（50% vs 40%） | 双方均可 solo，但底气不同，不对称博弈 |
| 必要材料被销毁 | 该套报废，B 只能转向其余两套 |
| A 销毁 B 的核心材料后自己也未合成 | 双方皆无圣物 → 纯合作博弈，极度紧张 |
| A 死亡掉落 → B 拾取 | 圣物状态**动态翻转**，单局内可多次变化 |
| B 已有圣物时捡到更好的 | 需脱离战斗后才能主动替换 |

## 十、开放问题

1. **三套材料中"必要材料"的具体划分**：哪些为核心（唯一）、哪些为辅助（可多份）？
2. **高级宝石的"高级"标准**：与宝石系统的具体等级如何对应？
3. **销毁是否配全局提示**？静默（折磨）/ 提示（策略），待定
4. **圣石、卷轴的分布与守护强度**：是否与双路线（狩猎/开箱）绑定？
5. **合成是否可在战斗中执行**？目前倾向"合成=拾取类，允许"，需与战斗系统对齐确认
6. **死亡掉落物是否有保留时限 / 是否可重复拾取**？目前倾向"永久存在、一次拾取"
7. **脱离战斗的 3 秒阈值**是否合适，需实测
8. 圣物效果是否需要**最低持续时间/衰减机制**（如随时间减效），避免后期过于依赖单一物品

## 十一、设计原则回顾

1. **简洁优先**：销毁无代价、拾取无读条、替换无冷却——规则尽量少
2. **决策有重量**：不可卸载、战斗中不可更换 → 每次装备选择都不可逆（战斗中）
3. **不对称即乐趣**：圣物状态差异驱动 Boss 战前的心理博弈
4. **零和竞争**：三套材料 + 销毁 → 中期强制冲突
5. **只作用于 Boss**：确保 PvP/结盟的公平性
6. **掉落可转移**：死亡掉落 + 可拾取 → 单局内圣物归属可翻转
7. **拾取 ≠ 更换**：即时机会 vs 战术决策，战斗中有明确区分
8. **装备只可替换不可卸载**：强化"入场券"定位，杜绝钻空子
9. **战斗规则全局一致**：前期后期同一套判定，降低理解成本

# 装备与宝石系统设计

> 版本：v0.1（设计稿）
> 关联文档：《游戏机制总览》《技能系统设计》《领地与塔系统设计》《海岛与海平面上升机制设计》《道具系统设计》《背包数据契约》《宝箱开箱系统设计》
> 定位：把现有"打怪/开箱掉落整件装备 + 自动合成"改为"固定初始装备 + 宝石成长"，让单局成长集中在宝石获取与圣物合成

## 一、设计目标

1. 装备开局固定，游戏内不再掉落具体装备，降低装备随机落差。
2. 六装备位结构清晰：四件防具 + 武器 + 圣物。
3. 四件防具采用同类型宝石，形成套装并额外获得 10% 加成，鼓励统一路线。
4. 宝石覆盖生命、攻击、防御三条基础成长线，武器宝石单独强化武器。
5. 日之石/月之石作为圣物，通过合成获得并影响 Boss 阶段。

## 二、装备位结构

| 装备位 | 初始来源 | 可镶嵌 | 说明 |
| --- | --- | --- | --- |
| 肩甲 | 开局固定 | 生命/力量/防御宝石 | 四件防具规则 |
| 胸甲 | 开局固定 | 生命/力量/防御宝石 | 四件防具规则 |
| 护腕 | 开局固定 | 生命/力量/防御宝石 | 四件防具规则 |
| 鞋子 | 开局固定 | 生命/力量/防御宝石 | 四件防具规则 |
| 武器 | 开局固定 | 武器宝石 | 只镶嵌武器宝石 |
| 圣物 | 游戏内合成 | 日之石 / 月之石 | 合成获得，初版二选一 |

### 2.1 四件防具宝石规则

- 四件防具各有一个宝石槽，每件装备只能镶嵌 1 颗宝石；宝石按部位类型、属性类型与等级区分。
- 四件防具全部镶嵌同类型宝石时，该类型属性总值获得 +10% 额外加成（套装效果）。
- 混插不同类型宝石时，各件单独生效，无套装加成。
- 防具本身是固定初始装备，没有随机词条，属性完全由宝石决定。

### 2.2 武器与圣物

- 武器槽只镶嵌武器宝石，武器宝石提供攻击力。
- 圣物槽只镶嵌日之石或月之石：
  - 日之石：对 Boss/恶魔增伤（初版建议 +20%）。
  - 月之石：受伤减免（初版建议 -15%）。
- 日之石/月之石只能通过合成获得，不在掉落表中直接产出。
- 每名玩家只有 1 个圣物槽，日之石/月之石二选一，只能同时装备一枚。

## 三、宝石类型

| 宝石 | 装备位 | 属性 | 等级 | 来源 |
| --- | --- | --- | --- | --- |
| 生命宝石 | 四件防具 | 增加生命值 | 普通/高级/传说 | 宝箱/怪物/商店 |
| 力量宝石 | 四件防具 | 增加攻击力 | 普通/高级/传说 | 宝箱/怪物/商店 |
| 防御宝石 | 四件防具 | 增加防御力 | 普通/高级/传说 | 宝箱/怪物/商店 |
| 武器宝石 | 武器 | 增加攻击力 | 普通/高级/传说 | 精英怪/暗黑宝箱/商店 |
| 日之石 | 圣物槽 | 对 Boss/恶魔增伤 | 合成产物 | 合成 |
| 月之石 | 圣物槽 | 受伤减免 | 合成产物 | 合成 |
- 宝石同时具有部位类型与属性类型：例如"鞋子·生命宝石"只能镶入鞋子；部位类型决定可镶嵌装备位，属性类型决定加成。

### 3.1 防御属性

- 当前数值体系没有独立防御属性，宝石系统引入"防御力"。
- 防御公式待定：百分比减免或固定减伤二选一，见开放问题。
- 公式确定前，防御宝石只累计防御值，不参与伤害结算。

### 3.2 宝石等级

- 宝石等级：普通 / 高级 / 传说；等级决定宝石数值。
- 同部位、同属性、同等级的宝石凑够数量后自动合成为下一等级，并自动镶嵌到对应装备位；圣物仍为手动合成。
- 自动合成数量（初版建议 3 合 1）见开放问题。

## 四、获得与成长

### 4.1 宝石来源

- 生命/力量/防御宝石：木箱、铜箱、暗黑宝箱、普通怪、精英怪、商店。
- 武器宝石：精英怪、暗黑宝箱、商店，掉率高于普通宝石。
- 圣物：通过合成获得，材料来自精英怪与暗黑宝箱（具体材料表见开放问题）。
- 掉落改为宝石后，旧装备掉落表移除；装备不再进入掉落预算。

### 4.2 初始状态

- 开局四件防具与武器均为空槽。
- 岛中岛祭坛守点完成后，双方各获得 1 颗高级宝石（生命/力量/防御三选一），守点输出更高者优先选择。
- 宝石获取窗口：任务结束 0-5 分钟以掉落/镶嵌为主，+5 分钟后以自动合成与圣物合成为主。

### 4.3 镶嵌与替换

- 背包中点击宝石 → 选择装备位 → 镶嵌。
- 替换已有宝石时，被替换的宝石回到背包，可再次使用、出售或销毁。
- 宝石可卸下并重新镶嵌，卸下不消耗。

### 4.4 自动合成与背包

- 同部位、同属性、同等级宝石凑够数量后自动合成为下一等级宝石（初版建议 3 合 1）。
- 合成后的高级宝石自动镶嵌到对应装备位；若该位已有宝石，原宝石回到背包。
- 多余的宝石保存在背包；同类型同等级宝石不堆叠，每颗占 1 格。
- 背包中的宝石可以选择出售或销毁，出售价格见开放问题。

| 宝石 | 普通 | 高级 | 传说 |
| --- | --- | --- | --- |
| 生命宝石 | +100 HP | +250 HP | +500 HP |
| 力量宝石 | +10 攻击 | +25 攻击 | +50 攻击 |
| 防御宝石 | +8 防御 | +20 防御 | +40 防御 |
| 武器宝石 | +20 攻击 | +50 攻击 | +100 攻击 |

- 四件防具套装：同类型四颗宝石的属性总值 ×1.1。
- 防御减伤公式：待定（开放问题）。
- 日之石：对 Boss/恶魔增伤，具体数值待定。
- 月之石：受伤减免，具体数值待定。

## 六、与现有系统联动

### 6.1 掉落与背包

- 掉落预算中的装备项替换为宝石项；宝石进入背包。
- 同类型同等级宝石不堆叠，每颗占 1 格背包。

### 6.2 合成

- 移除旧装备自动合成逻辑；普通宝石按规则自动合成，圣物保留手动合成。
- 圣物合成沿用读条规则（2 秒，受击回退），材料不返还。

### 6.3 角色属性

- 角色面板新增六装备位展示、宝石属性、套装加成与防御减伤。
- 攻击/生命/防御最终属性 = 角色基础值 + 宝石加成（含套装加成）。

### 6.4 营地、技能与圣物

- 装备宝石、营地升级、技能升级形成三条并行成长线。
- 日之石/月之石在 Boss 阶段生效，与恶魔之心阶段联动。

## 七、技术方案（Unity 实现草案）

| 组件 | 职责 |
| --- | --- |
| GemDefinition | ScriptableObject：部位类型、属性类型、等级、数值、可镶嵌位 |
| EquipmentSlot | 装备位：肩甲/胸甲/护腕/鞋子/武器/圣物，当前宝石 |
| EquipmentSystem | 初始装备、镶嵌/卸下、套装加成、最终属性聚合 |
| GemItem | 背包物品：点击后进入镶嵌选择 |
| GemAutoCraftController | 同部位/属性/等级宝石自动合成与自动镶嵌 |
| RelicCraftController | 日之石/月之石合成 |
| DefenseStat | 防御减伤计算（公式待定），接入伤害结算流程 |

事件接口：

```csharp
public static event Action<GemDefinition> OnGemEquipped;
public static event Action OnSetBonusChanged;
public static event Action<PlayerStats> OnStatsChanged;
```

开发节点拆分：

| 阶段 | 内容 | 验证标准 |
| --- | --- | --- |
| 一 | 装备位数据 + 宝石数据 | 六装备位与宝石类型齐全 |
| 二 | 镶嵌/卸下与背包接入 | 宝石正确进出装备位 |
| 三 | 套装加成与属性聚合 | 四件同类型 +10% 生效 |

## 八、验收与测试目标

1. 六装备位开局固定，游戏内不再掉落具体装备。
2. 四件防具同类型宝石套装 +10% 正确生效，混插无加成。
3. 生命/力量/防御/武器宝石按部位、属性与等级正确计入角色面板。
4. 宝石可更换，被替换宝石回到背包；同类型同等级宝石不堆叠。
5. 自动合成正确：同部位/属性/等级宝石合成后自动镶嵌，原宝石回背包。
6. 日之石/月之石合成获得并可镶入唯一圣物槽；旧装备掉落与合成逻辑已移除。
7. 防御减伤公式确定后参与伤害结算。

## 九、开放问题

1. 自动合成数量是否采用 3 合 1？合成后的高级宝石是否总是自动镶嵌？
2. 防御采用百分比减免还是固定减伤？
3. 日之石/月之石的合成材料与具体数值如何定？
4. 宝石出售与销毁的收益如何定？
5. 传说之上是否还有更高宝石等级？

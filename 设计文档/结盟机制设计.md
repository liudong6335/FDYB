# 《分道扬镳》结盟机制设计

> 版本：v1.4（结盟正常到期刷新目标与仇恨快照）
> 定位：限时合作工具，把三方博弈阶段性降维为两方对决；所有仇恨与目标选择以总分排序为准，不使用硬锁定
> 关联文档：《Boss属性与行为设计》《Boss战设计_三国演义式三方博弈》《游戏机制总览》《塔防与塔系统设计》《技能系统设计》《环境亲和度与双路线玩法》《圣物系统设计》《AI数值测试与验收文档》

## 一、设计定位

- 结盟只在 Boss 苏醒后生效，Boss 苏醒前不存在结盟系统。
- Boss + 玩家结盟要求场上恰好有 2 名玩家存活；只剩 1 名或 0 名玩家时绝不结盟。
- 结盟是 Boss 战内的限时合作工具，取代不可逆止戈；结盟可翻脸。
- 核心体验：被迫合作，到必然对立；每一次结盟与翻脸都在赌对方判断。
- 怪物、Boss 与环境压力不受结盟影响；不作为即双输。
- 岛中岛任务结束前处于强制结盟（双方不可互攻）；任务结束后进入自由状态，玩家可自由申请结盟。
- 结盟符合 Boss 人格：打不过才结盟（怕死）、很少主动帮人（想赢）、结盟后追杀弱者（记仇）、不与残血或当前仍持有仇恨的玩家结盟（谨慎）。

## 二、结盟类型与路径

### 2.1 Boss + 玩家（强者 / 弱者统一规则）

| 项 | 规则 |
| --- | --- |
| 发起方 | 玩家申请 或 Boss 主动提议 |
| 确认方 | 对方确认 / 拒绝 |
| 生效条件 | 场上恰好 2 名玩家存活 + 玩家当前对 Boss 的仇恨总分为 0 + 10 秒局势判断快照通过（排除残血者） |
| Boss 主动限制 | 额外受约 20% 主动发起概率限制 |
| 建议时长 | 15-20 秒 |
| 申请冷却 | 玩家申请失败（判定不通过 / 被拒 / 超时）后 30 秒 |
| 距离 | 申请不受距离限制 |

- 强者与弱者走同一套规则，不再区分路径。
- 绝对门禁：`alivePlayerCount != 2` 时拒绝申请、停止主动提议并取消待确认请求；已有结盟立即结束，不产生追杀仇恨。
- Boss 主动提议失败后，本判定周期内不重复向同一玩家发起，下一周期重新计算。
- Boss + 玩家结盟中，盟友攻击 Boss 会缩短结盟时间（视为背叛）；非盟友玩家攻击 Boss 会延长结盟时间（Boss 认为其有用）。
- 时长调整只由对 Boss 的真实伤害触发；未命中、完全被护盾吸收、环境伤害和玩家间伤害不触发。
- 调整键固定为 `(allianceId, attackerOwnerId, gameSecondBucket)`。每个键最多触发一次，Demo 暂定盟友 -1 秒、非盟友 +1 秒。
- `attackerOwnerId` 使用最终归属者；玩家自己的召唤物、分塔或持续伤害都归到玩家，不允许同一玩家通过多个来源重复叠加。
- 同一游戏秒内后续伤害事件全部记录为 `rate_limited`，不修改结盟剩余时间。
- 先应用本次 delta 再钳位到 `[0, 基础时长]`；达到 0 时立即结束结盟，后续同秒事件不能再延长已结束的结盟。
- `allianceId` 变化后重新建立调整键，旧结盟的秒桶不得影响新结盟。

### 2.2 玩家 + 玩家

| 项 | 规则 |
| --- | --- |
| 发起 | 任意一方自由申请 |
| 仇恨门槛 | 玩家之间没有仇恨概念，申请不受仇恨限制 |
| 申请次数 | 每名玩家每局只有一次申请机会 |
| 确认 | 对方 2-3 秒内确认，超时拒绝 |
| 建议时长 | 30-45 秒 |
| 适用 | 双方战力接近时最常走此路径，但不是硬条件 |

## 三、Boss 判定流程（Boss + 玩家）

- 每 10 秒进行一次局势判断并保存快照；结果采用上一次快照（存在 0-10 秒延迟），不因残血、血量突变等极端变化重算。玩家永久淘汰或 Boss 死亡时，事件结算后立即强制刷新一次快照。
- 结盟状态是实时版本化子状态：开始、结束、翻脸或关系变化时立即更新 `allianceState / allianceTargetId` 并递增 `allianceVersion`；10 秒快照保存版本号，不重掷其他战略字段。
- 第一门禁：存活玩家数必须恰好为 2；否则 `BossAllianceAllowed=false`，不得进入后续判定。
- 局势判断由 `BossAllianceController（Boss 结盟控制器）` 计算 `BossPowerAdvantage（Boss 战力压制）`；当两名玩家感知战力都低于 Boss 战力的 70% 时，`BossPowerAdvantage=true`，本周期不结盟。
- Boss 处于 `Rage（暴走）` 时直接禁止结盟，不接受申请，也不主动提议。
- 判定顺序：
  1. 绝对门禁：存活玩家数必须恰好为 2 且非 Rage。
  2. 战力压制：两名玩家感知战力都低于 Boss 战力的 70% → 不结盟；否则进入下一步。
  3. 残血排除：目标已残血 → 不结盟，选择先击杀。
  4. 主动结盟概率（仅 Boss 主动）：上限约 20%；玩家申请不经过该概率。
  5. 仇恨门槛：申请时结盟对象对 Boss 的当前仇恨总分必须为 0；伤害仇恨、圣物仇恨和追杀仇恨都会阻止结盟，对应分项消散后资格自动恢复。
- `BossAllianceCanProceed` 表示结盟绝对门禁通过且未触发战力压制；`ShouldSeekAlliance` 是 Boss 主动提议路径在此基础上继续通过残血排除、仇恨门槛和主动概率后的输出。
- `BossBehaviorController` 只消费 `ShouldSeekAlliance`，不重新定义结盟判定流程。
- 实际战力 = 当前生命值 × 1 + 当前 DPS × 4 + 当前防御值 × 2 + 已放置且未销毁塔的当前攻击 × 1。Boss 读取值再乘随机 0.95-1.05，并在当前 10 秒策略周期内固定。
- 被攻击不会自动产生仇恨；仇恨只由主动攻击 / 造成伤害产生。

## 四、与仇恨体系的交互

### 4.1 总分排序（唯一目标选择规则）

- 所有候选目标按仇恨总分从高到低排序，取最高者；不使用仇恨类型优先级，不使用硬锁定。
- 仇恨值 = 滚动 5 秒窗口内对 Boss 造成的真实伤害 + 残血修正 + 圣物仇恨 + 结盟追杀仇恨；各加分项独立累加。
- 同分时按"血量更低 → 战力更低 → 更近"依次裁决。

### 4.2 结盟期间

- 缔约方之间互不攻击；盟友不可成为仇恨目标。
- 盟友被攻击到 10% 以下也不会触发残血上限打断，直到结盟结束。
- Boss + 玩家结盟：盟友仇恨豁免（不计入目标池），剩余玩家按仇恨总分排序选择结盟目标（通常为强者）。
- 玩家 + 玩家结盟：共同目标为击杀 Boss；任意一方攻击对方即翻脸。

### 4.3 结盟结束 / 翻脸

- T0 关系结束：立即递增 `allianceVersion`，前盟友移出盟友池并进入目标池；立即刷新目标快照、5 秒求生快照、10 秒策略中的结盟区块和 AI 可见状态，不重掷其他战略字段。
- T+3 惩罚仇恨生效：增加追杀仇恨并递增 `revengeHateVersion`，立即刷新目标仇恨快照和排序，不再次递增 `allianceVersion`。
- 结盟结束后，原盟友的仇恨：先进 3 秒缓冲（仇恨为 0），之后进入追杀仇恨。
- 追杀仇恨 = +5000，30 秒内线性归零；攻击 Boss 造成的伤害仇恨照常另算。
- 若原盟友仍 ≤10% 血：残血修正（最高 2000）与结盟惩罚仇恨（5000）是两个独立加分项，叠加计算。
- 玩家 + 玩家翻脸：攻击方获得结盟惩罚仇恨（3 秒缓冲后 +5000，30 秒归零，计入总分），被攻击方短暂仇恨为 0（3 秒缓冲）。
- 若存活玩家数降到 1，Boss + 玩家结盟立即结束，不进入 3 秒缓冲，也不产生追杀仇恨。

### 4.4 圣物仇恨

- 日之石 5000、月之石 4000；Boss 苏醒后 2 分钟内线性消散至 0。
- 归零后不再产生仇恨，持有者可正常与 Boss 结盟。
- 圣物仇恨计入结盟门槛：携带圣物且仇恨未归零时，不能与 Boss 结盟。

## 五、结盟生效期间的行为约束

- Boss + 玩家：Boss 只使用召唤 / 范围技能，锁链不作用于盟友。
- 攻击塔：不攻击对手玩家，不攻击对手塔；继续攻击小怪与 Boss。
- 未放置塔：结盟期间锁定不可放置、不计入战力；结盟结束后解锁。
- 负面技能（减速 / 眩晕等）：不对对手玩家生效，仅对小怪 / Boss 生效；自身增益不受影响。
- 怪物腐肉：结盟期间不可对对手使用。
- 结盟期间 Boss 持续变强 / 回血（弱者 + Boss 结盟的主要压力）。

## 六、结盟结束与终止

- 时限到 → T0 立即结束关系并刷新目标/求生/策略结盟区块/AI 视角 → 3 秒预警 → PvP 解锁。
- 正常到期同样进入 T+3 惩罚仇恨流程：增加 5000 追杀仇恨并立即刷新目标仇恨快照。
- 翻脸：任一缔约方攻击对方 → 立即破裂，进入 4.3 的惩罚仇恨。
- Boss 死亡 → 结束所有结盟并递增 allianceVersion → 直接进入恶魔之心争夺（拾取 10 秒读条，可打断 / 抢夺）。
- 弱者临死前可引 Boss 到强者脸上，做最后一搏。
- Boss 苏醒后玩家死亡即为永久淘汰，不进入回魂流程。任一玩家死亡时，立即结束其参与的所有玩家间结盟和 Boss + 玩家结盟，递增 allianceVersion，不进入 3 秒缓冲，也不产生追杀仇恨；同时刷新所有存活观察者的活动快照。

## 七、囤塔与终局风筝

- 结盟不没收囤塔：背包中未放置塔不计入战力、结盟期间锁定不可放置；结盟结束后解锁。
- 弱者可以把放塔留到结盟结束后：被 Boss 追杀时在路径上放攻击塔输出、在折返点放生命塔回血，风筝 Boss。
- 预留塔数量是弱者贯穿中后期的隐藏决策：少放塔 → 结盟前战力低、判定更易通过，但 solo 资本少；全摆 → 当场火力高但判定风险大。

## 九、测试验收

- 结盟成功率（Boss + 玩家、玩家 + 玩家分别统计）与双输率上限。
- 单人残局：仅剩 1 名玩家时，Boss 拒绝结盟申请、不主动提议；已有 Boss + 玩家结盟立即解除且不增加追杀仇恨。
- 死亡结束：任一玩家死亡立即解除其参与的全部结盟；Boss 死亡解除全部结盟；均不进入缓冲、不生成追杀仇恨，并立即刷新活动快照。
- 10 秒判定快照可复现；结果采用上一次快照。
- 时长调整高并发：同一玩家同一秒产生多段伤害、DoT、分身和塔命中时，只调整一次；其他事件标记 rate_limited。
- 正常到期刷新：T0 立即刷新目标/求生/结盟区块/AI 视角；T+3 增加追杀仇恨并立即刷新目标排序，历史快照不改写。
- 仇恨门槛：当前对 Boss 的仇恨总分归零才能与 Boss 结盟；玩家间结盟无仇恨门槛、每局一次申请机会。
- 结盟期间盟友仇恨豁免、互不攻击；残血上限打断对盟友无效。
- 翻脸惩罚：攻击方 +5000 计入总分，被攻击方 3 秒缓冲。
- 未放置塔锁定、结束后解锁；囤塔可支撑结盟后风筝。

## 十、开放问题

1. 玩家 + 玩家"每局一次申请机会"在超时 / 被拒后是否消耗机会。
2. 结盟期间被风筝时拆塔的归属：是否只拆结盟目标所属的塔，盟友塔豁免。
3. Boss 召唤类技能（当前示例为魔潮召唤）产生的小怪是否会攻击盟友（目标池是否排除盟友）。
4. 强者 + 玩家结盟的时长与平衡实测。
5. 15-20 / 30-45 秒时限、30 秒冷却、5000 惩罚仇恨等数值实测校准。

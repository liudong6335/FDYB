# 宝箱开箱系统设计

---

## 一、完整流程

```
游戏开始 → 宝箱已出现在场景中
  ├→ 宝箱自带 UGUIFloatingHealthBar（满血 100%，默认隐藏）
  └→ 宝箱未读条，isOpening = false

玩家点击宝箱（未被其他玩家锁定）
  └→ 自动导航到 interactDistance（0.5m）范围内
       └→ StartOpening()
            ├→ UGUIFloatingHealthBar 显示（0%→100%)
            ├→ 受击（被动） → progress -= hitPenalty（不过位到负数）
            ├→ 移动/攻击怪物/放技能（主动操作） → CancelOpening() → progress 归零
            └→ progress >= readTime → 读条完成
                 ├→ UGUIFloatingHealthBar 保持 100%（已满）
                 └→ OpenChest()

OpenChest()
  ├→ 切换视觉 closedVisual → openVisual
  ├→ 生成物品模型（1 件装备 或 10 个金币）在 itemSpawnPoint
  └→ 启动 FlyItemsToPlayer() 协程

FlyItemsToPlayer()
  ├→ 所有物品模型依次飞向玩家（追踪移动中玩家位置）
  │   ├→ 每个到达 → InventoryManager.AddItem / AddGold
  │   └→ 每个到达 → 模型 Destroy
  └→ 全部飞完 → Destroy(gameObject)
       ├→ UGUIFloatingHealthBar 随对象销毁
       └→ 宝箱消失
```

---

## 二、状态与打断矩阵

| 操作 | 效果 | 原因 |
|------|------|------|
| 被怪物攻击 | progress -= 0.8s，不归零 | 被动惩罚 |
| WASD 移动 | CancelOpening() → progress 归零 | 主动离开 |
| 点击地面走路 | CancelOpening() → progress 归零 | 切换目标 |
| 点击正在读条的宝箱 | 无影响 | 已在开这个箱 |
| 点击攻击怪物 | CancelOpening() → progress 归零 | 进入战斗 |
| 按 Q 放技能 | CancelOpening() → progress 归零 | 执行动作 |
| 玩家在读条中被打死 | CancelOpening() | 死亡自动中断 |
| 玩家 B 来点正在读条的箱 | 忽略（isOpening = true） | 先到先得 |

## 三、进度条 UGUIFloatingHealthBar

### 归属
- 宝箱预制体的子对象
- 宝箱实例化时它就存在
- 默认隐藏（barPanel.SetActive(false)）

### 显示规则
```
读条未开始      → 隐藏
读条中 0%~99%   → 显示，fillAmount = progress / readTime
读条完成 100%   → 保持显示，fillAmount = 1
物品飞行中      → 保持显示，fillAmount = 1
物品飞完        → 宝箱 Destroy → bar 一起销毁
```

### 颜色
- 50% 以下：红色 → 黄色渐变（同 UGUIFloatingHealthBar 的 mid/low 逻辑）
- 50% 以上：黄色 → 绿色渐变

---

## 四、读条进度计算

```
progress = max(0, progress + deltaTime - hitPenalty × hitThisFrame)
```

- `hitThisFrame`：每帧检测玩家血量是否下降
- `hitPenalty` = 0.8s（可配置）
- `readTime` = 木箱 3s / 铜箱 5s（可配置）

### 基础参数示例

| 情况 | 用时 | 说明 |
|------|------|------|
| 不受干扰 | 3s | 纯读条时间 |
| 被击中 1 次 | 3.8s | 回退一次 |
| 被击中 3 次 | 5.4s | 回退三次 |
| 被击中 + 移动打断 | 归零重来 | 主动操作优先 |

## 五、物品飞行

### 单件装备
```
开箱 → 装备模型出现在 itemSpawnPoint
     → 飞向玩家（0.5s）
     → 到达 → InventoryManager.AddItem → 模型销毁
     → 宝箱 Destroy
```

### 10 个金币
```
开箱 → 10 个金币模型出现在 itemSpawnPoint（堆叠或阵列）
     → 第 1 个飞向玩家（0.2s 后第 2 个）
     → 第 1 个到达 → InventoryManager.AddGold(总金币量 / 10) → 模型销毁
     → 第 2 个飞... → 间隔 0.2s
     → 第 10 个到达 → 宝箱 Destroy
```

- 飞行总耗时：约 0.5s（装备）或 10×0.2s + 单个 0.5s ≈ 2.5s（金币）
- 飞行期间玩家可自由移动，物品追踪玩家位置
- 玩家中途死亡 → 物品飞到尸体位置 → 入包（复活后仍有）

## 六、宝箱 Inspector 配置

```
Chest Settings（已有）
  ├─ Chest Type           → Wooden / Copper

Opening（新增）
  ├─ Read Time            → 基础读条时长（木箱 3s，铜箱 5s）
  ├─ Hit Penalty          → 每次受击回退（默认 0.8s）
  └─ Interact Distance    → 触发读条距离（0.5m）

Item Display（新增）
  ├─ Item Spawn Point     → 物品出现位置（箱口附近 Transform）
  ├─ Item Fly Speed       → 飞行速度（默认 5）
  ├─ Open Animation Delay → 开箱后物品延迟出现（默认 0.3s）
  └─ Gold Visual Prefab   → 金币飞行模型

Visual（已有）
  ├─ Closed Visual        → 关闭状态模型
  └─ Open Visual          → 开启状态模型
```

## 七、制作步骤

### 第一步：TreasureChest 状态机改造

| 子步骤 | 内容 |
|--------|------|
| 1.1 | 新增读条状态枚举：Idle / Reading / OpeningItems / ItemFlying / Complete |
| 1.2 | 新增 `readTime`、`hitPenalty`、`interactDistance`、`itemSpawnPoint`、`itemFlySpeed`、`goldVisualPrefab` 字段 |
| 1.3 | 修改 `StartOpening()`：初始 progress=0，显示进度条，isOpening=true |
| 1.4 | 修改 `Update()`：读条中检测受击、检测主动操作打断、累加 progress |
| 1.5 | 添加 `CancelOpening()`：进度归零、隐藏进度条 |

### 第二步：受击与打断检测

| 子步骤 | 内容 |
|--------|------|
| 2.1 | `Update()` 中：读条时跟踪 `openingPlayer` 的 Health.CurrentHealth 下降 → 减 progress |
| 2.2 | `Update()` 中：检测玩家移动/攻击 → 调用 CancelOpening |

### 第三步：开箱与物品飞行

| 子步骤 | 内容 |
|--------|------|
| 3.1 | `OpenChest()`：切换视觉、生成物品模型、启动飞行协程 |
| 3.2 | `FlyItemsToPlayer()` 协程：依次飞向玩家、调用 InventoryManager.AddItem/AddGold、销毁模型 |
| 3.3 | 全部飞完后：Destroy(gameObject) |

### 第四步：进度条 UI

| 子步骤 | 内容 |
|--------|------|
| 4.1 | 宝箱预制体已有 UGUIFloatingHealthBar 子对象（初始隐藏） |
| 4.2 | 读条开始 → 显示并设置 provider |
| 4.3 | `Update()` 更新 fillAmount = progress / readTime |
| 4.4 | 读条结束/物品飞行时 fillAmount = 1 |
| 4.5 | 宝箱 Destroy → bar 随父对象销毁 |

### 第五步：宝箱读条超出范围检测

| 子步骤 | 内容 |
|--------|------|
| 5.1 | `Update()` 中检测 openingPlayer 与宝箱距离 > interactDistance + 1m → CancelOpening |

### 第六步：宝箱间隔设置（各 Chest Type）

| 子步骤 | 内容 |
|--------|------|
| 6.1 | 在场景中的 baoxiang 预制体上配置 readTime / hitPenalty / goldVisualPrefab 等 |

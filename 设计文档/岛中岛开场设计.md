# 岛中岛开场设计

> 版本：v0.1（设计稿）
> 关联文档：《游戏机制总览》《NPC 任务区域系统设计》《海岛与海平面上升机制设计》《领地与塔系统设计》《技能系统设计》《装备与宝石系统设计》《环境亲和度与双路线玩法》
> 定位：替代原护送阶段，用"祭坛守点 + 小 Boss + 奖励分配"完成开场教学、共同防御与开局资源发放

## 一、流程总览

```
对话阿蛮 → 三人传送到岛中岛
  → 阿蛮激活祭坛（0:30 开始）
  → 幽灵/牛怪波次 + 深渊幽灵将军
  → 守护成功 → 祭坛升起、石桥出现
  → 奖励结算（高级宝石选择 / Boss 掉落）
  → 阿蛮留在祭坛成为回血点
  → 任务结束后 3 分钟海平面开始上涨，正式进入探索阶段
```

## 二、场地与门控

- 岛中岛：主岛内湖/泻湖中央的高台，战斗区域直径 40-60 米。
- 开场被深水围困，祭坛激活前没有出口。
- 祭坛激活完成后，祭坛升起并浮现石桥连接主岛；石桥保持高水位，后续不被淹没。
- 空间门控替代规则门控：祭坛完成前无法离开，不需要额外的"开箱锁定"解释。

## 三、怪物设计

### 3.1 幽灵（恶魔系智慧型怪）

- 恶魔系智慧型怪，恶魔派来，攻击阿蛮，必须清；不受亲和度影响。
- 击杀不扣亲和度，不影响 Boss 苏醒。
- 掉落少量木头/石头，归属击杀者，掉率低。

### 3.2 牛怪（自然型怪）

- 只骚扰/攻击玩家，不攻击阿蛮，可选击杀。
- 击杀亲和 -5/只，全场最多 3 只，总扣减上限 -15。
- 掉落概率高于幽灵（木头/石头/金币/低概率普通宝石），但湖心岛阶段不出技能书。
- 首次击杀显示"击杀牛怪，亲和 -5"教学反馈。

### 3.3 波次安排

| 波次 | 内容 |
| --- | --- |
| 第一波 | 4-6 只幽灵（教学向） |
| 第二波 | 6-8 只幽灵 + 1-2 只牛怪 |
| 第三波 | 8-10 只幽灵 + 1-2 只牛怪 + 深渊幽灵将军 |

## 四、湖心岛宝箱

- 3 个木箱 + 1 个铜箱，开场即可开启。
- 木箱 3s / 铜箱 5s 读条，受击回退。
- 掉落：金币/木头/石头/低概率普通宝石；不出技能书。
- 开箱不掉亲和，与杀牛怪形成"稳定资源 vs 高风险资源"的选择。

## 五、小 Boss：深渊幽灵将军

- 第三波中段出现，祭坛剩余 60-90 秒时登场。
- 行为：优先攻击阿蛮；受玩家攻击后切换仇恨，3 秒无输出回到阿蛮。
- 技能：近战横扫（可走位躲）、召唤 2 只小幽灵、缓慢移动。
- 数值：HP 2000-2500，攻击 60-80/次，攻击间隔 2 秒。
- 击杀不扣亲和；Boss 苏醒在岛中岛任务结束后开始倒计时。
- 存在期间祭坛进度暂停，迫使双方处理。
- 失败条件：阿蛮死亡 = 双方失败。

## 六、奖励分配

### 6.1 祭坛守点完成奖励

- 双方各从阿蛮处获得 1 颗高级宝石（生命/力量/防御三选一）。
- 守点输出更高者优先选择；输出口径：对 Boss + 幽灵的总伤害。
- 直接弹出选择 UI，15 秒超时自动随机；另一方从剩余项选择，同样超时随机。

### 6.2 Boss 掉落

- 固定掉落 2 本不同技能书 + 1 颗普通宝石。
- 参与门槛：对 Boss 造成 ≥20% 最大生命值伤害。
- 最后一击者获得普通宝石，并优先选择 1 本技能书；另一本自动归达到门槛的另一方。
- 未达门槛的一方不能获得技能书；无人认领的技能书消失。
- 湖心岛阶段技能书唯一来源 = Boss；牛怪、宝箱、祭坛奖励均不出技能书。

### 6.3 输出统计

- 口径：对 Boss + 幽灵造成的总伤害。
- 结算 UI 显示双方伤害百分比，规则透明。
### 6.4 结盟规则

- 岛中岛任务结束前处于结盟状态，双方不可互攻。
- 任务结束后双方进入自由状态（PvP 开启），可互相攻击。
- 结盟是 Boss 战内的限时合作工具，规则见《Boss战设计_三国演义式三方博弈》：玩家间结盟需一方发起、对方确认，期间不可互攻，攻击对方即破裂并可翻脸。
- 结盟期间双方未放置的塔锁定不可放置、不计入战力；结盟结束后解锁。
- 怪物、Boss 与环境压力不受结盟影响。

## 七、阿蛮定位

- 祭坛守点完成后，阿蛮留在升起的祭坛上，成为固定回血点；Boss 被击杀并拾取恶魔之心后，阿蛮赶来收取，交付作为终局过场动画。
- 不可被玩家攻击；仍可被怪物/Boss 威胁，死亡判双方失败（仅关键事件触发）。
- 保留主动治疗与被动光环，光环改为常驻小范围回血（8 米内 20-30 HP/s，数值待定）。

## 八、时间轴

| 时间 | 事件 |
| --- | --- |
| 0:00-0:30 | 对话、传送岛中岛 |
| 0:30-2:30 | 祭坛守点：幽灵/牛怪波次 + 小 Boss |
| 2:30-3:00 | 结算表现 + 奖励选择 + 石桥浮现 |
| 任务结束 +3 分钟 | 海平面开始上涨，进入探索阶段 |
| 任务结束 0-5 分钟 | 选址建营地、建造建筑，宝石与基础技能成长 |
| 任务结束 +5 分钟 | 防御塔建造解锁 |
| 任务结束 +10 分钟 | Boss 苏醒倒计时结束 |
| 任务结束 +15 分钟 | 山腰低段淹没，只余峰顶决战圈 |
| 对局结束（约 25:00） | 最终决战 |

> 阶段门控：任务结束 0-5 分钟选址建营地与基础技能；+5 分钟开放防御塔；+10 分钟 Boss 苏醒；+15 分钟进入峰顶决战圈。

## 九、与现有系统联动

- 技能：湖心岛阶段技能书仅 Boss 掉落；探索阶段恢复宝箱/怪物/商店。
- 宝石：祭坛完成发放高级宝石；Boss 发放普通宝石。
- 领地资源：营地建造消耗金币与补给；防御塔材料（图纸/石头/对应宝石）按《塔防与塔系统设计》获取。
- 领地弱化为补给点/防御点：营地提供回血与休整，防御塔按《塔防与塔系统设计》用图纸 + 石头 + 对应宝石合成，无独立胜负线。
- 亲和度：牛怪教学扣减；幽灵无惩罚。
- 玩家死亡：岛中岛阶段复用《玩家机制设计》的回魂契约；符合条件时以 50% 生命值在死亡地点回魂，不额外设置回魂点。
- Boss 苏醒：岛中岛任务结束后开始 10 分钟倒计时，不受开场击杀影响。

## 十、验收与测试目标

1. 对话后正确传送岛中岛，祭坛激活前无出口。
2. 波次按时间刷出，幽灵攻击阿蛮、牛怪只骚扰玩家。
3. 小 Boss 仇恨切换、召唤、横扫正常；存在期间祭坛进度暂停。
4. 祭坛完成后祭坛升起、石桥出现，阿蛮变为回血点。
5. 奖励 UI 弹出、优先选择、超时随机分配正确。
6. 20% 门槛、最后一击、技能书归属判定正确；牛怪/宝箱不出技能书。
7. 海平面在任务结束后 3 分钟开始上涨；Boss 苏醒在任务结束后开始 10 分钟倒计时。
8. 原护送区域链不再锁阶段，QuestManager 接入守点流程。
9. 岛中岛玩家死亡时，回魂申请、防具宝石销毁、半血原地回魂和无观战规则与全局一致。

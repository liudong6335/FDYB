# 技能系统设计

> 版本：v0.2（技能包与技能槽职责分离）
> 关联文档：《游戏机制总览》《环境亲和度与双路线玩法》《领地与塔系统设计》《海岛与海平面上升机制设计》《道具系统设计》《背包数据契约》《宝箱开箱系统设计》
> 定位：把当前单一的 Q 加速技能扩展为"天赋技能 + 技能书学习"的双槽技能卡系统，让玩家在单局内按掉落和局势自由构建技能组合

## 一、设计目标

1. 提供两个技能槽：天赋槽固定携带角色天赋，学习槽通过技能书自由更换。
2. 技能书成为宝箱/怪物掉落的新资源，让"开箱/打怪 → 技能构建"成为独立决策线。
3. 允许两个槽携带相同技能，形成"双加速 / 双治疗"等极端构建，同时用独立冷却控制强度。
4. 技能效果统一打包为技能卡（SkillCard，以下简称技能包），实际冷却、优先级和触发策略由技能槽绑定负责，后续新增技能、调整数值、接入状态框架成本低。
5. 与海平面、塔防、结盟等系统联动，技能不只是战斗数值，也参与地图博弈。
6. 技能书升级体系：同技能书优先升级学习槽技能，配合固定产出点保证双方成长下限。

## 二、技能槽规则

### 2.1 槽位结构

- 每名玩家 2 个技能槽：
  - 天赋槽：自动携带角色天赋技能，不可更换、不可卸下。
  - 学习槽：初始为空，通过使用技能书获得技能，可被后续技能书覆盖。
- 两个槽可以是相同技能；相同技能在双槽内各自独立冷却，可分别释放。
- 快捷键：天赋槽 Q，学习槽 E（或 1/2，可配置）；UI 技能栏显示两个槽位、冷却与就绪状态。

### 2.2 天赋技能

- 天赋技能随角色绑定，预设在角色 Prefab 内；开局自动进入天赋槽，不可更换。
- 初版天赋示例：

| 天赋 | 效果 | 冷却 | 说明 |
| --- | --- | --- | --- |
| 加速 | 3 秒 +50% 移速 | 20s | 替换当前 Q 加速 |
| 加血 | 立即回复 200 HP | 25s | 或改为短吟唱 |
| 减速 | 命中敌人 2 秒 -30% 移速 | 15s | 单体投射物 |
| 眩晕 | 命中敌人 1 秒眩晕 | 30s | 单体投射物 |

- 更多天赋随角色扩展；玩家选角/角色卡流程见《游戏机制总览》主菜单规划。

### 2.3 技能书与学习槽

- 技能书通过开宝箱、打怪和商店获得；不参与合成，直接获得。湖心岛开场阶段技能书唯一来源为守点小 Boss。
- 背包中点击技能书 → 消耗该书 → 对应技能写入学习槽。
- 学习槽已有技能且使用同技能书时，优先升级该技能；使用不同技能书则直接覆盖，不做二次确认，被覆盖技能无返还。
- 技能书技能池包含所有角色天赋技能 + 其他扩展技能（护盾、净化、狂暴等）。

### 2.4 施放与打断

- 每个技能槽独立冷却，双槽相同技能互不影响。
- 实际冷却时间、冷却开始时机、触发策略、优先级和斩杀参数属于技能槽绑定（SkillSlotBinding），不写入技能包。
- 同一个技能包挂载到不同技能槽时允许使用不同冷却和触发策略。
- 技能施法前摇/吟唱被打断时，进度回退而非归零，与开箱读条一致。
- 使用技能书（0.5s 读条）同样采用受击回退。

### 2.5 技能升级

- 技能等级上限 3 级：Lv1 基础 → Lv2 ×1.3 → Lv3 ×1.6；冷却不变，只提升数值或持续时间。
- 学习槽已有技能 X 时，使用 X 技能书会升级 X，而不是覆盖。
- 满级后再使用同技能书不再升级，书籍可保留或出售（金币转化作为后续可选）。
- 天赋槽技能不参与升级；升级只作用于学习槽。
- 技能成长窗口：任务结束 0-5 分钟为基础获取期，+5 分钟后进入升级高峰。

## 三、技能卡与技能池

### 3.1 技能包（SkillCard）

SkillCard 是 ScriptableObject，只描述“技能是什么、命中后发生什么”，不保存角色或槽位的运行时状态：

```text
skillId
displayName
icon
description
skillType: Instant / Projectile / Area / Aura
targetMode: Self / Enemy / Point / Multiple
castTime
recoveryTime
duration
range
damage
effectRefs
projectilePrefab
maxLevel
levelMultipliers
```

SkillCard 明确不负责：

- 当前槽位编号。
- 冷却时长和剩余冷却。
- 优先级、触发条件和斩杀优先开关。
- 当前目标、施放锁和运行时状态。

### 3.2 技能槽绑定（SkillSlotBinding）

每个角色通过技能槽绑定决定“这个技能在这个槽位如何使用”：

```text
slotId
displayKey
skillCard         // 固定绑定；使用技能池的槽可留空
skillPoolId       // 可选，使用技能池的槽配置
cooldown
cooldownStartPolicy: CastStart / Commit / PostRecovery
priority
triggerPolicy
lethalPriorityEnabled
lethalTolerance
maxCharges
```

- 实际冷却 = 当前 SkillSlotBinding.cooldown。
- 同一个 SkillCard 可以挂载到多个槽位，并分别配置不同冷却。
- 两个玩家槽携带相同技能时，各自拥有独立的 SkillSlotRuntime，冷却不会互相影响。
- Boss 使用技能槽而不是固定技能：行为层只输出 `slotId` 和状态原因，SkillSlotBinding 决定该槽
  绑定的 SkillCard、冷却、优先级和触发策略。
- Boss `slotId=1` 是第一技能槽，在 Weak / Normal 的 Survive 状态请求；并在 Engage / Chase / Rage 中连续 3 秒未命中敌对玩家时作为追击受阻的战术例外请求。绑定内容可配置。
  “保命技能”只是体验描述，不是槽位类型或技能机制。
- `slotId=2/3` 是后续技能槽；当前 Demo 临时绑定分身和嗜血狂暴，第三槽随机池后置。Boss 只在 Engage / Chase / Rage 中按 `slot3 > slot2` 请求，槽位 Ready 后由 `triggerPolicy` 判断效果条件是否允许施放。
- 效果状态属于技能系统：`slot2` 是否已有存活分身、`slot3` 是否已有同一增益、目标是否有效、距离是否满足，都由 `SkillSlotBinding.triggerPolicy`、`SkillCard` 和状态系统判断；Boss 不读取这些状态。
- Boss 每次行为决策最多提交一个 `slotId`；普通战斗槽不排队，Ready 只表示可请求，不代表无条件释放。
- 早期暂定技能卡仍是未来候选，但不再是当前 Demo 的 Boss 槽位默认配置。
- 若只配置 SkillCard 而没有 SkillSlotBinding，技能不可施放并输出配置错误。

### 3.3 初版技能池

| 技能 | 类型 | 目标 | 效果 | 推荐槽位冷却 |
| --- | --- | --- | --- | --- |
| 加速 | 即时 | 自身 | 3s +50% 移速 | 20s |
| 加血 | 即时 | 自身 | 回复 200 HP | 25s |
| 减速 | 投射物 | 敌人 | 2s -30% 移速 | 15s |
| 眩晕 | 投射物 | 敌人 | 1s 眩晕 | 30s |
| 护盾 | 即时 | 自身 | 5s 吸收 200 伤害 | 30s |
| 净化 | 即时 | 自身 | 清除负面效果，2s 免疫减速/眩晕 | 35s |
| 狂暴 | 即时 | 自身 | 5s 攻击 +30% | 40s |

- 技能书可以开出重复技能：学习槽为空时可学习同天赋技能形成双槽同技能；学习槽已有同技能时则用于升级。

### 3.3.1 Boss Demo 技能卡（当前临时配置）

技能卡只描述效果、目标和持续时间；冷却、冷却开始时机和触发策略由 Boss 的技能槽绑定配置。

| 技能 | 目标 | 效果 | 持续时间 |
| --- | --- | --- | --- |
| 地震波 | 40m 范围内的敌对目标 | 移动速度和攻击速度降低 30%；盟友不受影响 | 5 秒 |
| 分身 | 自身召唤 | 以施放瞬间属性快照生成分身；移动速度、攻击速度与 Boss 一致，生命为施放时当前生命的 20%，攻击力为 Boss 施放时攻击力的 50%，可被击杀 | 最长 8 秒 |
| 嗜血狂暴 | 自身 | 移动速度和攻击速度提高 50%，其他属性不变 | 8 秒 |

补充规则：

- 地震波是否作用于塔、召唤物和其他非玩家单位，由 `targetMode` 与阵营过滤配置决定。
- 分身死亡或达到最长持续时间后消失；属性使用施放瞬间快照，是否继承后续阶段强化待定。
- 嗜血狂暴只影响移动速度和普攻攻击频率，不影响技能 CD、施法前摇和技能恢复时间。
- 分身槽的 `triggerPolicy` 负责检查是否已有存活分身；不满足时由技能系统拒绝本次请求。
- 嗜血狂暴槽的 `triggerPolicy` 负责检查增益是否已经生效；不满足时由技能系统拒绝本次请求。
- 上述三张卡是当前 Demo 配置，可以替换；Boss 行为层仍只请求 `slotId`。

### 3.4 统一执行闭环

所有角色共用以下流程：

```text
请求施放
→ 收集 Ready 技能槽
→ 判断 triggerPolicy
→ 计算斩杀候选和普通优先级
→ 解析目标并锁定
→ Casting
→ Commit
→ Resolving
→ Recovering
→ 按 cooldownStartPolicy 开始该技能槽冷却
→ 写事件和日志
```

- 全局只允许一个技能处于 Casting / Resolving / Recovering。
- SkillCard 在 Commit 时只负责产生效果；SkillSlotRuntime 负责开始冷却。
- 单体技能默认在 Casting 开始时锁定目标；目标死亡、不可选或关系变化时取消。
- 范围、自身和地点技能在 Commit 时锁定位置或自身状态。
- Commit 时重新检查距离、目标和动作锁；预览结果只用于决策，不直接造成伤害。
- 打断结果由 SkillSlotBinding.cooldownStartPolicy 决定是否进入冷却。

## 四、技能书掉落与背包

### 4.1 掉落

- 宝箱按配置概率掉技能书；普通怪概率掉，精英怪必掉；商店可刷新出售技能书。
- 技能书走掉落预算中的独立权重，不占用装备/金币/塔材料预算。
- 掉落时向持有者广播技能书名称，不显示具体数值。
- 固定产出点：湖心岛开场阶段仅小 Boss 掉落技能书（2 本，20% 门槛分配）；探索阶段由商店固定出售、精英/暗黑宝箱保底，怪物与普通宝箱随机掉落。

### 4.2 背包与使用

- 技能书是背包物品，允许堆叠（需扩展 ItemType 与堆叠规则），使用一次消耗 1 本。
- 使用技能书：0.5 秒读条（受击回退）→ 消耗书籍 → 学习槽为空则学习；学习槽已有同技能则升级；已有不同技能则覆盖。
- 使用技能书不会打断移动，但会打断开箱读条（与现有"主动操作打断开箱"一致）。
- 技能书可出售，商店也可刷新出售；价格与限购规则见开放问题。

## 五、与现有系统联动

### 5.1 输入与 UI

- 替换 PlayerInputController 中单一的 Q 加速逻辑，改为 SkillSystem 双槽输入。
- 技能栏 UI：天赋槽 + 学习槽、冷却遮罩、就绪高亮、技能书覆盖提示。

### 5.2 状态效果框架

- 减速复用/扩展 DamageSlowEffect；眩晕、护盾、净化需要通用状态效果框架（现有缺口）。
- 建议 SkillCard 效果统一为 StatusEffect 数据，技能只负责触发。

### 5.3 海平面与地图

- 加速用于撤离浅水/洪水窗口；净化用于解除海水减速；减速/眩晕用于拖住对手错过撤离或资源点争夺。
- 区域类技能不能投放到已淹没区域；自身类技能不受影响。

### 5.4 领地与塔

- 加血/护盾提升守营地与决战圈续航；加速帮助玩家在营地与资源点之间快速支援。
- 学习槽覆盖技能不影响已建造的建筑与营地。

### 5.5 结盟联动

- 结盟期间，减速/眩晕等负面技能不对对手玩家生效，仅对小怪/Boss 生效。
- 自身增益类技能不受结盟影响。

### 5.6 Boss 阶段

- 眩晕/减速可用于 Boss 关键技能打断（若 Boss 设计支持）；加血/护盾是后期续航辅助。
- Boss 阶段开始后技能书停止掉落（或保持极低概率）。
- Boss 第一技能槽的 SkillCard 由 BossDefinition / SkillSlotBinding 配置，Survive 或连续 3 秒未命中敌对玩家时请求该槽。
- Boss 行为层只请求技能槽；槽位绑定内容变化时不得要求修改 Boss 状态机。
- Boss 第三槽启用随机技能池时必须使用 encounter seed，固定 seed 下结果可复现。
- Boss 第一槽为 `Disabled` 时，Survive 不进入或立即退出；为 `Cooldown` 时等待到 `Ready` 后请求一次，
  不进行每帧轮询；达到 `maxSurviveDuration` 后强制退出并进入行为层兜底。
- Boss 第一槽的 3 秒未命中判定只统计 Boss 本体对敌对玩家的命中；分身、召唤物、塔和非敌对目标不计入。
- Boss 第二、第三槽在 `SeekAlliance` 中不请求；未来防御型或增益型槽位通过 `triggerPolicy` 单独配置。

## 六、技术方案（Unity 实现草案）

### 6.1 组件划分

| 组件 | 职责 |
| --- | --- |
| SkillCard | ScriptableObject：技能效果、目标、施法、范围和表现引用，不保存冷却和运行时状态 |
| SkillSlotBinding | 槽位静态配置：SkillCard、实际冷却、优先级、触发策略和斩杀参数 |
| SkillSlotRuntime | 槽位运行时状态：冷却剩余、充能、当前 SkillCard、是否就绪 |
| SkillSystem | 双槽管理、冷却计时、输入入口、事件广播 |
| SkillCastController | 全局施放状态、施放锁、前摇、结算、恢复和打断 |
| SkillBookItem | 技能书物品：引用 SkillCard，点击使用并写入学习槽 |
| SkillEffectApplier | 将 SkillCard 效果应用到目标（回血/移速/眩晕/护盾等） |
| SkillBarUI | 技能栏显示、冷却遮罩、就绪状态 |

### 6.2 事件接口

```csharp
public static event Action<int, SkillCard> OnSkillChanged;      // 槽位, 新技能
public static event Action<int> OnSkillCast;                    // 槽位
public static event Action<int, float, float> OnCooldownChanged; // 槽位, 剩余, 总长
```

### 6.3 开发节点拆分

| 阶段 | 内容 | 验证标准 |
| --- | --- | --- |
| 一 | SkillCard 效果包 + SkillSlotBinding + 技能池 | 技能效果可复用，同一技能可挂到不同槽位并使用不同冷却 |
| 二 | SkillSystem 双槽 + 输入/UI | Q/E 施放、各槽独立冷却、就绪状态正确 |
| 三 | 技能书物品 + 背包使用/覆盖/升级 | 学习、覆盖、升级行为正确 |
| 四 | 技能效果（加速/加血/减速/眩晕等） | 效果、目标、持续、打断正确 |
| 五 | 掉落接入 + 固定产出点 | 固定点/随机掉书数量达标 |
| 六 | 结盟/海平面/塔防联动 + 整合测试 | 负面技能结盟期间不生效，撤离/守塔可用 |

## 八、验收与测试目标

1. 天赋槽自动携带且不可更换；学习槽初始为空。
2. 学习槽为空时使用技能书学习；同技能书升级；不同技能书覆盖、无二次确认。
3. 双槽相同技能各自独立冷却，可分别施放；实际冷却和触发策略来自 SkillSlotBinding，而不是 SkillCard。
4. 各技能效果、冷却、投射物/目标判定正确；施法前摇/吟唱受击回退、不归零。
5. 湖心岛阶段技能书只来自小 Boss；探索阶段从宝箱/怪物/商店正确获得，背包可堆叠，使用后消耗 1 本。
6. 结盟期间减速/眩晕不对对手生效，增益技能不受影响。
7. 技能栏 UI 显示槽位、冷却、就绪状态。
8. 技能与海平面撤离、塔防守塔、Boss 阶段联动无冲突。
9. 技能升级至 Lv3 后同书不再升级，可保留/出售；固定产出点按表发放。

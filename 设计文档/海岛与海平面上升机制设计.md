# 海岛与海平面上升机制设计

> 版本：v0.1（设计稿）
> 关联文档：《游戏机制总览》《环境亲和度与双路线玩法》《NPC 任务区域系统设计》《开发节点拆分》
> 定位：正式 1v1 地图的环境机制，以"海平面随时间上升"形成全局时间压力，可活动区域逐步收缩到峰顶决战圈

## 一、设计目标

1. 提供全局时间压力：单局 25 分钟内潮水持续上涨，玩家必须在"发育 / 探索 / 抢占高地"之间取舍。
2. 与阶段节奏联动：淹没节点对齐岛中岛任务、探索、Boss 苏醒阶段，前期低压、中后期持续压缩。
3. 制造对抗与信息博弈：低地通道关闭会改变路线，迟滞对手可以使其错过撤离窗口。
4. 保证可读与公平：每次淹没都有预警、水位提示与安全区反馈，不做突然致死。
5. 服务世界观：封禁之地是一座正在沉没的海岛，Boss 所在的峰顶是最终决战圈。

## 二、海岛地图设定

### 2.1 岛屿分层

| 地形带 | 海拔 | 主要玩法 | 资源 | 淹没节点 |
| --- | --- | --- | --- | --- |
| 低地海滩 | 0-2m | 可选资源区 | 少量木箱 | 任务结束 +3 分钟 |
| 低地区（渔村 / B区） | 2-6m | 开箱流主场、商店 | 木箱、铜箱、暗黑箱、自然型怪 | 任务结束 +6 分钟 |
| 中坡地（猎场 / A区） | 6-12m | 狩猎流主场、精英 | 精英怪、圣物、智慧型怪 | 任务结束 +9-12 分钟 |
| 高地区（山腰） | 12-20m | 安全通道、救援点 | 少量宝箱、补给 | 任务结束 +12-15 分钟 |
| 峰顶（祭坛） | 20m+ | Boss 战、恶魔之心交付 | 决战圈 | 不淹没 |

### 2.2 关键地点

- 低地海滩：可选资源区，不再是出生点；玩家从岛中岛祭坛开始。
- 渔村（B区）：低地资源区，宝箱密集、商店与自然型怪集中，先被淹没。
- 猎场（A区）：中坡战斗区，精英怪与圣物集中，稍后被淹没。
- 断桥：低路与高路的汇合口，淹没后低路关闭，玩家只能走高路。
- 半山祭坛：商店与补给点，低地商店关闭后的替代位置。
- 峰顶祭坛：Boss 战场，海平面无法淹没；恶魔之心由阿蛮赶来收取（交付为过场动画）。

### 2.3 路线结构

- 低路（沿海/渔村）：宝箱多、路程短，但 7:00 后逐段关闭，适合前期开箱发育。
- 高路（猎场/山腰）：路程长、战斗多，安全窗口更久，适合中后期转线。
- 探索路线：岛中岛祭坛 → 断桥 → B区/A区 → 半山 → 峰顶；断桥被淹后低路关闭，改走高路。

## 三、海平面上升规则

### 3.1 潮汐曲线

- 初始海平面 0m，最终 16m，单局 25 分钟。
- 节点建议（可与最终阶段时间线统一调整）：

| 时间 | 水位 | 淹没内容 | 阶段 |
| --- | --- | --- | --- |
| 岛中岛任务结束前 | 0m | 守点期，水位不涨 | 祭坛守点 |
| 任务结束 +3 分钟 | 2m | 低地海滩 | 探索 |
| 任务结束 +6 分钟 | 6m | 渔村 / B区低地 | 探索（Boss 苏醒前） |
| 任务结束 +9 分钟 | 10m | 断桥、A/B 连接通道 | 探索末期 |
| 任务结束 +12 分钟 | 14m | 中坡猎场下半段 | Boss 战 |
| 任务结束 +15 分钟 | 16m | 山腰低段 | 决战收缩 |
| 之后至对局结束 | 16m 维持 | 仅峰顶决战圈 | 最终决战 |

- 阶段门控：任务结束 0-5 分钟选址建营地与基础技能；+5 分钟开放营地升级；+10 分钟 Boss 苏醒；+15 分钟进入峰顶决战圈。
- 水位在节点之间持续上升，但"区域淹没"只在节点触发，避免地形每帧变化。
- 推荐曲线：前期缓、中后期加速；具体用线性 + 事件节点还是动画曲线，见开放问题。

### 3.2 淹没事件

- 每个 FloodEvent 配置：触发时间、目标水位、淹没区域列表、预警时长。
- 默认预警 30 秒：HUD 显示"XX 区 30 秒后淹没"，安全区地图同步闪烁。
- 淹没后区域不可行走：NavMesh 封路 + 水面判定生效，区域被标记为 Flooded。
- 同一区域只淹一次，水位继续上涨只影响视觉，不重复触发事件。

### 3.3 涉水规则

| 状态 | 判定 | 效果 |
| --- | --- | --- |
| 浅水 | 水线低于角色腰部（<1m） | 移速 -30%，可主动撤离 |
| 深水 | 区域已淹没或水线 >=1m | 30 HP/s 持续伤害，移速加成无效 |
| 阿蛮 | 驻守岛中岛祭坛，不进深水 | 祭坛安全，不受涨潮影响 |

- 深水不立即致死：1000 HP 下约 33 秒，配合 30 秒预警足够逃生。
- 撤离窗口结束后仍留在深水中的玩家会阵亡，死亡后复活到最近安全高地。

## 四、与现有系统联动

### 4.1 祭坛与探索区域

- QuestArea 绑定 FloodZone（或配置 groundLevel），区域被淹后不再是任务目标。
- 保护规则：岛中岛任务期间水位不涨；探索阶段资源点被淹前 60 秒不触发，避免软锁。
- 阿蛮驻守祭坛，不参与导航；断桥被淹后玩家改走高路。

### 4.2 资源与掉落

- 预警期间宝箱与掉落物仍可开/可拾取；区域淹没后未处理的资源"沉没"，不可再获取。
- 低地商店在任务结束 +6 分钟前关闭并迁移到半山祭坛；未迁移视为被淹没消失。
- 怪物按海拔向高地迁移，低地怪物会聚集在通道口，形成"水位 + 怪物 + 对手"的堵截局面。

### 4.3 环境亲和度与双路线

- B区（开箱流主场）先淹，开箱流必须限时收割并提前转线。
- A区（狩猎流主场）后淹，狩猎流获得更长安全时间，但中后期同样向峰顶收缩。
- 海平面成为"换线时机"：低路关闭后对手位置可预测，读线与拦截空间变大。

### 4.4 投喂道具与海平面

- 怪物腐肉可在低地/撤离窗口使用，拖住对手错过涨潮撤离。
- 被病毒感染的肉喂怪后，目标自然怪会追击对手，可用于低地撤离窗口拖延对手。
- 投喂道具不与地形绑定，区域淹没不额外影响道具。

### 4.5 Boss 与第三阶段

- Boss 战固定在峰顶祭坛，海平面不淹没决战圈。
- v1 不做"击退入水"效果，避免环境秒杀；强制位移不会把玩家推出安全圈。
- 恶魔之心由阿蛮赶来收取，交付作为终局过场动画；峰顶 Boss 战场不受海平面影响。

## 五、技术方案（Unity 实现草案）

### 5.1 组件划分

| 组件 | 职责 |
| --- | --- |
| SeaLevelController | 单例/场景组件：推进水位、触发 FloodEvent、广播事件 |
| FloodZone | 区域配置：groundLevel、bounds、预警时长、NavMesh 封路、Flooded 标记 |
| WaterSurface | 水面视觉：跟随海平面 y，仅表现，不参与判定 |
| SafeAreaHUD | 潮汐倒计时、下一淹没区域、安全区比例、深水警示 |
| 实体避水 | 玩家/怪物/阿蛮在目标被淹后重采样最近安全点（NavMesh.SamplePosition） |

### 5.2 数据配置

- FloodEvent：timeSeconds、targetLevel、zoneIds[]、warningSeconds。
- FloodZone：zoneId、groundLevel、bounds、navObstacle、floodedMaterial。
- 数值走 ScriptableObject 或场景 Inspector，便于平衡迭代。

### 5.3 事件接口

```csharp
public static event Action<float> OnSeaLevelChanged;
public static event Action<FloodZone> OnZoneWarning;
public static event Action<FloodZone> OnZoneFlooded;
public static event Action<float> OnSafeAreaRatioChanged;
```

### 5.4 NavMesh 方案

- v1：预烘焙 + 每个 FloodZone 挂 NavMeshObstacle，淹没时启用封路。
- 不做逐帧动态 Carve，避免性能开销。
- 实体被困时重采样最近安全点，保证玩家、怪物、阿蛮不会被永久卡在深水。

### 5.5 开发节点拆分

| 阶段 | 内容 | 验证标准 |
| --- | --- | --- |
| 一 | FloodEvent/FloodZone 数据 + SeaLevelController 水位推进 | 水位按节点推进，事件时间准确 |
| 二 | 水面视觉 + 淹没封路 | 区域按时封路，水面跟随海平面 |
| 三 | 实体避水（玩家伤害、怪物迁移、祭坛安全） | 无实体卡在深水，撤离后自动找安全点 |
| 四 | 资源沉没 + 商店迁移 | 宝箱/掉落沉没规则正确，商店按时迁移 |
| 五 | HUD 预警 + 安全区 + 整合测试 | 预警可见、安全区正确、整局收束到峰顶 |

## 六、数值建议（初版）

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| 单局时长 | 25 分钟 | 与阶段门控时间轴对齐 |
| 初始 / 最终水位 | 0m / 16m | 峰顶 20m+ 保持安全 |
| 预警时长 | 30 秒 | 可调 20-45 秒 |
| 浅水减速 | -30% | 可撤退 |
| 深水伤害 | 30 HP/s | 1000 HP 约 33 秒致死 |
| 安全区比例 | 100% → 8% | 任务结束 +15 分钟后只剩峰顶决战圈 |
| 阿蛮改路耗时 | +20-30% | 断桥被淹后的代价 |

## 七、验收与测试目标

1. 水位按曲线推进，所有 FloodEvent 在正确时间触发。
2. 淹没区域提前 30 秒预警，安全区提示准确。
3. 玩家、怪物、阿蛮不会卡在深水区，撤离后能自动回到安全点。
4. 岛中岛任务期间水位不涨；探索阶段资源点被淹前保留 60 秒预警。
5. 宝箱、掉落物、商店沉没/迁移规则正确。
6. 峰顶决战圈不受海平面影响，恶魔之心交付判定正常。
7. 整局结束时可活动区域只剩峰顶。

## 八、开放问题

1. 潮汐采用"线性上升 + 事件节点"还是"动画曲线整体平滑"？
2. 浅水是否允许长期停留，还是 30 秒后自动转深水？
3. 低地商店被淹后是"消失"还是"半山祭坛直接出现新商店"？
4. 沉没宝箱/掉落物是否允许"漂到岸边"回收，还是永久损失？
5. 是否允许玩家通过圣物/机关延缓某次涨潮？
6. 安全区提示是否接入小地图（当前小地图仅占位）？

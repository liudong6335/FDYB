# 《分道扬镳》Boss 战设计文档

> 版本：v1.8（明确：判定快照不重算 / 玩家靠经验判断而非数值计算）
> 定位：1v1 海岛策略竞技的终局阶段
> 核心体验：**被迫合作，到必然对立；每一次结盟与翻脸，都在赌对方的判断**

---

## 一、设计总纲

### 1.1 一句话核心

> **Boss 战不是两个人打一个木桩，而是三方（强者 / 弱者 / Boss）在 shrinking 地图上的三国演义。结盟是阶段性把三方博弈降维成双方博弈的工具，不作为即双输。**

### 1.2 三大设计支柱

| 支柱 | 含义 |
|------|------|
| **Boss 是唯一胜负目标** | 一切（塔、装备、杀怪、结盟）最终服务于"打 Boss"；无独立于 Boss 的胜负条件 |
| **Boss 随时间变强** | 时间不是朋友，是所有人的敌人；不作为即被 Boss 淘汰 |
| **结盟降维** | 用限时结盟把混乱的三方混战阶段性简化为清晰的两方对决 |

### 1.3 终局节奏（Boss 苏醒 → 结束，约 10 分钟）

```
Boss 苏醒 ──→ 被迫合作（满血→50%）──→ 裂痕（50%→25%）──→ 抉择（25%→10%）──→ 决战（10%→0%）──→ 心争夺（拾取 / 抢夺 / 交付）
                                              │                              │
                                         结盟窗口                        翻脸 / 倒计时
```

## 二、Boss 行为规则（第三方博弈方）

### 2.1 基础规则

1. **自由活动**：Boss 在地图上移动，攻击沿途一切，非固定点位；后期随海平面上升，可活动区域逐步被压缩至峰顶决战圈。
2. **仇恨机制**：优先攻击范围内对它造成伤害最多 / 最近的目标；可被"引怪"转移。
3. **随时间变强**：每 30 秒提升一次属性（攻击 / 血量 / 技能频率），幅度约 5–10%。
4. **残血回血**：血量进入 20% 区间开始缓慢回血，10% 以下加速；迫使玩家做选择。

> **变强与回血共同构成全局倒计时**：合作越久越难打，拖延必然双输。

### 2.2 Boss 的"判断力"（结盟判定）

Boss 不是被动木桩，它有自己的生存判断：**每 10 秒进行一次局势判断；只有判断打不过二人联手时，才会考虑与玩家结盟。**

| 情况 | Boss 反应 |
|------|----------|
| Boss 自评能双杀 / 打不过二人联手的判断不成立 | 不结盟，直接进攻 |
| Boss 自评打不过二人联手，弱者状态尚可 | 进入结盟判定；主动发起结盟的概率上限约 20% |
| Boss 自评打不过二人联手，但弱者已残血 | 不结盟（Boss 不与残血者结盟），选择先击杀弱者 |
| 强者（战力高方）按结盟 | **不接受申请**（给弱者保留活路与翻盘机会）；仅弱者拒绝 Boss 主动提议后才可能转向强者 |
| 双方战力差 < 阈值（约 5%） | 视为势均力敌，走"玩家间结盟"路径 |

**判定周期（10 秒，局势判断）**：Boss 每 10 秒按当前状态做一次局势判断并保存快照；判断条件包括双杀可行性、残血排除、战力差与浮点波动。玩家申请结盟时不实时重算，以**上一次判断快照**作为依据（结果存在 0-10 秒延迟窗口）。快照固定使用到下一周期，不因残血 / 血量突变等极端变化重算——Boss 凭上次判断行事，这是设计意图。

**主动结盟概率限制**：Boss 判断打不过二人联手后，主动发起结盟的概率上限约 20%（初版建议，待实测）。Boss 作为想赢的第三方，很少主动帮人；结盟本身就是与虎谋皮。

**玩家申请不共用主动概率**：Boss 同意玩家结盟申请只依据 10 秒局势判断快照结果（含浮点波动，玩家参数不变结果也可能不同）与残血排除；条件满足即同意，不经过 20% 主动发起概率。

**判定带浮点波动**：Boss 的"能否双杀"评估不是精确数值，而是带随机波动的区间；即使结盟是最优解，也可能拒绝，避免玩家把 Boss 当公式机器。

**玩家无法精确读取 Boss 的"双杀信心"**：紧张局势下即使显示精确数值，绝大多数玩家也来不及计算，只能靠经验判断（类似玩家间结盟，对方也可能无理由拒绝）；只有极少数顶尖玩家会利用精确数值，设计不以此为前提。

**弱者 = Boss 可利用的刀；强者 = Boss 不需要的帮手。**

**设计意图：结盟是最后手段，不是稳定策略**：到 Boss 阶段，弱者若想赢基本只有赌结盟这一条路；因此真正重要的是前期把自身发展好，而不是依赖结盟翻盘。Boss 随时会反咬，弱者把赢的希望寄托在结盟上，本身就是高风险赌博。

### 2.3 战力计算体系：塔的计入规则

Boss 判定结盟、以及玩家自身评估"我能不能 solo"时，依据的**战力 = 攻击 + 生命 + 防御 + 已放置塔的综合统计值**。已放置的塔计入战力；背包中未放置的塔不计入战力，结盟期间锁定不可放置，结盟结束后可继续放塔；结盟不会没收囤塔。

> **囤塔定义**：前期收集并合成塔，但不在战场上放下。囤塔不计入战力，结盟期间锁定不可放置，结盟结束后解锁；这是弱势玩家为 Boss 战翻盘的手段之一。

| 规则 | 含义 |
|------|------|
| **战力组成** | 攻击、生命、防御、已放置塔综合统计为一个数值 |
| **已放下的塔** | 计入战力 |
| **背包 / 未放置的塔** | **不计入战力**；结盟期间锁定不可放置，结盟结束后可继续放塔 |
| **被摧毁的塔** | 从战力中实时扣除 |

**设计意图：**

1. **战力是"当前能打的火力"，不是"你攒了多少"** —— 已放塔是当前战力的一部分，未放塔是预留资本。
2. **结盟不没收囤塔** —— 前期囤下的塔不被作废，弱者可以把塔留到结盟结束后用于风筝与翻盘。
3. **战力接近不代表一边倒** —— 战力是属性的综合评价；接近时胜负仍由属性结构、操作与时机决定。
4. **伪弱者边界** —— 囤塔压战力骗结盟只在双方装备接近时有意义；塔在战力中权重不高，囤塔对战力差影响有限，强者仍靠装备与技能拉开差距。

> 对玩家的信息呈现：战力对比界面显示综合战力数值（攻击 / 生命 / 防御 / 塔），并标注"背包中未放置塔不计入战力；结盟期间锁定，结盟结束后可放置"。

## 三、结盟系统（核心机制）

### 3.1 结盟路径

| 类型 | 发起方 | 确认方 | 生效条件 |
|------|--------|--------|----------|
| **弱者 + Boss** | 弱者申请 或 Boss 主动 | 对方确认/拒绝 | 申请：10 秒局势判断快照通过（排除残血者，含浮点波动）即同意；主动：额外受 20% 概率限制（结盟不没收囤塔） |
| **强者 + Boss（后补路径）** | Boss 主动 | 强者确认/拒绝 | 仅弱者拒绝后触发；条件与弱者结盟不同，待定 |
| **玩家 + 玩家** | 一方发起 | 另一方确认（各一次机会） | 双方都确认 |

**共同点：都有时间限制；时限到即强制解除并进入 PvP；结盟期间背包中未放置的塔锁定不可放置、不计入战力，结盟结束后可继续放塔。Boss 主动提议失败后，本次判定周期内不重复向同一玩家发起，下一周期重新计算。**

### 3.2 弱者 + Boss 结盟

#### 触发判定

**判定周期（每 10 秒）**：Boss 每 10 秒按当前状态计算一次结盟条件并保存快照，判定流程如下：

1. **双杀可行性**：Boss 自评能否击杀双方？能双杀 → 不结盟；很难双杀 → 进入下一步。
2. **弱者状态（残血排除）**：Boss 不与残血者结盟；弱者已残血（几下可击杀）→ 不结盟，选择先击杀弱者；弱者状态尚可 → 进入结盟判定。
3. **战力差确认**：双方战力差距 > 阈值（如强者 / 弱者 DPS > 1.3x），确认弱者身份。
4. **浮点波动**：判定带随机波动区间，即使数值上结盟是最优解，也可能拒绝。
5. **主动结盟概率限制（仅限 Boss 主动）**：Boss 判断打不过二人联手后，主动发起结盟的概率上限约 20%。玩家申请不经过该概率：只看 10 秒局势判断快照结果（含浮点波动，玩家参数不变结果也可能不同）与残血排除，条件满足即同意。

**结果采用上一次计算快照**：玩家申请结盟时，Boss 不实时重算，直接采用最近一次判定结果；Boss 也可在计算后主动向玩家发起结盟提议，玩家可接受或拒绝。

> 参考公式（初版）：`Boss剩余血量 × 强化系数 > 双方合计DPS × 预估击杀时间` 表示"Boss 难以被联手击杀"，实际判定在此基础上叠加浮点波动。

#### 结盟生效期间（建议 15–20 秒）

- Boss 仇恨 **100% 锁定强者**
- 弱者只打强者，不强者即视为"盟友"
- 强者被 Boss + 弱者夹击
- 结盟期间 Boss 持续变强 / 回血 → 弱者必须速战速决
- **强者的反制**：强者需在中期预判弱者结盟意图，并通过技能配置强化保命（如第二技能选隐身、冰冻），用于躲过结盟爆发窗口或打断弱者输出

#### 结盟结束

- **Boss 优先追杀结盟过的弱者**（防止退回三方混战）
- 弱者需面对：强者可能还活着 + Boss 转头
- 弱者临死前可"引 Boss"至强者脸上，做最后一搏

#### 拒绝的惩罚

- Boss 短暂优先攻击该弱者（约 10 秒）暴露意图，强者获得反击窗口
- 弱者申请与 Boss 结盟有 30 秒冷却：申请失败（判定不通过 / 被拒 / 超时）后，下次申请需等冷却结束
- **弱者拒绝 Boss 主动结盟**：本次判定周期内 Boss 不再向该弱者重复提议，并可转向强者发起结盟提议，强者可接受或拒绝

#### 囤塔与"终局放塔"

**结盟不没收囤塔：前期囤下的塔不计入战力，结盟期间锁定不可放置；结盟结束后解锁，可继续放塔用于风筝与翻盘。**

**但弱者可以把"放塔"留到结盟结束之后：**

- 结盟期间（20 秒内）：弱者全力打强者；未放塔锁定不可放置，只能等结盟结束后再放塔风筝
- 结盟结束、Boss 转头追杀弱者时：弱者获得"临场放塔"窗口 —— 在 Boss 行进路径上放**攻击塔**输出、在风筝折返点放**生命塔**回血，把 Boss 引着绕圈

> **弱者赢的终局形态 = 被 Boss 追杀 + 用事先预留的塔风筝 Boss。**
> 预留的塔 = 弱者 solo 阶段的生存资本；预留得越多，风筝越久，翻盘概率越高。

**这构成了一个关键的前期决策**：弱者前期要不要**少放塔、攒着**？——攒着则结盟前战力低（Boss 更易判定通过），但结盟后 solo 资本少；全摆出来则战力高（判定风险）、但当场可打的火力多。**"预留多少塔"是弱者贯穿中后期的隐藏决策。**

### 3.3 玩家 + 玩家结盟

#### 触发条件

- 双方战力接近（差距 < 阈值）
- 一方发起 → 另一方 2–3 秒内确认（否则超时拒绝）

#### 结盟生效期间（建议 30–45 秒）

- 双方不能互相攻击
- 共同目标：击杀 Boss
- **Boss 残血时可翻脸**（高风险，见下）
- 任一玩家攻击对方 → 结盟立即破裂，攻击方获得"Boss 仇恨锁定" debuff，被攻击方获短暂"Boss 不打你"buff

#### 结盟结束

- 倒计时 3 秒提示后 PvP 解锁
- 或直接由翻脸提前破裂
- Boss 已死 → 直接进入恶魔之心争夺

### 3.4 结盟时限设计原则

| 结盟类型 | 建议时长 | 设计意图 |
|----------|---------|----------|
| 弱者 + Boss | 15–20 秒 | 弱者必须全力爆发，强者需极限操作 |
| 玩家 + 玩家 | 30–45 秒 | 需足够时间合作击杀 Boss |

- 弱者攻击 Boss → 结盟时间缩短（视为背叛）
- 强者攻击 Boss → 结盟时间延长（Boss 认为其有用）

## 四、双方各自的赢的路径

### 4.1 强者（战力高方）

> **发育 → 引 Boss → 合作消耗 → 在 Boss 残血前翻脸 → solo 收尾**

| 阶段 | 强者处境 | 理性选择 |
|------|---------|---------|
| Boss 满血 | 需弱者帮忙 | 忍，不翻脸 |
| Boss 50% | 弱者开始试探 | 继续忍，控制自身血量 |
| Boss 25% | 弱者持续施压 | 准备翻脸 |
| Boss 15% | 弱者没停手 | **必须翻脸** |
| Boss 10% | 自身血量 < 30% | 赌博式翻脸或认栽 |

**翻脸时机 = 核心决策**：太早 → solo 打不完；太晚 → 被弱者反杀。

### 4.2 弱者（战力低方）

> **推 Boss 进度 → 胁迫合作 → 持续压强者血量 → 残血时反杀或合作到底**

| 阶段 | 弱者处境 | 理性选择 |
|------|---------|---------|
| Boss 满血 | 不合作 = solo 必死 | 打 Boss（被迫合作） |
| Boss 50% | 强者血量在降 | 试探（打强者一下） |
| Boss 25% | 强者血量 < 我 | 持续压强者 |
| Boss 15% | 强者血量 < 40% | **全力打强者** |
| Boss 10% | 强者未翻脸 | 赌一把翻脸 |
| 结盟结束 / 强者死 | Boss 转头追杀 | **放预留塔，风筝 Boss** |

**弱者赢的方式不是正面击败，是借 Boss 为武器 + 残血收割 + 终局风筝：**

1. 中期少放塔、攒**预留塔**（囤塔不计战力、结盟不没收囤塔；结盟期间不能放置，结盟结束后解锁，留到 solo 阶段风筝最稳）
2. 结盟结束被 Boss 追杀 → 边跑边在 Boss 路径上放攻击塔 / 在折返点放生命塔
3. 用塔把 Boss 引着绕圈 → 持续输出 + 回血 → 拖到 Boss 可被击杀

> **注意设计一致性**：结盟不没收囤塔，囤下的塔始终保留；无论弱者走哪条结盟路径，"囤塔用于终局风筝"都在 solo 阶段可用。

### 4.3 势均力敌时

双方皆非"明确强/弱"，走**玩家间结盟**路径：

- 假装合作 → 等 Boss 残血 → 谁先动手谁暴露
- 用塔改变 DPS 对比 → 从势均力敌变为"我强" → 转强者路径
- 用走位 / 假动作骗对手先暴露 → 后发制人

> **赢的路径不是一个固定路线，是一个时机判断："我现在翻脸能赢吗？"**

## 五、三方混战（都不结盟时）

### 5.1 默认路径：被动合作

三方都不结盟 → 双方都在打 Boss（被动合作）→ Boss 变强 → 收敛：

| 分支 | 结果 |
|------|------|
| 双方 DPS 够 | Boss 被打死 → 恶魔之心争夺 → 交付方获胜 |
| DPS 不够 | Boss 越来越强 → 一方先残 → 翻脸或逃跑 |
| 有人提前翻脸 | 三方混战 → 有人先死 → 终局 |
| 双方都打不动 | **Boss 赢 → 双输** |

### 5.2 "Boss 赢"是系统惩罚

> **实力差不多 + 都不结盟 = 最终赢家是 Boss。**

这确保"不作为"不是合法策略，迫使玩家主动选择结盟或翻脸。

## 六、决策场景写法（设计方法）

### 6.1 每个决策点需闭环

每个决策的后果必须在 **1–3 分钟内可见**，并能引出下一个决策。

### 6.2 决策卡模板

```
【时机】游戏第 X 分钟 / Boss 血量区间 / 某事件触发
【情境】玩家可见信息（Boss形态 / 双方血量 / 强化层数 / 对手行为）
【选择】A / B / C
【即时后果（1–3分钟内）】每个选择导致什么
【对后续的影响】后果如何改变下一个决策的输入
```

### 6.3 示例：弱者考虑与 Boss 结盟（Boss 30%）

> **情境**：Boss 第 2 层强化，回血中；你 55% 血，强者 40% 血；攻击塔已建 1 座。
>
> **选择**：
> - A：按结盟 → 赌 Boss 判定通过 → 20 秒内需击杀强者
> - B：继续打 Boss → 赌强者也不翻脸 → Boss 死 → 你赢
> - C：打强者 → 翻脸 → 赌自己能先杀强者
>
> **后果**：
> - A 成功 → 强者死 → 你 vs Boss（结盟时血量）→ 赢或死
> - A 失败（拒绝/超时）→ 暴露意图 → 强者反杀窗口
> - B → Boss 持续回血 → 可能双输
> - C → 被 Boss 集火 → 需强者也翻脸才成立

## 七、海平面与空间压缩

- Boss 苏醒前后海平面开始上升，持续压缩活动空间
- 把双方与 Boss 自然逼入同一区域，避免无限风筝
- Boss 自由活动但被海平面逐步压缩至峰顶决战圈，不会长期远离战场
- 被淹没区域：持续掉血 / 减速（具体规则待定）
- 高地是后期可靠阵地，低地塔需提前转移

> 海平面是**倒计时与压缩器**，不是独立机制；确保"不去 Boss 区域"不是可持久选项。

## 八、胜负判定（Boss 死后进入恶魔之心争夺）

**Boss 死亡 → 恶魔之心掉落 → 拾取读条（10 秒）→ 打断 / 抢夺 → 交付（过场动画）**

- Boss 被击杀后，恶魔之心掉落在地面，进入**心争夺阶段**。
- 拾取恶魔之心需要 10 秒读条：受击回退（不归零），移动或主动操作可打断并重置；拾取者可被攻击，死亡后心掉落回地面。
- 对手可以打断拾取并抢夺；心在玩家死亡时必定掉落。
- 交付：心持有者触发交付后，阿蛮主动赶来收取；交付只作为**终局过场动画**，玩家不需要移动回岛中岛祭坛，游戏在过场结束时判定胜负。

| 情况 | 结果 |
|------|------|
| 一方拾取恶魔之心并完成交付 | 交付方获胜 |
| Boss 死亡后双方都未能拾取 / 交付 | 双输 |
| 双方都被 Boss / 互相击杀 | 双输 |
| 一方先出局，另一方 solo Boss 失败 | 双输（与死亡规则统一） |

> **死亡规则统一口径**：玩家死亡 = 出局（失去参与权与胜负资格），对局继续至 Boss 战结束；若幸存者无法击杀 Boss 或交付恶魔之心，仍为双输。

## 十、开放问题与待办

| 优先级 | 问题 | 方向 |
|--------|------|------|
| P0 | Boss 变强幅度与间隔（5–10% / 30 秒） | 实测，以"合作 DPS 在 40% 前追不上"为目标 |
| P0 | 弱者+Boss 结盟时长（15/20 秒） | 强者解谜窗口 vs 弱者爆发窗口平衡 |
| P0 | Boss 双杀可行性判定 + 浮点波动区间 | 波动让结果不可精确预测，但整体趋势可预期 |
| P0 | 弱者残血时 Boss 转击杀的边界 | 明确"几下能杀"的判定阈值，并给玩家可感知的反馈（Boss 转头） |
| P1 | Boss 结盟申请 30 秒冷却 | 实测失败惩罚与翻盘窗口平衡 |
| P1 | 强者 + Boss 结盟路径的条件与时长 | 仅在弱者拒绝后触发；需避免强者路径优于弱者路径，建议更短时限/更高背叛风险 |
| P1 | 10 秒判定快照的延迟窗口 | 快照结果与实况偏差在 0-10 秒，需保证玩家可读 |
| P1 | 玩家申请通过率的可读性 | 已定：不共用主动结盟 20% 概率；申请只看 10 秒快照 + 残血。需实测浮点波动幅度，保证"参数不变结果可能不同"可被感知但不失控 |
| P0 | 强者 solo 残血 Boss 成功率 | 翻脸时机应有 50–70% 成功区间 |
| P0 | 弱者+Boss 结盟后 Boss 剩余血量（40–60% 最佳） | 确保弱者 solo 有挑战但可行 |
| P0 | 玩家间结盟时长（30–45 秒） | 够打死 Boss 但不过于宽裕 |
| P1 | 强者反制手段（中期预判 + 保命技能配置：隐身 / 冰冻 / 位移） | 确保被结盟方不无解 |
| P1 | 海平面上升节奏 | 与 Boss 苏醒时机协调 |
| P2 | 单局时长与前期节奏 | 避免"全程对峙"僵局 |
| P1 | 囤塔数量与弱者 solo 风筝可行性 | 囤几座塔能让风筝"有挑战但可行"，需配合 Boss 移动速度与塔射程实测 |
| P1 | 结盟前战力是否被"Boss 实时读取" | 玩家临结盟前紧急放塔能否影响判定（建议：判定瞬间锁定，防钻空子） |
| P0 | 恶魔之心拾取读条（10 秒）与打断/抢夺节奏 | 实测拾取与抢夺的紧张感，避免心争夺变成尾刀或运气 |

## 十一、一句话总结

> **这不是两个人打一个 Boss，是三方在倒计时里轮流谈判、结盟、背叛。强者靠时机翻脸，弱者靠 Boss 翻盘、靠预留塔风筝，Boss 靠耐心收割——不作为的人，把胜利留给 Boss。塔要么在战场上发光，要么被囤到最后一刻；弱者把塔留到最后一刻，才换来 solo 时的一线生机。**

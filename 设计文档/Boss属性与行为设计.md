# 《分道扬镳》Boss 属性与行为设计

> 版本：v0.4（冻结 3 秒单向申请承诺，移除 Boss 结盟仇恨门槛）
> 定位：Boss 本体（属性 / 技能 / 行为逻辑）设计；三方博弈与结盟规则见《Boss战设计_三国演义式三方博弈》
> 原则：Boss 是"想赢、怕死、记仇、谨慎"的第三方，所有属性与行为都服务这一人格
> 文档边界：本文只描述 Boss 本体属性、状态和 Boss 侧决策；Common、圣物、Endgame 和 AI 玩家规则通过相关文档与接口引用

## 一、Boss 定位

- Boss 不是木桩，也不是普通怪：它承担共同威胁、博弈杠杆、终局载体三个功能。
- 属性回答"玩家要花多久才能打死它"；行为回答"它现在想赢、怕死，还是在试探"。

## 二、属性基线（初版）

| 属性 | 初版值 | 说明 |
| --- | --- | --- |
| 生命 | 10000 | 正常状态基线；最大生命、攻击和攻击速度按阶段默认取 0.6 / 1.0 / 2.0 |
| 防御 | 100 | 固定减伤：1 点防御抵消 1 点伤害，角色通用 |
| 攻击 | 300/次 | 攻击间隔 2 秒，等效 DPS 150/秒；圣物文档的减伤示例沿用此基准 |
| 移速 | 3 m/s | 低于玩家基础 4 m/s，可被风筝，但受海平面压缩 |
| 目标获取范围 | 20m | 达到此距离才进入候选目标池；只负责获取，不负责移动 |
| 追击范围 | 20m / 40m | 普通追击 20m；已获取的残血目标追击 40m |
| 攻击距离 | 2m（可配置） | 普通攻击实际命中距离，与获取和追击范围独立 |
| 强化层 | 每 30 秒 +1 层 | 每层攻击 / 技能频率 +5-10%，层数 UI 可见 |
| 被动回血 | 由 Health/CombatState 配置：Weak / Normal 可启用；Rage 禁用；Boss 不创建回血 Intent | 制造斩杀线前的抉择窗口 |
| 控制抗性 | 减速生效，眩晕缩短 / 免疫 | 避免控制链锁死 Boss |

### 与圣物的交互

- Boss 不保存圣物类型、减伤比例、仇恨基础值或衰减时长；这些数据由圣物系统负责。
- Boss 通过 `IRelicStateProvider` 检测目标是否持有圣物，并读取最终 `relicHate` 与仇恨版本。
- 圣物变化事件触发目标池或目标快照刷新；Boss 只消费结果，不自行维护圣物状态。
- Boss 伤害进入统一伤害系统；圣物减伤、防御和最终伤害计算公式由伤害系统负责。
- Boss 的仇恨排序中只保存 `relicHate` 分项，具体数值来源属于圣物系统。

### 状态：虚弱、正常、暴走

Boss 状态统一使用三种互斥表述：

| 状态 | 触发 | 效果 | 退出 |
| --- | --- | --- | --- |
| 虚弱 | 提前苏醒或对手淘汰后苏醒 | 最大生命 / 攻击 / 攻击速度倍率 = 0.6；移速、技能频率、仇恨倍率 = 1.0 | 强度恢复到 100% 后进入正常 |
| 正常 | 正常苏醒或虚弱恢复完成 | 最大生命 / 攻击 / 攻击速度倍率 = 1.0；移速、技能频率、仇恨倍率 = 1.0 | 到达暴走时间后进入暴走 |
| 暴走 | 苏醒后达到设定时间 | 最大生命 / 攻击 / 攻击速度倍率 = 2.0；移速、技能频率、仇恨倍率 = 1.0 | 死亡 |

规则：

- 虚弱状态下，起始强度暂定为 50-60%，每分钟恢复约 10%。
- 玩家在 Boss 苏醒前死亡但成功回魂时，不属于对手淘汰，不触发虚弱。
- 如果虚弱状态在到达暴走时仍未恢复完成，直接进入暴走。
- `rageAtTime` 使用 `encounterTime = gameTime - encounterStartTime`，从 Boss 苏醒开始计算；暂定苏醒后 480 秒进入 Rage。
- 行为逻辑可以通过行为控制器调整，但状态控制器只提供属性、技能频率和仇恨倍率。
- UI、日志和后续文档统一使用“虚弱 / 正常 / 暴走”，不再使用第一、第二、第三形态作为状态名称。

行为差异：

- Weak（虚弱）：每 5 秒做一次求生快照；生命低于 `35% × 0.9-1.1`，且 20m 内非盟友存活玩家的当前生命总和大于 Boss 当前生命的 150% 时，Survive（求生）优先。Boss 强行脱离战斗并逃跑，同时请求第一技能槽；生命恢复到 40% 时结束求生。
- Normal（正常）：只有生命低于 10%，且 20m 内非盟友存活玩家的当前生命总和大于 Boss 当前生命的 200% 时才进入 Survive；其他情况优先残血追击/击杀。生命恢复到 30% 时结束求生。
- 进入 Survive 时调用 `IHealthService.EnterAutoRegen(RegenReason.Survive)`，由 Health 自动回血；退出 Survive、进入 Rage、死亡或 slot1 不可用时停止。
- Survive 自动回血不要求 Boss 先脱离战斗，默认不因受击完全停止；Boss 不直接修改生命，也不自行计算回血速率。
- Rage（暴走）：不逃跑、不结盟、不接受结盟申请、不主动提议，只执行攻击、追击并请求配置为进攻用途的技能槽。
- 第一技能槽就是普通技能槽，Survive 或连续 3 秒未命中敌对玩家时请求该槽；实际效果由绑定的 SkillCard 决定。“保命技能”只是体验描述，不是机制分类。
- 进入战斗后，第二、第三技能槽只要槽位 Ready 且存在合法战斗目标，就在下一个行为决策点请求；效果是否允许施放由技能系统的 `triggerPolicy` 判断，Boss 不读取分身或增益状态。
- Engage / Chase / Rage 中，如果 Boss 本体连续 3 秒未命中敌对玩家，第一技能槽作为追击受阻的战术例外，优先于普通战斗技能。Survive 仍拥有最高优先级。
- `SeekAlliance` 当前不请求第二、第三技能槽；没有符合条件的技能时继续普攻、移动或执行当前意图。
- 求生快照周期内不重新计算进入条件；一旦进入 Survive 就锁存到对应退出阈值，不因血量波动、盟友关系变化或局势判断快照切换而中断。
- Boss 首次跌破求生进入阈值时立即刷新一次求生快照；恢复到退出阈值时立即结束 Survive，不等待 5 秒周期。
- 第一技能槽为 `Disabled` 时不进入 Survive，已在其中则立即结束；为 `Cooldown` 时可短暂逃跑等待，
  但不轮询请求，超过 `maxSurviveDuration` 仍未达到退出阈值时强制结束并转入普通战斗或结盟。
- Survive 每 1 秒或受阻时重新选择逃跑目标点：生成多个候选方向，用 NavMesh 落点校验，按威胁中心、安全区、火力覆盖和地形风险评分；只有目标明显变化或路径失效时才 `SetDestination`。卡住判断使用 1 秒窗口内的有效路径进度，累计 2.5 秒无有效进度时强制退出 Survive。

## 三、技能槽设计

Boss 的行为逻辑只决定“在什么状态下请求第几个技能槽”，不依赖固定技能名。
技能效果、目标类型和具体触发参数由槽位当前绑定的 `SkillCard` 与 `SkillSlotBinding` 决定。

| 技能槽 | 当前 SkillCard | CD | Boss 侧请求规则 | 技能系统负责 |
| --- | --- | --- | --- | --- |
| `slotId=1` | 地震波 | 20 秒 | Weak / Normal 的 Survive 状态请求该槽；或 Engage / Chase / Rage 中连续 3 秒未命中敌对玩家时请求 | 目标过滤、范围、距离和效果应用 |
| `slotId=2` | 分身 | 15 秒 | Engage / Chase / Rage 中，有合法战斗目标、槽位 Ready 时请求 | 是否已有分身、分身继承和生命周期 |
| `slotId=3` | 嗜血狂暴 | 30 秒 | Engage / Chase / Rage 中，有合法战斗目标、槽位 Ready 时请求 | 增益状态、叠加顺序、持续时间和目标过滤 |

Boss 行为层只请求 `slotId`。当前三张 SkillCard 是 Demo 临时配置，后续可以整体替换；
具体效果以《技能系统设计》的 Boss Demo 技能卡为准。

技能系统负责判断槽位是否 Ready 以及效果触发策略是否通过；Boss 只负责战斗状态、请求优先级和状态原因，不保存分身或增益活动状态。

槽位触发关系：

- `Survive` → 请求 `slotId=1`，优先级最高。
- `Engage / Chase / Rage` 中连续 3 秒未命中敌对玩家 → 请求 `slotId=1`，优先于普通战斗技能。
- `Engage / Chase / Rage` → 请求配置为战斗槽的槽位，当前为 `slotId=2/3`；固定优先 `slot3`，其次 `slot2`。
- `Kite` 当前仅为占位枚举，Demo 默认 `kiteEnabled=false`，不进入行为验收。
- `SeekAlliance` → 结盟期间允许的槽位由后续配置决定。
- `Rage` → 只请求 `triggerPolicy` 允许在 Rage 下触发的槽位，不按固定 slotId 禁用。
- `SeekAlliance` → 当前不请求 `slot1/2/3`；后续防御型槽位另行配置。

## 四、行为逻辑（核心）

Boss 是"状态机 + 每 10 秒局势判断 + 每 5 秒求生判断"的决策者：

```
漫游 → 追击 → 求生快照（5 秒）/ 局势判断（10 秒）→ 进攻 / 求生 / 结盟 / 转向
→ 结盟执行 → 翻脸 / 追杀 → 死亡 → 心争夺
```

- **不做极端状态重算**：10 秒局势判断快照固定使用到下一周期，残血、血量突变等极端变化不打断局势判断快照。求生使用独立的 5 秒快照，进入后锁存到 40% / 30% 退出阈值。唯一强制例外是玩家永久淘汰或 Boss 死亡；事件结算后立即刷新所有存活观察者的活动快照，历史快照不改写。
- **结盟关系实时覆盖**：结盟开始、结束、翻脸或关系变化时，立即更新 `allianceState / allianceTargetId` 并递增 `allianceVersion`；10 秒快照保存版本号，不重掷其他战略字段。目标过滤和攻击合法性以实时版本为准。任一玩家或 Boss 死亡时，涉及死亡方的结盟立即结束，不进入缓冲、不产生追杀仇恨。

### 仇恨结算（总分排序 + 5 秒快照）

- 所有候选目标按仇恨总分从高到低排序，取最高者；不使用仇恨类型优先级（标记、圣物不单独置顶），同分时按"血量更低 → 战力更低 → 更近"依次裁决。
- 仇恨值 = 滚动 5 秒窗口内对 Boss 造成的真实伤害 + 残血修正 + 圣物仇恨 + 结盟追杀仇恨；各加分项独立累加（如有）。
- 伤害统一采用真实伤害：扣除防御、减伤后实际对 Boss 造成的伤害；玩家本体、玩家召唤物与塔计入，玩家间伤害不计入。
- 残血修正：
  `hpRatio = currentHp / maxHp`；
  `isLowHp = hpRatio < 30%`；
  `lowHpModifier = clamp((30% - hpRatio) / 20%, 0, 1) × 2000`。
  正好 30% 时修正为 0；≤10% 时封顶 2000；血量变化实时更新分值。
- 快照规则：正常每 5 秒结算一次目标，窗口内不因伤害变化换目标；唯一例外是目标血量从 10% 以上跌破 10%（残血修正达到上限 2000）时立即打断快照并换目标，其他血量变化不打断。
- 残血追击范围：
  `effectiveChaseRange = isLowHp ? 40m : 20m`。
  残血目标距离 ≤40m 时继续追击，>40m 时立即终止；目标恢复到 ≥30% 后范围立即回到 20m，
  若此时距离 >20m，则当前目标失效并立即按正常仇恨体系重选。盟友、死亡、不可选或离开战斗区域
  的目标不进入残血追击。
- 当前目标死亡或超出仇恨范围时允许立即重选，其余情况等到下个结算周期。
- `targetAcquireRange` 不因残血扩大；只有已在目标池或有效位置记忆中的残血目标才使用 40m 追击范围。
- `ChaseRange` 只控制移动；普攻是否命中使用独立 `attackRange`，技能命中使用各自 SkillCard.range。
- 圣物仇恨：由 `IRelicStateProvider` 提供最终 `relicHate` 和版本；Boss 不保存日之石/月之石常数。
- 塔不进入玩家仇恨竞争：塔仇恨 = 滚动 5 秒窗口内对 Boss 造成的真实伤害 × 80%，仅在没有可追击玩家目标时生效。Boss 只选择当前可攻击塔；是否持续拆同一座塔、是否切换目标由塔/目标系统决定，Boss 不保存拆塔承诺。
- 仇恨结算决定"追谁"（战术），10 秒局势判断决定"怎么打 / 是否结盟"（战略），两者独立；局势判断快照不因血量变化重算。

行为优先级（每周期；目标选择只按仇恨总分，不使用类型优先）：

1. Weak 求生快照满足条件 → 进入 Survive；Normal 仅在 `<10%` 且敌我生命比 `>200%` 时进入 Survive，否则优先残血击杀。
2. 结盟执行中（Boss + 玩家）→ 盟友仇恨豁免，剩余玩家按仇恨总分排序选择攻击目标；只请求当前配置允许的槽位。
3. 仇恨总分最高的目标在攻击范围内 → 请求当前就绪的战斗槽；Demo 固定 `slot3 > slot2`，每次决策最多请求一个。
4. Engage / Chase / Rage 中连续 3 秒未命中敌对玩家 → 请求 `slot1`；仍无可追击玩家目标时，由目标系统决定是否提供塔目标。
5. 被双人围攻时，如果两名玩家感知战力都低于 Boss 战力 70%，则触发 `BossPowerAdvantage（Boss 战力压制）`；此时 Boss 不结盟，未结盟时只请求战斗槽。
6. 结盟结束 → 按结盟追杀仇恨规则追击原盟友。
7. 非 Rage 且血量 <20% → 由 Health 被动执行回血，不创建 Behavior Intent；Boss 的行为优先级不因回血额外插入状态。

### 与结盟的仇恨联动

- Boss + 玩家结盟的绝对门禁：场上必须恰好有 2 名玩家存活；只剩 1 名或 0 名玩家时，
  拒绝申请、停止主动提议，并立即结束已有 Boss + 玩家结盟。
- 与 Boss 结盟：Boss 仇恨不再限制申请或 Boss 接受；仇恨仍正常参与 Boss 的目标选择。申请不受距离限制。
- 与 Boss 结盟还要求申请人生命比例不低于 30%；低于 30% 时不可主动申请，正好 30% 时允许。
- 有效结盟申请提交后进入 3 秒等待期：申请者本体、召唤物、分身和塔停止攻击目标，目标保持完全自由；申请者主动攻击目标会取消申请。
- 目标主动攻击申请者，或目标归属单位累计造成超过申请者最大生命值 5% 的实际伤害，视为拒绝。Boss 作为申请者主动提议时同样受 3 秒等待期限制。
- Boss + 玩家主动申请冷却为 60 秒，玩家间主动申请冷却为 120 秒；均从有效申请提交时开始，即使随后被接受、拒绝或超时也不返还。
- 接受或拒绝他人的申请不消耗自己的主动申请冷却；Boss 主动提议被接受也不触发玩家的 Boss 申请冷却。
- Boss + 玩家结盟期间以及结束后的 10 秒内，玩家间结盟申请与接受均禁止。
- 玩家间申请被拒绝或超时后，双方进入 5 秒协商锁，期间不能再次互相申请。
- 与玩家结盟：玩家之间没有仇恨概念，申请不受仇恨限制，可自由申请；不设每局固定申请次数，由 120 秒主动申请冷却限制。
- `relicHate` 由 `IRelicStateProvider` 提供；继续参与目标选择，但不再阻止 Boss 结盟，衰减时长由圣物系统维护。
- 结盟期间，缔约方之间互不攻击；盟友不可成为仇恨目标，即使被强者打到 10% 以下也不会触发残血上限打断，直到结盟结束。
- 结盟结束后，原盟友的仇恨：先进 3 秒缓冲（仇恨为 0），之后进入追杀仇恨；若目标仍 ≤10%，残血修正与结盟惩罚仇恨（+5000，30 秒内线性归零）是两个独立加分项，叠加计算；攻击 Boss 造成的伤害仇恨照常另算。
- 正常到期时，T0 立即刷新目标池、目标快照、5 秒求生快照、策略结盟区块和 AI 可见状态；T+3 惩罚仇恨生效时立即刷新目标仇恨排序。

人格一致性总结：Boss 想赢（能双杀就杀、残血必杀）、怕死（打不过才结盟、主动结盟低概率）、记仇（追杀结盟过的弱者）、谨慎（不与残血者结盟）。

行为可读性：玩家不需要精确预测 Boss。紧张局势下即使显示精确数值，绝大多数玩家也来不及计算，只能靠经验判断；因此意图呈现以可观察的模式为主（低吼 / 变色 / 地面特效 / 强化层光环）。只有极少数顶尖玩家会利用精确数值，设计不以此为前提。

## 五、开放问题

1. 虚弱、正常、暴走的最大生命、攻击和攻击速度默认倍率为 0.6 / 1.0 / 2.0；移速、技能频率和仇恨倍率固定为 1.0。切换时间和后续平衡微调待实测，不影响默认配置。
2. 防御公式已定：1 点防御抵消 1 点伤害（固定减伤，角色通用）；暴走状态下防御是否同步变化待定。
3. Demo 技能的目标过滤、分身继承、增益叠加和第三槽随机池统一在《技能系统设计》维护，不列入 Boss 开放问题。
4. 强化层幅度（5-10% / 30 秒）与"合作 DPS 在 40% 前追不上"的目标。
5. 移速、仇恨范围与海平面压缩速度的配合。
6. 控制抗性的具体规则（眩晕免疫 / 缩短比例）。
7. 圣物减伤与防御的最终公式由统一伤害系统冻结，Boss 只消费最终伤害。
8. `relicHate` 与残血修正的最终平衡由圣物系统和 Boss 数值测试验证，不在 Boss 文档保存圣物常数。
9. 当前 Demo 的战斗槽请求、优先级和 3 秒未命中规则已冻结；结盟期间允许的槽位和未来防御型槽位触发规则待技能设计。
10. `maxSurviveDuration` 与 `surviveForcedExitCooldown` 的具体数值需根据第一槽技能冷却和恢复量实测。
11. Normal 从 `<10%` 进入求生、恢复到 30% 才退出，Survive 自动回血曲线需要与 15 秒最大求生时长一起实测，避免无法恢复或恢复过快。

## 六、测试对接

- 属性与技能数值进《AI数值测试与验收文档》的 Boss 判定与稳定性验收项。
- 行为逻辑用 AI 稳定性用例验证：状态机无非法迁移、状态只请求配置技能槽、局势判断快照可复现。
- 死亡刷新验证：玩家淘汰和 Boss 死亡后，求生/策略快照立即刷新一次，不死等周期结束。
- 求生槽位兜底验证：Disabled 不进入/立即退出；Cooldown 只在 Ready 后请求一次；超时强制退出且不会立即重入。
- 求生阈值刷新验证：Boss 首次跌破进入阈值立即刷新求生快照，恢复到退出阈值立即结束，不等待 5 秒周期。
- 逃跑目标验证：候选点必须通过 NavMesh 落点校验；目标位移 <2m 或评分优势 <0.15 时保持原目标；实际进度低于 `max(0.5m, 预期进度×25%)` 时判定卡住，累计 2.5 秒无有效进度强制退出。
- 求生逻辑验证：Weak 按 5 秒快照、`35% × 0.9-1.1` 和 150% 敌我生命比进入；Normal 仅在 `<10%` 且 200% 敌我生命比时进入，否则优先残血追击；Weak / Normal 分别在 40% / 30% 退出；Rage 永不进入。
- 仇恨与结盟验收项：总分排序正确（真实伤害 + 残血修正 + relicHate + 结盟追杀仇恨，各加分项独立累加）；relicHate 数值和衰减由 IRelicStateProvider 验证，Boss 在版本变化后刷新目标；5 秒窗口内不换目标、仅跌破 10% 打断；残血追击在 40m 外终止、血量恢复 30% 以上后追击范围回到 20m 并按正常体系结算；结盟期间盟友仇恨豁免且互不攻击；与 Boss 结盟要求生命比例不低于 30%，但仇恨不限制申请或接受；Boss / 玩家主动申请冷却分别为 60 / 120 秒；有效申请后 3 秒等待期内申请者及归属单位停止伤害目标，目标保持自由，目标主动攻击或累计造成 >5% 最大生命实际伤害视为拒绝；Boss 结盟期间及结束后 10 秒内禁止玩家间结盟；玩家间申请被拒或超时后双方 5 秒协商锁；结盟结束先进 3 秒缓冲且残血与结盟惩罚仇恨叠加。
